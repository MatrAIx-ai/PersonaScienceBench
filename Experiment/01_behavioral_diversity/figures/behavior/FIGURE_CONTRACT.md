# Figure contract

Python/Matplotlib; quantitative figures, 183 mm wide, editable PDF/SVG and 600 dpi PNG/TIFF. Minimum text 5.5 pt. Original Astra trials only, no new inference or embeddings.

1. Behavioral effects: which observable behaviors change on matched tasks? A single heatmap uses color only to compare standardized magnitudes; each cell prints the raw paired change and pointwise 95% study-cluster CI. No favorable direction is implied. Inapplicable/undefined scales are gray. Denominators and original units are in source data and report.
2. Repeat variation: which behavioral dimensions separate personas beyond run variation? Four panels compare mean absolute differences within off, within personas, and between personas. Each metric uses the same complete task panel for all three categories. Length versus workflow counts serve a positive pattern and its boundary, rather than universal diversity claims. All intervals use the same source-stratified study bootstrap; pairwise run combinations are not independent samples.
3. Reply-length distribution: show every task-matched mean difference, without subsampling, alongside source-balanced means and study-cluster CIs. This makes heterogeneity and extreme changes visible rather than relying on means alone. Language/script sensitivity remains in the report.

Source data are saved with each figure. The alignment gate runs on final axes geometry, followed by source, PDF text and collision audits and visual inspection. No transcript excerpts or private prompts are exported.
