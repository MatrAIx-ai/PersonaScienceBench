## Proposed central question

What does scientific-agent evaluation miss when it samples only one default collaborator behavior?

PersonaScienceBench varies the simulated scientific collaborator while holding the task and actor protocol fixed. It evaluates interaction diversity, task/fact fidelity, information exchange, and downstream agent robustness. Real-world heterogeneity motivates broader testing; no measured human realism or representative population claim follows. The current intervention is in the simulator, not the scientific actor itself. Language is explicitly part of all four selected persona profiles.

Potential paper claim, to be tested: persona-conditioned collaborators expose different scientific interaction paths and information-recovery patterns, sometimes without a large change in mean final performance. A reusable evaluation protocol and diagnostic metrics provide benchmark value beyond an empirical persona ablation.

## Prioritized additions

1. Scientific information transfer (Experiment 08). Existing endpoint recovery is recovered deleted facts / total deleted facts. Proposed per-fact extensions: correct requested-fact disclosure, unrequested disclosure under the actual protocol, and final incorporation of correctly disclosed facts. Do not infer disclosure from endpoint recovery. Requires validated fact-to-turn annotation or structured instrumentation; no human realism rating is required, but semantic content validation cannot simply be assumed.
2. Actor process diversity and coverage (Experiment 01). Extract native action sequences, excluding forced initial actions and infrastructure retries. Report optional-review/revision/repeated-question patterns and pairwise normalized sequence distances within a benchmark and question. Native events describe interaction strategy, not a full scientific-method taxonomy. Claiming varied analysis methods requires code/tool/artifact evidence.
3. Failure-discovery coverage (Experiment 02 plus 01). At equal rollout or full evaluation token budget, count distinct tasks with a scientific failure, failures newly found beyond persona-off, and marginal coverage as personas are added. Compare against repeated off, not one baseline run. Native binary success definitions only; continuous benchmarks need separately justified thresholds or continuous regret. Exclude quota/API failures, validate simulator fidelity, and label outcome-selected personas exploratory. Current off has three repeats, so a four-persona versus one-off coverage claim would be unfair; restrict budget to supported common counts or collect new repeats.
4. Task and fact fidelity (Experiment 08/native checks). Report preservation of scientific intent, contradictions with task-owned facts, unauthorized knowledge disclosures and terminal-specification validity. Diversity and fidelity are separate axes. Existing native grounding/intent metrics are reusable where defined; new content claims require a rubric/instrumentation. No single universal higher-is-better metric for verbosity, disagreement or withholding.
5. Elicitation efficiency (Experiment 08). Recovered-fact fraction versus exchanges or full token budget; redundant questions / all questions; questions until all recoverable target facts are elicited. Final-only judges do not support a per-turn recovery curve without additional labels. Treat unreached thresholds as censored and report early termination rather than imputing unobserved messages. Cross-language tokens measure cost, not language-neutral verbosity.
6. Feedback incorporation and correction (Experiment 04 -> quantitative extension). For factual corrections with auditable evidence, measure requested valid changes incorporated / valid actionable requests, correct versus incorrect revision, and repeated errors after feedback. No eligible feedback means unavailable, not zero. Existing traces yield descriptive responsiveness; controlled identical-prefix interventions would be required for a causal persona/feedback mechanism claim.
7. Robustness profile (Experiment 02/03). Report mean score, across-persona spread and observed worst-persona score on identical coverage; binary outcome flips and repeat consistency where repeats exist. Worst among this selected finite set is not real-population worst-case robustness. Three repeats yield limited reliability resolution; 003 and 046 have one. Joint actor/simulator model changes cannot isolate actor-model effects.

Keep current role-separated semantic distances as representation-level diagnostics. Optionally evaluate a Vendi score with a fixed PSD kernel at matched sample counts, per question/role; do not compute on UMAP coordinates or use broad topic/language differences as proof of scientific strategy diversity. This is lower priority than information transfer and evaluation coverage.

## Evidence status and controls

The current repeated panel is off/148/155/089/001/127; 003/004/046 extend one-trial descriptive coverage. The selected figures use off/155/001/003/046. Historical behavior uses original traces, while performance uses eligible repaired endpoints; their episode populations differ. New mechanistic cross-metric comparisons must reconcile them explicitly. The strict post-PR6 SciConv attempt has no scored outcomes and supplies no protocol-comparison evidence.

Proposed controls: equal rollout/token budgets; fixed source-study/question panels; neutral persona-prompt paraphrases; same-language persona variants; repeated off and repeated personas; preserve protocol knowledge/style/volunteering switches. Existing different-language profiles measure a bundled identity intervention. Strong actor scientific-process claims require more than text distance. No significance claim or benefit is presumed.

## Focused literature shortlist and reading depth

- **DIVERT: Efficient Agent Evaluation via Diversity-Guided User Simulation** (Nakash, Kour, Anaby-Tavor, ACL Industry 2026). Primary full-text HTML inspected, especially methods and evaluation metrics. Reports failed trajectories per agent-token budget and unique failed-task coverage. Adapt the coverage question; our persona setup is not its snapshot-branching method. https://aclanthology.org/2026.acl-industry.112/ ; full-text version inspected: https://arxiv.org/html/2604.21480v1
- **Evaluating Large Language Models as Generative User Simulators for Conversational Recommendation** (Yoon et al., NAACL 2024). Primary abstract and targeted full-text PDF sections inspected. Separates component user behaviors, uses diversity diagnostics and comparisons with real users. Borrow decomposition, not evidence of human fidelity for scientific collaborators. https://aclanthology.org/2024.naacl-long.83/
- **τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains** (Yao et al., 2024). Primary abstract inspected. Evaluates terminal state and pass^k consistency across repeated interactions. Borrow repeated reliability; it does not establish realism for our personas. https://arxiv.org/abs/2406.12045
- **The Vendi Score: A Diversity Evaluation Metric for Machine Learning** (Friedman and Dieng, 2022, revised 2023). Primary abstract inspected. Similarity-spectrum effective diversity without reference population; representation/kernel choice defines what diversity means. Optional supplement, not evidence of scientific or human validity. https://arxiv.org/abs/2210.02410
- **Generating Diverse Personas for User Simulators to Test Interview Dialogue Systems** (Nakano, Komatani, Takeuchi, 2026). Primary preprint abstract inspected. Persona generation and communication-trait prompting increase utterance variation. Close adjacent work means persona-conditioned textual diversity alone is not a strong novelty claim. https://arxiv.org/abs/2608.19549
