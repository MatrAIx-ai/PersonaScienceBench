Scientific agents must adapt to researchers with different expertise and
communication preferences, yet benchmark evaluation rarely varies the
collaborator. We introduce \benchmark, an interactive benchmark adapting
200 tasks from five benchmarks across four scientific domains.
Persona-conditioned researcher simulators provide context and feedback
while task objectives and grading criteria remain fixed across settings;
the scientific agent encounters researcher preferences only through interaction.
We evaluate seven model configurations using scientific performance,
fact recovery, and self-repetition, revealing different strengths across
these measures. Detailed analyses with GPT-6 Astra compare four researcher
personas with a persona-off control. All ten pairwise comparisons show
semantic separation in both simulator and actor final responses
(Holm-adjusted $p<0.05$). Interaction traces show targeted follow-up
questions, language accommodation, and workflow revision in response to
researcher feedback. These adaptations are not fully reflected in final
scores: matched attempts can achieve the same score through different
conversations, and some unsuccessful attempts recover every required fact.
\benchmark makes researcher diversity an explicit dimension of
scientific-agent evaluation, capturing adaptation during multi-turn
scientific work alongside task performance.
