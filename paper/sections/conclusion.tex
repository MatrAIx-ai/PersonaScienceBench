\section{Conclusion}
\label{sec:conclusion}

We introduced \benchmark, which adapts 200 tasks from five scientific
benchmarks for collaboration with diverse simulated researchers.
Scientific objectives and grading criteria remain fixed across persona
settings, allowing researcher variation to be examined within the same task.
Persona-conditioned interactions produced distinct agent responses,
communication patterns, and interaction trajectories. Agents asked targeted
follow-up questions, accommodated language preferences, and revised analysis
workflows in response to researcher feedback. Final scores alone did not
capture these differences in how the work was carried out. By evaluating
interaction behavior alongside scientific performance, \benchmark makes
responsiveness to different researchers an explicit part of assessing agents
for multi-turn scientific work.
