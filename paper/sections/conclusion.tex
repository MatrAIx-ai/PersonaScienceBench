\section{Conclusion}
\label{sec:conclusion}

\benchmark evaluates scientific agents against a varying collaborator rather
than a fixed one. By converting 200 tasks from five scientific agent
benchmarks under a source-preserving contract, conditioning a researcher
simulator on complete persona profiles, and pairing every persona condition
with an identical persona-off control, it separates a source of difficulty that
conventional evaluation leaves entangled with task difficulty and agent
capability. Reporting native scientific grades and interaction metrics as
distinct quantities makes it possible to say not only whether a collaborator
changed the outcome, but whether the agent's behavior changed at all---and these
need not coincide.

The practical implication is a change in what a single benchmark number means.
An agent's score against one default collaborator is an average over an
unstated collaborator condition, and this work supplies the apparatus to
measure that dependence directly: worst-collaborator performance, not only mean
performance, is a reportable property of a scientific agent.

Three limits bound these conclusions and are not incidental. The collaborators
are simulated, so the results concern sensitivity to simulated collaborator
variation and not to real scientists. The persona panel was selected using
pilot outcomes, so it spans a range of effects rather than estimating an average
over researchers. And complete profiles vary many attributes at once, so no
effect is attributable to a single dimension.

Each limit indicates a specific next experiment. Single-dimension manipulation
is feasible because the underlying schema separates communication, capability,
and background attributes \citep{li2026matraix}, and would convert range
characterization into dimension-level attribution. Evaluating multiple actor
models on the same collaborator panel would establish whether collaborator
sensitivity is a property of agents in general or of one system, and whether
actor rankings are stable across collaborators. Comparison against human
collaborators on a small task subset would test the ecological validity that
simulation alone cannot establish \citep{liu2026fitnessforpurpose}. The actor
comparison and the non-interactive static reference described in
\secref{sec:experimental-setup} are designed but unexecuted, and are proposals
rather than results of this work.
