\section{Discussion and Conversation Case Studies}
\label{sec:discussion}

\subsection{From Profile to Interaction to Outcome}
Aggregate score differences do not explain themselves. This section presents
task-matched cases in which a specific profile instruction can be traced through
a researcher message, an actor decision, and the graded deliverable, with the
persona-off episode on the same task as the comparison. Each case is built from
four linked elements: the exact injected profile wording, short event-linked
excerpts from the researcher and actor messages, the subsequent actor action, and
the native result alongside its baseline.

Two evidentiary rules apply. Excerpts retain event identifiers so that any
claimed link can be checked against the full recorded trace, and annotation is
performed with outcome scores hidden from the annotator so that a known score
cannot motivate the narrative. Cases are selected to include counterexamples
where a profile preference did not produce the expected behavior, not only
confirming instances.

\subsection{Helpful, Unproductive, and Score-Neutral Changes}
Collaborator effects are not monotone, and three categories are worth separating
because they have different implications for agent design.

\emph{Helpful interventions} occur where researcher guidance supplies a
constraint or correction the actor had not derived, and the deliverable improves
relative to the paired baseline. \emph{Unproductive interactions} consume budget
without changing the science: repeated clarification on already-settled points,
or approval cycles that terminate in the same deliverable. A protocol asymmetry
makes one failure mode structurally available---termination is permitted only
during result review, so a cautious researcher facing an unreadable input can
stall in approach review---and where this occurs it is identified as a protocol
interaction rather than attributed to the profile alone.

\emph{Score-neutral behavioral change} is the category most easily lost in
aggregate reporting. A profile may substantially alter exchange counts, question
patterns, message length, or language while leaving the native score
statistically indistinguishable from baseline. This is a substantive finding
rather than a null result: it demonstrates that behavioral sensitivity and
outcome sensitivity are separate properties, and that an agent can adapt its
interaction without that adaptation reaching the science.

\subsection{Implications for Scientific-Agent Evaluation}
Three implications follow from the design if the effects are borne out, and each
is stated with its limit.

First, a single benchmark score against one default collaborator is an average
over an unreported condition. If collaborator variation moves native scores
appreciably, then worst-collaborator performance becomes a property worth
reporting alongside mean performance, in the same way that worst-group accuracy
is reported in distribution-shift evaluation.

Second, failure under a difficult collaborator is not the same as failure to
adapt. Because interaction metrics are recorded separately from outcomes, it is
possible to distinguish an agent that never sought available information from one
that sought it and was refused, and only the former is an agent deficiency. This
distinction is unavailable in outcome-only evaluation and is the practical
argument for two-sided measurement. A caveat applies in the other direction:
models can perform worse when an equivalent task is distributed across
multiple turns rather than posed in one turn \citep{laban2025lost}. A persona
that provokes more rounds may therefore depress outcomes partly through
interaction length, so exchange counts must be read alongside any outcome
claim.

Fourth, deference is a distinct failure mode from under-asking, and it is
visible only when the collaborator can be wrong. An agent that accepts a
researcher's mistaken claim about their own data fails scientifically while
appearing maximally cooperative, paralleling documented agent overreliance on
unreliable tools \citep{yang2026overreliance}. The present design does not plant
false researcher claims, so it measures how agents respond to varied
collaborators but not whether they check claims against data evidence. Adding
controlled researcher error is the most direct extension, and it would turn
collaborator variation into a test of scientific skepticism rather than only of
adaptation.

Third, observed associations here are not mechanisms. The design supports claims
that conditioning on a profile changed behavior and outcomes on matched tasks; it
does not identify which attribute produced the change, because complete profiles
vary many dimensions simultaneously. Mechanism claims require single-dimension
manipulation, which the underlying schema supports but this study does not
perform \citep{li2026matraix}. Similarly, nothing here establishes that the same
sensitivity would appear with human collaborators; that is a question of
ecological validity requiring human comparison data
\citep{liu2026fitnessforpurpose}.
