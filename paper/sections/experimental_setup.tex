\section{Experimental Setup}
\label{sec:experimental-setup}

\subsection{Models, Persona Settings, and Evaluation Protocol}
\label{sec:run-coverage}
\label{sec:statistical-protocol}
We evaluate Claude Opus 5.5~\cite{anthropic2026opus55} and
Claude Haiku 4.5~\cite{anthropic2025haiku45} from Anthropic,
and Gemini 3.7 Flash~\cite{deepmind2026gemini37flash} and
Gemini 3 Flash~\cite{deepmind2025gemini3flash} from Google DeepMind.
The OpenAI models are GPT-6 Astra~\cite{openai2026astra},
GPT-5 mini, and GPT-5 nano~\cite{openai2025gpt5}
(\tabref{tab:model-scorecard}). Each configuration uses the same model
for the actor and researcher simulator; model-based judging uses GPT-6 Astra.
Astra runs use low reasoning effort. The detailed persona analyses in
Sections~\ref{sec:persona-performance}--\ref{sec:interaction-outcomes}
use the set of runs with GPT-6 Astra.

We use four contrasting persona profiles to examine how agents adapt to
researchers with different disciplinary backgrounds and collaboration
preferences (\tabref{tab:focal-personas}). Persona 001 combines a business and management background
with a curriculum-design specialty and a preference for brief, direct
communication. Persona 003 brings an engineering background and favors
detailed, concrete explanations, speed, and novel approaches. Persona 046
combines finance and economics with a machine-learning specialty and formal,
indirect communication. Persona 155 brings an agriculture and agronomy
background, emphasizing detailed guidance, accuracy, familiar methods, and
teamwork. Together, these profiles provide contrasting contexts for examining
how agents explain technical work, elicit missing information, and negotiate
methodological choices. Only the researcher simulator receives the profile;
the actor encounters its expression through interaction. Persona off uses
the same task and interaction protocol with the profile omitted.

The current design uses one trial per task and persona setting for each model.
Analyses use evaluable task attempts, with coverage determined separately
for each metric. When repeated historical runs are included, they are
averaged within each task. The domain table includes valid repaired outputs
where available. Astra scorecard estimates use original runs, with 95\%
confidence intervals from 20,000 study-cluster bootstrap resamples within
benchmarks~\cite{field2007bootstrap}. Resampling draws are shared across
persona settings. These intervals describe variation across sampled studies,
conditional on the recorded runs.

\subsection{Evaluation Metrics}
\label{sec:metrics}

\noindent\textbf{Scientific performance.}
We normalize each benchmark's score to a 0--100 scale. Performance for setting $p$ is
$S_p=|\mathcal B|^{-1}\sum_{b\in\mathcal B}|Q_b|^{-1}\sum_{q\in Q_b}s_{qp}$,
where $s_{qp}$ is the normalized question score, $Q_b$ contains questions
observed under all five settings in benchmark $b$, and $\mathcal B$ contains
applicable benchmarks. Mean Persona Performance is
$S_{\mathrm{persona}}=|\mathcal P|^{-1}\sum_{p\in\mathcal P}S_p$ for
$\mathcal P=\{155,001,003,046\}$; persona off is reported separately.

\noindent\textbf{Fact recovery.}
For SciConvBench disambiguation cases, fact recovery is
$F_e=100\,|H_e\cap R_e|/|H_e|$, where $H_e$ is the nonempty set of required
withheld facts and $R_e$ is the set recovered during episode $e$.

\noindent\textbf{Actor self-repetition.}
We measure lexical reuse across actor messages using word windows.
For window $w$ in eligible message $m$, the match indicator is
$I_{em}(w)=\mathbf{1}\{\max_{v\in W_{e,<m}}\sum_{k=1}^{6}\mathbf{1}\{w_k=v_k\}\geq3\}$,
where $W_{e,<m}$ contains windows from earlier eligible actor messages and
$\mathbf{1}$ denotes the indicator function. Episode-level repetition is
$\operatorname{Rep}_e=\frac{100}{M_e-1}\sum_{m=2}^{M_e}|W_{em}|^{-1}\sum_{w\in W_{em}}I_{em}(w)$,
where $W_{em}$ contains the windows in message $m$ and $M_e\geq2$ is the
number of eligible messages.
