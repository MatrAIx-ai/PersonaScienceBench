\section{Limitations}
\label{sec:limitations}

\benchmark covers 200 computational tasks drawn from five source benchmarks,
with an emphasis on reasoning over text, data analysis, and code execution.
This scope leaves analysis of images and workflows involving physical
experiments for future extensions. Including these settings would allow
evaluation of how agents respond to visual evidence, instrument constraints,
and researcher feedback during experimental work. The current protocols also
organize collaboration into bounded episodes between one actor and one
simulated researcher. Longer projects and interactions with multiple
researchers would introduce additional demands, including retaining context
across sessions, revisiting earlier decisions, and coordinating differing
priorities. Extending the benchmark along these dimensions would test whether
the observed adaptations persist in multi-turn scientific work across
broader workflows and longer projects.
