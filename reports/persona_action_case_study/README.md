# Retired action-persona experiment

The action-rule diagnostic and benchmark comparison were withdrawn on September 26, 2026. They injected selected action instructions rather than the broader original persona profiles intended for this study. Scores, rankings, generated profile displays, trace indexes, and raw runs have been removed from the current worktree.

The original local persona sample, deterministic sampling metadata, static selection records, and historical 30-candidate identifiers remain under `external/persona_case_study/` and `data/persona_case_study/`. The exact 73 diagnostic-qualified identifiers were lost in the earlier cleanup; the surviving sample cannot establish that membership.

The replacement experiment now uses full-profile simulator system prompts. See the [current partial results and trace report](../full_persona_v2/README.md).

Old scripts are retained as implementation history. Their deleted result inputs are no longer available. Previously committed summaries remain in Git history.
