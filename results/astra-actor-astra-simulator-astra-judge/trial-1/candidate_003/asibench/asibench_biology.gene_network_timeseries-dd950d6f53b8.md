## Предлагаемый анализ после утверждения

### 1. Два независимых вычислительных подхода

**A. Разреженная линейная динамическая модель.** Для каждого target моделировать скорость изменения `(x[t+1]−x[t])/dt` по всем значениям `x[t]`, используя Elastic Net. Собственное значение target включать как динамический контроль, но диагональ не выдавать как межгенную связь. Масштабирование оценивать только на обучающих экспериментах. Регуляризацию выбирать внутренней групповой проверкой. Коэффициент источника даёт направление source→target и локальный линейный знак. Уверенность строить из воспроизводимости ненулевого коэффициента, устойчивости знака и нормированной величины эффекта. Ограничения: линейная аппроксимация, коллинеарность, усиление измерительного шума при вычислении приращений.

**B. Нелинейная динамическая модель на деревьях (Extra Trees).** Независимо обучать по target прогноз того же следующего приращения по полному текущему состоянию. Направленную важность источника оценивать через ухудшение прогноза при исключении источника с переобучением; сравнения проводить на отложенном эксперименте, а не по встроенной impurity importance. Для знака использовать усреднённые локальные конечные разности предсказанной скорости при небольшом изменении source в области поддерживаемых данными значений; проверить несколько масштабов приращения. Если знак зависит от состояния или нестабилен, отмечать его как неопределённый. Ограничения: деревья имеют ступенчатые предсказания; коррелированные источники могут заменять друг друга; нелинейная важность сама по себе не доказывает прямую причинность.

Это разные классы моделей и способы выделения связей, но они используют одни данные: их согласие не равно независимой экспериментальной верификации.

### 2. Проверка без утечки между экспериментами

Получаются **245** переходов, строго по 49 внутри каждого из пяти экспериментов; переходов между последней точкой одного и первой точкой другого не будет. Основная внешняя проверка — leave-one-experiment-out, пять фолдов. Внутри четырёх обучающих экспериментов — отдельная групповая проверка для выбора регуляризации и сложности деревьев. Масштабирование, отбор признаков и любые обучаемые преобразования выполняются заново внутри фолда. Случайного разделения отдельных соседних точек не будет. Базовый вариант не требует сглаживания, исключая использование будущих точек при вычислении предикторов.

На внешних фолдах сравнить ошибку прогноза приращений, R² и преимущество перед персистентностью (`Δx=0`) и моделью только собственной динамики. R² приводить с оговоркой о слабой вариабельности; ошибки также нормировать масштабом target, оценённым на обучении. Представить распределение результатов по экспериментам, а не считать 245 переходов независимыми репликами.

Оценки исключения источника на внешних фолдах будут внутренним свидетельством для выбора сети; качество окончательно выбранной по этим данным сети нельзя объявлять независимой тестовой оценкой. Для устойчивости использовать исключение целых экспериментов и ограниченный bootstrap целых экспериментов; не перемешивать временные точки. При всего пяти экспериментах интервалы устойчивости являются описательными.

### 3. Стационарные профили при неизвестных вмешательствах

**Номер строки не будет идентификатором гена, цели или механизма вмешательства.** Из стационарных отклонений нельзя непосредственно получить ориентированные причинные эффекты, а знак корреляции не равен знаку регуляции. Не буду подгонять все изменённые состояния под условие нулевой скорости исходной wild-type модели: вмешательство могло изменить само уравнение target.

Предлагаю использовать эти данные отдельно как слабую, неориентированную проверку совместной вариабельности: базовые отклонения, устойчивые попарные ассоциации и чувствительность этих ассоциаций к исключению каждого условия. Сопоставить пары в итоговой сети с этой поддержкой, но **не менять на её основании ориентацию, знаки или основной confidence**. Это сознательный консервативный выбор, не требующий недокументированного допущения о точечных вмешательствах. Такая проверка не является причинной валидацией; отсутствие ассоциации также не опровергает связь. Неустойчивость особенно ожидаема при 16 профилях на 25 генов.

### 4. Сравнение, объединение и порог

Для каждого метода сохранить прогнозные proxy-метрики, устойчивость, сильные стороны и ограничения. Дополнительно сравнить ранги направленных рёбер, пересечение top-k и согласие определённых знаков.

Привести оценки обоих методов к сопоставимому диапазону [0,1], не превращая нулевые/неположительные свидетельства в сильные связи. Основной вариант — равновесное объединение нормированных оценок, умноженных на их воспроизводимость; сравнить чувствительность с каждым методом отдельно. Не называть confidence калиброванной вероятностью причинности.

Порог выбирать по заранее ограниченной сетке плотностей **5%, 10%, …, 40%** (30–240 из 600 возможных внедиагональных рёбер), используя устойчивость topology и внутреннюю групповую ошибку моделей с ограниченным набором родителей. Предпочитать наиболее разреженный вариант в пределах одной стандартной ошибки от лучшего внутреннего прогнозного результата, учитывая нестабильность этой ошибки при малом числе групп. Любая настройка порога для оценки качества выполняется внутри обучающей части; финальный порог затем выбирается по всем данным той же процедурой. Если для минимальной плотности не хватает содержательно положительных свидетельств, явно сообщить это ограничение, а не объявлять слабые рёбра доказанными. Равенства разрешать детерминированно.

Знаки вычислять только для сохранённых рёбер: согласованный и воспроизводимый знак → +1 или −1; конфликт методов, смена знака по состояниям или недостаточная поддержка → 0. Отсутствующая связь всегда имеет знак 0. Диагонали обоих массивов — 0. Матрица confidence неотрицательная; знак хранится отдельно.

### 5. Два регулятора и структурные метрики

Во всех операциях использовать **[target, source]**. После единственного окончательного порога `A=(inferred_network != 0)`:
- `n_edges=A.sum()`, `density=n_edges/600`;
- in-degree — суммы строк, out-degree — суммы столбцов;
- представить степени каждого гена, среднее, SD, минимум и максимум, при необходимости взаимность и компоненты связности;
- выбрать ровно два различных регулятора по сумме исходящего confidence (сумма столбца); при равенстве — по out-degree, затем индексу. Привести чувствительность рейтинга к методу/порогу. Это операционное определение влияния, не доказательство силы биологического вмешательства.

Все знаки, hubs и метрики используют **ту же точную пороговую topology**; никаких скрытых дополнительных порогов для метрик.

## Существенные допущения и неопределённости

Предполагается общая wild-type динамика между экспериментами и достаточная информативность наблюдаемого состояния для одношагового прогноза. Неизвестны задержки регуляции, величина/структура шума, скрытые регуляторы, истинная функциональная форма, число прямых связей и разнообразие начальных условий. Близость средних траекторий делает эффективное разнообразие режимов отдельной диагностикой будущего анализа. Наблюдательные временные данные могут путать прямые и косвенные воздействия, общую причину и взаимную регуляцию; шаг дискретизации может скрывать быстрые связи.
