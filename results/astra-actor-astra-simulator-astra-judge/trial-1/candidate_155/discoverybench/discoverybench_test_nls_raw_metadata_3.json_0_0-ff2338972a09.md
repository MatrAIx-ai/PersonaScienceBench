3. **学业特征**：四项ASVAB可在同一分析样本内分别重新标准化后等权平均为测验综合分，不称其为官方AFQT；同时检查分项结果。班级表现拟定义为 `1−(rank−1)/(class_size−1)`，高值表示靠前，仅在名次方向获确认且1≤rank≤人数、人数>1时使用。该定义是拟议转换，不是文件已有字段。
