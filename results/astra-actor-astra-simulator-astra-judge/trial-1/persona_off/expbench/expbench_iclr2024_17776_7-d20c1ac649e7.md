## 3. Models and comparison rationale

## 5. Primary condition: matched source content
### Budgets
For each model m, verify total sequence limit L_m. Fix a maximum new-token budget G_m before final evaluation, leaving input allowance L_m − G_m including all tokenizer-added special tokens. For a verified short completion task, a proposed initial budget is 128 new tokens for each model; for a different target unit, set a suitable budget using official rules or development-only checks. Equal token caps are an operational control, not equal output length in source characters. Report cap hits and consider a separately preregistered higher-budget sensitivity analysis if development checks show the cap is binding.

### Shared prompt construction
Construct one canonical prompt text per example using only authorized context and the verified template. Both models receive exactly that text, even though token IDs and token counts differ. Do not pad the smaller prompt with extra source information or truncate independently per tokenizer.

Where official rules prescribe context selection and truncation, implement them first. For the controlled variant, define an outcome-independent removal ladder when the resulting prompt does not fit both allowances:
