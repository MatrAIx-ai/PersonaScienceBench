Convert the rotational speed of 10,000 RPM to angular velocity omega in radians per second.
The angular velocity equals 10000 multiplied by 2 pi divided by 60, which simplifies to 1000 pi divided by 3 radians per second.
Use the differential radial equilibrium equation dP/dr = rho * r * omega^2 for the rotating fluid element.
Treat fluid density rho as an unspecified symbolic variable.
Integrate the differential equation with respect to radius r from reference radius r_0 to r.
Set the boundary condition such that pressure at radius r_0 is reference pressure P_0.
Express the final pressure distribution as P(r) = P_0 + (1/2) * rho * omega^2 * (r^2 - r_0^2).
Substitute the numerical angular velocity so the final formula is P(r) = P_0 + (1/2) * rho * (1000 * pi / 3)^2 * (r^2 - r_0^2).
Note that if the reference radius is at the axis of rotation r_0 = 0, the equation simplifies to P(r) = P_0 + (1/2) * rho * (1000 * pi / 3)^2 * r^2.
