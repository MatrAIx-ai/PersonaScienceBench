Simulate a two-dimensional lid-driven cavity flow using the OpenFOAM solver icoFoam.
Construct a square cavity domain with dimensions of 0.1 m by 0.1 m in the x and y directions.
Generate a uniform Cartesian mesh with 20 cells in the x-direction and 20 cells in the y-direction using blockMesh.
Configure the front and back patches as empty type to enforce a two-dimensional domain.
Set the kinematic viscosity nu to 0.001 m²/s in constant/transportProperties for a Reynolds number of 100.
Set the top wall boundary condition to a fixed velocity of 1 m/s in the positive x-direction.
Set the bottom, left, and right wall boundary conditions to fixed no-slip walls with zero velocity.
Set kinematic pressure boundary conditions to zeroGradient on all solid walls.
Configure system/controlDict with startTime set to 0.
Configure system/controlDict with deltaT set to 0.002 seconds.
Configure system/controlDict with endTime set to 0.5 seconds.
Execute blockMesh to generate the grid.
Execute icoFoam to perform the transient fluid flow simulation.
