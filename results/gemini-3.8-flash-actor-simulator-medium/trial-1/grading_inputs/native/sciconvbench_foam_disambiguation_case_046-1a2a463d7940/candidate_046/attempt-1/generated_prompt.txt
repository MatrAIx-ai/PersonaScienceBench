Simulate a two-dimensional lid-driven cavity flow using OpenFOAM.
Use the icoFoam solver for incompressible, laminar, isothermal flow.
The geometry is a square cavity of length 0.1 m and height 0.1 m, with an extrusion thickness of 0.01 m in the z-direction.
Generate a uniform Cartesian blockMesh with 20 cells in the x-direction, 20 cells in the y-direction, and 1 cell in the z-direction.
Set the top boundary movingWall to a fixed velocity of (1 0 0) m/s.
Set the bottom, left, and right walls to stationary no-slip boundaries with fixed velocity of (0 0 0) m/s.
Set the front and back boundaries to the empty boundary condition type for two-dimensional flow.
Set the pressure boundary condition to zeroGradient on all solid walls.
Set the fluid kinematic viscosity to 0.001 m2/s in constant/transportProperties to achieve a Reynolds number of 100.
Set the simulation startTime to 0 seconds in system/controlDict.
Set the simulation endTime to 0.5 seconds in system/controlDict.
Set the time step deltaT to 0.002 seconds in system/controlDict.
