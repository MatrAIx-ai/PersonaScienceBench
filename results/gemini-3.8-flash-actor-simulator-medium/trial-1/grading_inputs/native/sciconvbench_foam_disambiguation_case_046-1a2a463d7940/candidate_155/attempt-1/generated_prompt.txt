The simulation models a two-dimensional incompressible lid-driven cavity flow using OpenFOAM.
The simulation solver is icoFoam.
The cavity geometry has dimensions of 0.1 meters in the x direction and 0.1 meters in the y direction.
The computational domain has a depth of 0.01 meters in the z direction with a single cell thickness.
The grid is generated using blockMesh with a uniform Cartesian resolution of 20 cells in the x direction and 20 cells in the y direction.
The front and back boundaries in the z direction are assigned the empty boundary condition.
The bottom, left, and right cavity walls are configured as stationary no-slip walls with zero velocity.
The top lid wall moves in the positive x direction with a constant velocity of (1 0 0) meters per second.
The kinematic viscosity in constant/transportProperties is set to 0.001 square meters per second.
The resulting Reynolds number of the simulation is 100 based on the cavity length and lid velocity.
The startTime in system/controlDict is set to 0.
The endTime in system/controlDict is set to 0.5.
The time step deltaT is set to 0.002.
The writeControl is set to timeStep.
The writeInterval is set to 20.
