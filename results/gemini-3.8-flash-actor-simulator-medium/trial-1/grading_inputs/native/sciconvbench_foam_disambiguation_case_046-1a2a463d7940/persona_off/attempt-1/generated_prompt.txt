Simulate a 2D lid-driven cavity flow using OpenFOAM with the icoFoam solver.
Use blockMesh to generate a square domain of dimension 0.1 m by 0.1 m.
Create a uniform grid of 20 cells in the x-direction and 20 cells in the y-direction, with 1 cell in the z-direction.
Configure the front and back boundary patches as type empty to enforce a 2D domain.
Set the kinematic viscosity nu in the transportProperties file to 0.001 m2/s.
Apply a fixed velocity boundary condition of (1 0 0) m/s on the top moving wall.
Apply a no-slip velocity boundary condition of (0 0 0) m/s on the bottom, left, and right walls.
Set zeroGradient boundary conditions for pressure on all cavity walls.
Configure the simulation start time to 0 seconds.
Set the time step deltaT to 0.002 seconds.
Set the simulation end time to 0.5 seconds.
Set writeControl to timeStep and writeInterval to 20.
