Use the interFoam solver for a transient two-phase sloshing simulation of water and air.
Set the domain geometry to a rectangular tank with a length of 1.0 m in x, height of 0.6 m in y, and width of 0.1 m in z.
Set gravity to 9.81 m/s2 acting in the negative y direction with vector (0 -9.81 0).
Set the mesh resolution to 200 cells in x, 120 cells in y, and 1 cell in z for a 2D configuration, or 20 cells in z for a 3D configuration.
Set the left, right, and bottom boundaries as walls with noSlip velocity, fixedFluxPressure for p_rgh, and zeroGradient for alpha.water.
Set the top boundary as open to the atmosphere with pressureInletOutletVelocity for velocity, totalPressure with p0 set to 0 for p_rgh, and inletOutlet with inletValue 0 for alpha.water.
Set front and back boundaries to empty for the 2D configuration.
Set the turbulence simulation type to laminar in momentumTransport or turbulenceProperties.
Initialize the flow field with initial velocity U equal to (0 0 0) and p_rgh equal to 0.
Initialize alpha.water with a default value of 0 and set the water volume fraction to 1 using setFields with 10 staircase boxes along x.
Define each staircase box i from 0 to 9 over the x interval from 0.1 times i to 0.1 times (i plus 1) with water height hi equal to 0.255 plus 0.01 times i.
Set the simulation end time to 10 seconds.
Enable adjustable time stepping with adjustTimeStep set to yes.
Set the maximum Courant number maxCo to 0.5.
