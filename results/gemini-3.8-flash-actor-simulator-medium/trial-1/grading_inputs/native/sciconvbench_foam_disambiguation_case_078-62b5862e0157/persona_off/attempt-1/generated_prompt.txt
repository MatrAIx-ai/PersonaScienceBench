Simulate 2D transient sloshing in a rectangular tank using the OpenFOAM interFoam solver.
The computational domain has dimensions of 1.0 m in length along the x-axis, 0.6 m in height along the y-axis, and 0.1 m in depth along the z-axis.
Generate the mesh using blockMesh with 200 cells in the x-direction, 120 cells in the y-direction, and 1 cell in the z-direction.
Set the boundary type of the front and back patches to empty to enforce a 2D planar configuration.
Define the bottom, left, and right boundaries as rigid no-slip walls with zero normal gradient for pressure and zero flux for alpha.water.
Set the top boundary patch as an open atmosphere using pressureInletOutletVelocity for velocity, totalPressure with a value of 0 Pa for p_rgh, and inletOutlet with an inlet value of 0 for alpha.water.
Set standard gravity to 9.81 m/s^2 acting in the negative y-direction.
Use a laminar flow model with standard water and air physical transport properties.
Initialize fluid velocity to zero everywhere across the domain.
Initialize the free surface using setFields with water occupying the region below a line sloping linearly from a depth of 0.25 m at x = 0 m to 0.35 m at x = 1.0 m, and air occupying the remainder of the tank.
Run the transient simulation for a total physical time of 10 seconds.
Use adaptive time stepping constrained by a maximum Courant number suitable for free-surface VOF modeling.
