The simulation domain is a 2D axisymmetric cylindrical chamber with a length of 0.2 m and a diameter of 0.1 m.
The initial chamber pressure is set to 101325 Pa.
The initial air temperature inside the chamber is set to 800 K with standard atmospheric air composition.
The turbulence model is the standard k-epsilon model.
Liquid dodecane is injected through a cone injection model located at the center of the inlet boundary.
The fuel mass flow rate is set to 0.002 kg/s.
The spray cone angle is set to a standard value of 15 degrees.
Combustion is modeled using a two-step global reaction mechanism for dodecane.
Thermodynamic properties are calculated using the JANAF polynomial model.
The total physical simulation run time is 0.05 seconds.
