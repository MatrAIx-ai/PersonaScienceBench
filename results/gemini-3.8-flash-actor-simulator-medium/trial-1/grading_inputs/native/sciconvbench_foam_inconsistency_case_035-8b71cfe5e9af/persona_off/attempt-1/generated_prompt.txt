Use pimpleFoam to execute a transient, incompressible, laminar 2D simulation of flow past a cylinder.
Ensure the computational mesh is one cell thick in the spanwise direction.
Set the patch type for frontAndBack to empty in constant/polyMesh/boundary.
Set the boundary condition for frontAndBack to empty in 0/U.
Set the boundary condition for frontAndBack to empty in 0/p and any other 0/ field files.
Maintain existing configured boundary conditions for inlet, outlet, and cylinderWall.
