Simulate a compressible supersonic jet at Mach 2.0 discharging into an ambient reservoir using OpenFOAM.
Set the application to rhoCentralFoam in system/controlDict.
Model the flow as laminar using the Sutherland transport model and a perfect gas equation of state in constant/thermophysicalProperties.
Construct a 2D rectangular computational domain extending 0.2 meters in the x-direction and 0.1 meters in the y-direction, extruded one cell thick in the z-direction.
Set the nozzle inlet patch with a height of 0.01 meters centered along the minimum x boundary.
Set the front and back patches to type empty.
Apply fixedValue conditions at the nozzle inlet with velocity (686 0 0) m/s, temperature 300 K, and pressure 101325 Pa.
Apply noSlip velocity conditions and zeroGradient temperature and pressure conditions on solid wall boundaries.
Apply waveTransmissive boundary conditions for pressure and temperature, and zeroGradient for velocity, on the far-field and outlet boundaries.
Initialize the interior flow field to a stationary state with velocity (0 0 0) m/s, temperature 300 K, and pressure 101325 Pa.
Set adjustable time stepping in system/controlDict with a maximum Courant number of 0.2.
Run the simulation until the supersonic jet structure achieves a statistically steady shock and expansion pattern.
