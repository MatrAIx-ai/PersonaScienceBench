Simulate a high-speed compressible supersonic jet discharging into a larger quiescent domain using OpenFOAM.
Set the application solver to rhoCentralFoam in system/controlDict.
Construct a 2D computational domain with a length of 0.3 m along the x-axis, a height of 0.15 m along the y-axis, and an extrusion of 0.001 m across one single cell along the z-axis.
Configure a nozzle inlet patch on the left boundary with a height of 0.01 m.
Set the patch type of the front and back planes to empty.
Define the fluid thermophysical properties in constant/thermophysicalProperties using the hePsiThermo model with perfectGas equation of state and sutherland transport.
Set the simulation turbulence properties to laminar mode in constant/momentumTransport or constant/turbulenceProperties.
Apply fixedValue boundary conditions at the nozzle inlet with velocity U equal to (686 0 0) m/s, temperature T equal to 300 K, and pressure p equal to 101325 Pa.
Apply waveTransmissive boundary conditions for pressure p and temperature T on far-field and outlet boundaries.
Apply zeroGradient boundary conditions for velocity U on far-field and outlet boundaries.
Apply noSlip boundary conditions for velocity and zeroGradient for temperature and pressure on solid wall boundaries.
Configure system/controlDict to use adaptive time-stepping with a maximum Courant number of 0.2.
Set the total simulation end time to 0.002 seconds with appropriate output write intervals.
