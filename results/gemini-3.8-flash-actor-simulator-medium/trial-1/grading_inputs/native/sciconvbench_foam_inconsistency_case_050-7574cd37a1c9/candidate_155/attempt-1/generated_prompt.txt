Set up an OpenFOAM simulation using the rhoCentralFoam solver for a high-speed compressible supersonic jet.
Configure the computational domain as a two-dimensional domain extruded by one cell in the z-direction.
Assign the front and back patches the empty boundary type.
Configure the geometry with a nozzle inlet discharging into a larger computational domain.
Set the thermophysical properties in constant/thermophysicalProperties using hePsiThermo with perfectGas equation of state and sutherland transport.
Set the simulation turbulence properties to laminar mode.
Set the nozzle inlet boundary condition with fixed values of velocity at (686 0 0) m/s, temperature at 300 K, and static pressure at 101325 Pa.
Set the far-field and outlet boundary conditions using waveTransmissive for pressure and temperature, and zeroGradient for velocity.
Set solid wall boundaries to noSlip or slip conditions.
Configure system/controlDict to set the application name to rhoCentralFoam.
Configure time-stepping with a Courant number less than 1.0 to maintain numerical stability for explicit shock capturing.
