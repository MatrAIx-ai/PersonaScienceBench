Simulate a two-dimensional compressible supersonic jet discharging into an ambient domain using OpenFOAM.
Set the solver application to rhoCentralFoam in system/controlDict.
Generate a structured two-dimensional mesh extruded one cell thick in the z-direction with front and back boundaries assigned the empty type.
Define the nozzle inlet with a height of 0.02 meters discharging along the positive x-axis into a domain extending at least 0.5 meters downstream.
Configure the thermophysical model in constant/thermophysicalProperties using hePsiThermo, pureMixture, perfectGas equation of state, sensibleInternalEnergy, and Sutherland transport.
Set the working fluid properties to represent air treated as a perfect gas.
Set the turbulence simulation type to laminar in constant/momentumTransport or constant/turbulenceProperties.
Apply fixed value boundary conditions at the supersonic nozzle inlet with velocity U set to (686 0 0) m/s, static pressure p set to 101325 Pa, and temperature T set to 300 K.
Apply waveTransmissive boundary conditions for pressure and temperature, and zeroGradient for velocity, at the far-field and downstream outlet boundaries.
Apply noSlip boundary conditions for velocity and zeroGradient for pressure and temperature on solid wall boundaries.
Initialize the internal field across the domain with static pressure at 101325 Pa, temperature at 300 K, and velocity at (0 0 0) m/s.
Set the simulation end time to 0.005 seconds in system/controlDict with automatic time stepping enabled based on a maximum Courant number of 0.2.
