Configure an OpenFOAM simulation using the twoPhaseEulerFoam solver for steady-state two-phase oil-water flow.
Create a horizontal pipe geometry with an inner diameter of 0.05 m and a total length of 2.0 m oriented along the positive x-axis.
Generate a structured, three-dimensional computational mesh refined near the pipe walls to properly resolve boundary layers.
Set water density to 1000 kg/m3 and kinematic viscosity to 1e-6 m2/s in the phase properties dictionary.
Set oil density to 850 kg/m3 and kinematic viscosity to 1.176e-5 m2/s in the phase properties dictionary.
Set the interfacial surface tension between water and oil to 0.045 N/m.
Use the standard continuous-dispersed two-phase k-epsilon turbulence model with standard wall functions.
Set the inlet boundary condition for alpha.water to fixedValue uniform 0.3.
Set the inlet boundary condition for both phase velocity fields U.water and U.oil to fixedValue uniform (1 0 0) m/s.
Set the inlet boundary condition for modified pressure p_rgh to fixedFluxPressure.
Set the inlet boundary conditions for turbulent kinetic energy k and dissipation rate epsilon based on a 5 percent turbulence intensity and the hydraulic diameter.
Set the outlet boundary condition for alpha.water to zeroGradient.
Set the outlet boundary condition for phase velocities U.water and U.oil to zeroGradient.
Set the outlet boundary condition for modified pressure p_rgh to fixedValue uniform 0 Pa.
Set the outlet boundary conditions for k and epsilon to zeroGradient.
Set the pipe wall boundary condition for alpha.water to zeroGradient.
Set the pipe wall boundary condition for phase velocities U.water and U.oil to noSlip.
Set the pipe wall boundary condition for modified pressure p_rgh to fixedFluxPressure.
Apply kqRWallFunction for k and epsilonWallFunction for epsilon on all pipe walls.
Initialize internal fields to alpha.water uniform 0.3, phase velocities uniform (1 0 0) m/s, and modified pressure p_rgh uniform 0 Pa.
Configure fvSchemes using second-order bounded upwind schemes for convective divergence terms and standard linear orthogonal schemes for Laplacian terms.
Configure fvSolution using the PIMPLE algorithm set for steady-state convergence with residual tolerances of 1e-6 for all field variables.
Set an adjustable time step governed by a maximum Courant number of 0.8.
Run the simulation until residuals stabilize and mass flow balances between inlet and outlet are satisfied.
