Simulate steady-state two-phase oil and water flow in a horizontal circular pipe using the OpenFOAM solver twoPhaseEulerFoam.
Model the horizontal pipe with an internal diameter of 0.05 meters and a length of 2.0 meters aligned along the horizontal x-axis.
Generate a structured three-dimensional mesh with wall-normal refinement near the pipe wall.
Define the water phase with a density of 1000 kg/m3 and a kinematic viscosity of 1.0e-6 m2/s.
Define the oil phase with a density of 850 kg/m3 and a kinematic viscosity of 1.0e-5 m2/s.
Set the interfacial surface tension between oil and water to 0.03 N/m.
Apply the Schiller-Naumann drag model for interphase momentum exchange.
Set the inlet boundary condition for velocity to a uniform fixed value of 1.0 m/s in the axial direction for both phases.
Set the inlet boundary condition for alpha.water to a uniform fixed value of 0.3.
Set the inlet boundary condition for alpha.oil to a uniform fixed value of 0.7.
Set the outlet boundary condition for alpha.water to zeroGradient.
Set the outlet boundary condition for phase velocities to zeroGradient.
Set the outlet boundary condition for modified pressure p_rgh to a uniform fixed value of 0 Pa.
Set the wall boundary conditions for phase velocities to noSlip.
Set the wall boundary conditions for phase fractions to zeroGradient.
Apply the standard two-phase mixture k-epsilon turbulence model.
Execute the simulation until the phase distribution, velocity, and pressure fields reach a steady state.
