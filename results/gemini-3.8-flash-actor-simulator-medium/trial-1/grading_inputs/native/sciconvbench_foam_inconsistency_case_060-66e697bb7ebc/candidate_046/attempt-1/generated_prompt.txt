Use the interFoam solver for this classic two-dimensional dam-break simulation.
Set the application entry in system/controlDict to interFoam.
Set the simulation endTime in system/controlDict to 1 second.
Configure the computational domain to standard dimensions of 0.584 meters in length and 0.584 meters in height.
Generate a two-dimensional mesh extruded exactly one cell in the z-direction.
Assign the patch type empty to the frontAndBack boundaries.
Assign no-slip wall boundary conditions to the bottom and side boundaries.
Assign open atmospheric boundary conditions to the top boundary.
Set gravity to 9.81 meters per square second directed downward along the negative vertical axis.
Define fluid phase properties for water and air using standard canonical interFoam physical properties.
Initialize the default field value of alpha.water to 0 throughout the domain.
Use setFields to define a water column at the lower-left corner with a width of 0.1461 meters and a height of 0.292 meters.
Set alpha.water to 1 within the specified water column geometry.
