Set up the classic 2D dam-break case using the standard OpenFOAM damBreak tutorial configuration.
Set application to interFoam in system/controlDict.
Set endTime to 1.0 in system/controlDict.
Generate a 2D mesh representing a domain measuring 0.584 m in width by 0.584 m in height with an obstacle on the floor matching the standard tutorial geometry.
Extrude the mesh one cell thick in the z-direction.
Assign the front and back patches to type empty.
Define the top boundary as an open atmosphere boundary condition.
Define all walls and the obstacle as no-slip boundary conditions.
Configure fluid properties for water and air phases with standard constant values.
Use setFields to initialize a water column of width 0.146 m and height 0.292 m at the bottom corner of the domain.
Set alpha.water to 1 inside the water column box and 0 everywhere else in the domain.
Run the simulation using interFoam to capture the collapse of the water column and the evolution of the free surface.
