Simulate 2D natural convection in a square cavity based on the de Vahl Davis benchmark using OpenFOAM.
Set the square cavity side length to 0.1 m in the x and y directions.
Model the domain in two dimensions with an empty boundary condition on the front and back planes in the z direction.
Use buoyantBoussinesqPimpleFoam as the OpenFOAM solver.
Set the left wall boundary condition to fixedValue with a temperature of 300 K.
Set the right wall boundary condition to fixedValue with a temperature of 290 K.
Set the top and bottom wall boundary conditions for temperature to zeroGradient for adiabatic conditions.
Set all four walls to noSlip boundary conditions for velocity.
Set the gravitational acceleration vector to (0 -9.81 0) m/s2 pointing in the negative y direction.
Use the Boussinesq approximation for buoyancy with a reference temperature of 295 K.
Configure the laminar simulation with fluid properties matching air at a Prandtl number of 0.71 and a Rayleigh number of 100000.
Generate a structured orthogonal mesh of 100 by 100 cells in the x and y directions.
Run the simulation in transient mode with adaptive or appropriate time stepping until steady-state convergence is achieved.
