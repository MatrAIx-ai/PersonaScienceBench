Simulate natural convection in a two-dimensional square cavity based on the de Vahl Davis benchmark using OpenFOAM.
Use buoyantBoussinesqPimpleFoam as the simulation solver.
Set the side length of the square cavity to 0.1 m in both x and y dimensions.
Set the cavity to have a thickness of one cell in the z dimension with empty boundary conditions on the front and back planes.
Generate a structured uniform mesh with 50 cells in the x direction, 50 cells in the y direction, and 1 cell in the z direction.
Set the acceleration due to gravity to (0 -9.81 0) m/s^2.
Set the target Rayleigh number to 10^4 by configuring the fluid transport properties and thermal expansion coefficient accordingly.
Set the left wall boundary conditions to a fixed temperature of 300 K and a no-slip velocity condition.
Set the right wall boundary conditions to a fixed temperature of 290 K and a no-slip velocity condition.
Set the top and bottom walls to adiabatic with a zeroGradient boundary condition for temperature and a no-slip velocity condition.
Set the reference temperature for the Boussinesq approximation to 295 K.
Set the modified pressure p_rgh to fixedFluxPressure on all solid walls.
Run the simulation until steady-state flow and thermal fields are reached.
