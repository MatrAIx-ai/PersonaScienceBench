Q: What file format and structure are used for the defect entries inside the Mg_Ga directory?
A: Внутри папки `Mg_Ga` лежат поддиректории для каждого зарядового состояния (`[-2, -1, 0, 1]`). 

В каждой такой подпапке находятся стандартные сжатые файлы VASP:
- `vasprun.xml.gz`
- `LOCPOT.gz`

Их и нужно загружать для сборки `DefectEntry` (плюс bulk reference берется из `bulk_sc/LOCPOT.gz`, а диэлектрическая константа равна `14`).

Q: Which Pymatgen module or class should be used to construct the formation energy diagram and extract the chemical potential limits?
A: Для построения диаграммы формирования дефектов используется класс `FormationEnergyDiagram` из модуля `pymatgen.analysis.defects.thermo` (или `pymatgen.analysis.defects`). 

Общий пайплайн такой:
1. Строишь фазовую диаграмму с помощью `PhaseDiagram` из `pymatgen.analysis.phase_diagram` на основе стабильных элементных записей (atomic entries).
2. Собираешь объекты `DefectEntry` для зарядовых состояний.
3. Передаешь их в `FormationEnergyDiagram` (вместе с данными фазовой диаграммы / химпотенциалами и VBM из bulk vasprun).
4. Количество лимитов химических потенциалов (`chemical_potential_limits_count`) извлекается напрямую из объекта `FormationEnergyDiagram` (через его атрибут с лимитами химпотенциалов, например `chem_pot_limits` / `chemical_potentials` — это количество различных химических сред/границ).
