Q: What specific file formats and filenames are stored inside the `Mg_Ga` directory for the defect entries and bulk/band-edge data?
A: Inside the `Mg_Ga` defect-entry directory, each charge state subfolder contains `vasprun.xml.gz` and `LOCPOT.gz` files (for charge states `[-2, -1, 0, 1]`). 

For the bulk reference and band-edge data, you should use `bulk_sc/LOCPOT.gz` as the bulk reference LOCPOT, and the corresponding bulk `vasprun` (`bulk_sc/vasprun.xml.gz`) to obtain the VBM and the bulk entry.

Q: What value should be used for the dielectric constant if electrostatic finite-size corrections are applied?
A: A dielectric constant of `14` should be used for the Freysoldt finite-size corrections.

Q: Which pymatgen class or method should be used to determine the chemical potential limits from the stable entries?
A: You should build a `PhaseDiagram` (from `pymatgen.analysis.phase_diagram`) using the stable entries (collecting the elemental stable entries as atomic entries), and then construct the `FormationEnergyDiagram` (from `pymatgen.analysis.defects.thermodynamics`) using the charged defect entries, the phase diagram, and the band-edge data (VBM). 

The `FormationEnergyDiagram` object itself provides the chemical potential limits (via its `chempot_limits` property/attribute), from which you can count the number of limits.
