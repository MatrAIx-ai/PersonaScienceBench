Operate in the working directory data/relax/BaTiO3.
Create the INCAR file containing the specified relaxation parameters.
Set ALGO = Fast in INCAR.
Set EDIFF = 0.0005 in INCAR.
Set ENCUT = 520.0 in INCAR.
Set IBRION = 2 in INCAR.
Set ISIF = 3 in INCAR.
Set ISMEAR = -5 in INCAR.
Set ISPIN = 2 in INCAR.
Set LASPH = .TRUE. in INCAR.
Set LMAXMIX = 4 in INCAR.
Set LORBIT = 11 in INCAR.
Set LREAL = Auto in INCAR.
Set LWAVE = .FALSE. in INCAR.
Set MAGMOM = 39*-0.0 in INCAR.
Set NELM = 100 in INCAR.
Set NSW = 99 in INCAR.
Set PREC = Accurate in INCAR.
Set SIGMA = 0.05 in INCAR.
Copy INCAR to INCAR1 using the command cp INCAR INCAR1.
Execute the relaxation calculation by running bash run_vasp.sh.
Extract the optimized total energy by running python get_energy.py.
Report the final total energy exactly as output by get_energy.py.
