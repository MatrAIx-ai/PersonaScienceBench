The working directory is data/relax/BaTiO3.
Create the VASP input file INCAR with ALGO set to Fast.
Set EDIFF to 0.0005 in INCAR.
Set ENCUT to 520.0 in INCAR.
Set IBRION to 2 in INCAR.
Set ISIF to 3 in INCAR.
Set ISMEAR to -5 in INCAR.
Set ISPIN to 2 in INCAR.
Set LASPH to .TRUE. in INCAR.
Set LMAXMIX to 4 in INCAR.
Set LORBIT to 11 in INCAR.
Set LREAL to Auto in INCAR.
Set LWAVE to .FALSE. in INCAR.
Set MAGMOM to 39*-0.0 in INCAR.
Set NELM to 100 in INCAR.
Set NSW to 99 in INCAR.
Set PREC to Accurate in INCAR.
Set SIGMA to 0.05 in INCAR.
Execute the calculation by running the bash command bash run_vasp.sh.
Copy the INCAR file to INCAR1 using the command cp INCAR INCAR1.
Execute python get_energy.py to extract the optimized total energy.
Report the final optimized total energy exactly as output by get_energy.py.
