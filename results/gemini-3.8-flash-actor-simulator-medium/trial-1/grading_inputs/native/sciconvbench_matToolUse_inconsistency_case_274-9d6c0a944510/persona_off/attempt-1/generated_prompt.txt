Operate inside the working directory data/relax/BaTiO3.
Create the VASP input file INCAR with the parameters ALGO = Fast, EDIFF = 0.0005, ENCUT = 520.0, IBRION = 2, ISIF = 3, ISMEAR = -5, ISPIN = 2, LASPH = .TRUE., LMAXMIX = 4, LORBIT = 11, LREAL = Auto, LWAVE = .FALSE., MAGMOM = 39*-0.0, NELM = 100, NSW = 99, PREC = Accurate, and SIGMA = 0.05.
Run the VASP calculation by executing bash run_vasp.sh.
Save a copy of the INCAR file as INCAR1 by executing cp INCAR INCAR1.
Execute python get_energy.py to extract the final total energy after relaxation.
Return the optimized total energy value exactly as printed by get_energy.py.
