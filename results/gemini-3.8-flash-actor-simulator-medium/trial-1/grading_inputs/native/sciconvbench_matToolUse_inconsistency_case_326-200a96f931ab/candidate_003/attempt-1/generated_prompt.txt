Navigate to the working directory data/bandgap/MoS2.
Create an INCAR file configured for a standard PBE self-consistent ground state calculation with wave function and charge density writing enabled.
Execute the PBE ground state calculation by running bash run_vasp.sh.
Save a copy of the PBE INCAR file by running cp INCAR INCAR1.
Create a new INCAR file for the HSE06 hybrid functional calculation using the parameters provided in the task specification.
Set ISTART to 1 to read the wave functions from the PBE calculation.
Set ICHARG to a value less than or equal to 10 to recalculate the charge density from the wave functions.
Ensure that MAGMOM, NBANDS, and NELECT are not set in the HSE INCAR file.
Execute the HSE calculation by running bash run_vasp.sh.
Save a copy of the HSE INCAR file by running cp INCAR INCAR2.
Run python gap.py to evaluate the band structure and compute the band gap.
Return the band gap value exactly as printed by gap.py.
