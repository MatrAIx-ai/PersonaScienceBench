Task ID is molk_006.
Solve the 3-state neural dynamics toy model ODE system for unknown state variables E, I, and H as functions of time t.
The governing equations are dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t), dI/dt = delta*E - epsilon*I, and dH/dt = theta*I - phi*H.
Trigonometric arguments are evaluated in radians.
The time domain is t in [0.0, 50.0].
The initial conditions at t = 0.0 are E(0.0) = 0.5, I(0.0) = 0.2, and H(0.0) = 0.1.
The system parameters are alpha = 1.2, beta = 1.0, gamma = 0.5, delta = 0.8, epsilon = 0.7, theta = 0.9, and phi = 0.4.
Integrate the system using the classical 4th-order Runge-Kutta (RK4) method with a fixed time step dt = 0.01 for Nt = 5000 steps.
Compute and store the full state vector at each discrete time point t_n = 0.0 + n*dt for n from 0 to Nt inclusive.
Save the results into a file named solution_molk_006.npz containing the 1D array t of length Nt+1, the 2D array Y of shape (Nt+1, 3) with column ordering [E, I, H], and all scalar parameters.
Generate and save line plots of each state variable versus time t in an image file named solution_molk_006.png.
Print the final values of E, I, and H at the final time t = 50.0.
Print the minimum and maximum values of each state variable across the entire time trajectory.
