Simulate the 1D Compressible Navier-Stokes equations without heat conduction for unknown fields rho, v, and p over the spatial domain x in [-1, 1] and time interval t in [0, 0.5].
Set the adiabatic index Gamma to 1.6666666666666667.
Set the dynamic shear viscosity eta to 0.1 and the bulk viscosity zeta to 0.1.
Use a uniform cell-centered finite-volume grid with Nx = 400 cells and cell size dx = 0.005.
Define the cell centers as x_j = -1 + (j + 0.5) * dx for j = 0, ..., Nx - 1.
Initialize the primitive fields on the cell centers at t = 0 as rho = 1.0 + 0.2 * sin(pi * x), v = 0.1 * cos(pi * x), and p = 1.0 + 0.2 * cos(pi * x).
Compute the initial conserved variables as rho, m = rho * v, and E = p / (Gamma - 1) + 0.5 * rho * v^2.
Apply periodic boundary conditions at x = -1 and x = 1 by wrapping indices across the grid boundaries.
Evaluate pressure using the equation of state p = (Gamma - 1) * (E - 0.5 * m^2 / rho).
Enforce positivity of density and pressure by clipping rho and p to a minimum floor of 1e-12 at every stage.
Compute the convective numerical interface flux using the Rusanov local Lax-Friedrichs scheme with local maximum wave speed a = max(|v_L| + c_L, |v_R| + c_R), where the sound speed is c = sqrt(Gamma * p / rho).
Compute cell-centered velocity derivatives v_x using central differences with periodic boundary wrapping.
Compute cell-centered viscous stress as sigma = (zeta + 4.0 / 3.0 * eta) * v_x.
Interpolate sigma and v to cell interfaces by arithmetic averaging of adjacent cell-centered values.
Form the viscous interface flux as [0, -sigma, -v * sigma] and add it to the convective interface flux to obtain the total interface flux.
Integrate in time using the two-stage SSP-RK2 Heun method.
Set the CFL number to 0.5.
Calculate the convective time step limit as dt_conv = CFL * dx / max(|v| + c).
Calculate the viscous time step limit as dt_visc = 0.5 * dx^2 / (zeta + 4.0 / 3.0 * eta).
Select the time step dt as the minimum of dt_conv and dt_visc, adjusting the final time step so the simulation terminates exactly at t = 0.5.
