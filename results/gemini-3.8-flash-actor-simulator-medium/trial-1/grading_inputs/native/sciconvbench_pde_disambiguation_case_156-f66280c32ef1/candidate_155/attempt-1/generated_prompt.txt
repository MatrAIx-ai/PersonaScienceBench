Simulate the 1D compressible Navier-Stokes equations without heat conduction for unknown fields rho(x,t), v(x,t), and p(x,t) on the domain x in [-1, 1] from t = 0 to t = 0.5.
Set the physical parameters to Gamma = 1.6666666666666667, eta = 0.1, and zeta = 0.1.
Use a uniform cell-centered finite-volume grid with Nx = 400 cells, grid spacing dx = 0.005, and cell center coordinates x_j = -1 + (j + 0.5) * dx for j = 0 to Nx - 1.
Apply periodic boundary conditions at x = -1 and x = 1 by wrapping indices across domain boundaries.
Initialize the cell-centered fields at t = 0 using rho(x,0) = 1.0 + 0.2*sin(pi*x), v(x,0) = 0.1*cos(pi*x), and p(x,0) = 1.0 + 0.2*cos(pi*x).
Define the conservative state vector as U = [rho, m, E] where momentum m = rho * v and total energy E = p / (Gamma - 1) + 0.5 * rho * v^2.
Evaluate the equation of state as p = (Gamma - 1) * (E - 0.5 * m^2 / rho), enforcing positivity by clipping rho and p to a lower threshold of 1e-12.
Calculate interface convective fluxes using the Rusanov numerical flux F_hat = 0.5 * (F_conv(U_L) + F_conv(U_R)) - 0.5 * a * (U_R - U_L), where F_conv(U) = [m, m^2/rho + p, (E+p)*v] and wave speed a = max(|v_L| + c_L, |v_R| + c_R) with sound speed c = sqrt(Gamma * p / rho).
Compute the velocity derivative v_x at cell centers using centered differences with periodic wrapping.
Compute the cell-centered viscous stress as sigma = (zeta + 4.0 / 3.0 * eta) * v_x.
Evaluate the interface viscous flux as F_visc = [0, -sigma_interface, -v_interface * sigma_interface], where sigma_interface and v_interface are arithmetic averages of neighboring cell-centered values.
Sum the convective and viscous fluxes to obtain the total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete conservative system in time using the two-stage SSP-RK2 Heun method.
Set the CFL parameter to 0.5.
Determine the time step at each iteration by dt = min(dt_conv, dt_visc) where dt_conv = CFL * dx / max_j(|v_j| + c_j) and dt_visc = 0.5 * dx^2 / (zeta + 4.0 / 3.0 * eta), adjusting the final step to terminate exactly at T = 0.5.
