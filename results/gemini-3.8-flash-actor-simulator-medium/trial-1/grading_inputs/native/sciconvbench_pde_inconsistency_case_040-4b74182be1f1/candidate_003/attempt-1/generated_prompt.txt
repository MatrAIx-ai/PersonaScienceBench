Solve the 2D heat equation u_t = 0.05 * (u_xx + u_yy) for unknown field u(x,y,t).
The spatial domain is [0, 1) x [0, 1) with periodic boundary conditions along both x and y axes.
The temporal domain is t in [0, 0.5].
Discretize the spatial domain with Nx = 64 and Ny = 64 uniform grid points without duplicated endpoints, where dx = 1.0 / 64, dy = 1.0 / 64, x_i = i * dx for i = 0 to 63, and y_j = j * dy for j = 0 to 63.
Set the initial condition at t = 0 to u(x, y, 0) = cos(2 * pi * x) + sin(2 * pi * y).
Use second-order central finite differences with periodic wrap-around to construct the 2D periodic Laplacian operator matrix L.
Advance the solution in time using the Crank-Nicolson scheme with a constant time step dt = 0.0025 for 200 steps to reach final time T = 0.5.
At each time step, solve the linear system (I - 0.5 * dt * 0.05 * L) u^{n+1} = (I + 0.5 * dt * 0.05 * L) u^n using a sparse direct solver.
Evaluate the exact reference solution u(x, y, T) = exp(-0.05 * (2 * pi)^2 * T) * cos(2 * pi * x) + exp(-0.05 * (2 * pi)^2 * T) * sin(2 * pi * y) on the same grid at T = 0.5.
Compute the discrete L2 norm of the numerical solution at T defined as sqrt(sum(u^2) * dx * dy).
Compute the maximum absolute error and discrete L2 error between the numerical solution and the reference solution at T = 0.5.
Print the minimum value of u, maximum value of u, discrete L2 norm of u, maximum absolute error, and L2 error at T = 0.5.
Save the results into a file named solution_agent_heat_11.npz containing 1D arrays x and y, 2D array u with shape (len(y), len(x)) such that u[j, i] = u(x[i], y[j]), and scalar metadata T, dx, dy, and dt.
