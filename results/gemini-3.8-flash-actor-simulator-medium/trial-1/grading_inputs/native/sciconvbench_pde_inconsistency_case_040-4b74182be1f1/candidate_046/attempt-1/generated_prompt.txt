Solve the two-dimensional heat equation u_t = 0.05 * (u_xx + u_yy) for unknown field u(x,y,t).
The spatial domain is [0,1) x [0,1) with periodic boundary conditions along both x and y directions.
The time domain is t from 0 to 0.5.
The thermal diffusivity parameter alpha is 0.05.
The initial condition is u(x,y,0) = cos(2*pi*x) + sin(2*pi*y).
The reference exact solution is u(x,y,t) = exp(-0.05*(2*pi)^2*t)*cos(2*pi*x) + exp(-0.05*(2*pi)^2*t)*sin(2*pi*y).
Discretize the spatial domain with Nx = 64 and Ny = 64 grid points where dx = 1/Nx, dy = 1/Ny, x_i = i*dx for i from 0 to Nx-1, and y_j = j*dy for j from 0 to Ny-1.
Approximate spatial derivatives using second-order central differences with periodic boundary wrap-around.
Advance in time using the Crank-Nicolson method with time step dt = 0.0025 across exactly 200 time steps to reach T = 0.5.
Assemble the sparse matrix for the two-dimensional periodic Laplacian L and solve (I - 0.5*dt*alpha*L) u^{n+1} = (I + 0.5*dt*alpha*L) u^n at each step using a sparse direct solver.
Compute the numerical solution u(x,y,T=0.5) on the grid.
Save the solution to a file named solution_agent_heat_11.npz containing 1D array x, 1D array y, 2D array u with shape (len(y), len(x)) such that u[j,i] corresponds to u(x[i], y[j]), and scalar metadata T, dx, dy, dt.
Save a heatmap or contour plot of u(x,y,T) to a file named solution_agent_heat_11.png.
Print the minimum value of u, the maximum value of u, and the discrete L2 norm defined as sqrt(sum(u^2)*dx*dy) at T = 0.5.
Compute and print the maximum absolute error and discrete L2 error between the numerical solution and the reference exact solution evaluated on the same grid at T = 0.5.
