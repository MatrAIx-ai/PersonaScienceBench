The task is to solve the two-dimensional heat equation u_t = 0.05 * (u_xx + u_yy) numerically.
The spatial domain is x in [0, 1] with Dirichlet boundary conditions and y in [0, 1) with periodic boundary conditions.
The boundary conditions in x are u(0, y, t) = 0 and u(1, y, t) = 0.
The boundary conditions in y are periodic such that u(x, 0, t) = u(x, 1, t) and u_y matches across the boundaries.
The initial condition is u(x, y, 0) = sin(pi * x) * cos(2 * pi * y).
The spatial grid uses Nx = 60 intervals for x resulting in 61 grid points, and Ny = 64 periodic grid points for y on [0, 1).
Spatial derivatives are discretized using second-order central differences.
Time integration is performed using the Implicit Euler scheme with time step dt = 0.001 for 300 steps up to final time T = 0.3.
The numerical solution u(x, y, T) is computed on the 2D grid.
Save the solution to a file named solution_agent_heat_16.npz containing 1D array x, 1D array y, 2D array u with shape (len(y), len(x)), and metadata scalars T, dx, dy, and dt.
Save a heatmap or contour plot of u(x, y, T) as solution_agent_heat_16.png.
Print the minimum value of u, the maximum value of u, and the discrete L2 norm computed as sqrt(sum(u^2) * dx * dy) at time T.
Compute and print the maximum absolute error and L2 error compared to the exact solution u(x, y, t) = exp(-0.05 * (pi^2 + (2 * pi)^2) * t) * sin(pi * x) * cos(2 * pi * y) evaluated on the same grid at time T.
