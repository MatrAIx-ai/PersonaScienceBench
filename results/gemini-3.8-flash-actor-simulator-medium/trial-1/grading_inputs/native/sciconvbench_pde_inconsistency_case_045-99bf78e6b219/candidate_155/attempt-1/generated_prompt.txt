The task is to solve the 2D heat equation u_t = 0.05 * (u_xx + u_yy) numerically.
The spatial domain is x in [0, 1] and y in [0, 1), with time t in [0, 0.3].
Boundary conditions are homogeneous Dirichlet at x = 0 and x = 1 such that u(0, y, t) = 0 and u(1, y, t) = 0.
Boundary conditions along the y direction are periodic such that u(x, 0, t) = u(x, 1, t) and u_y is continuous across the boundary.
The initial condition is u(x, y, 0) = sin(pi * x) * cos(2 * pi * y).
The exact reference solution is u(x, y, t) = exp(-0.05 * (pi^2 + (2 * pi)^2) * t) * sin(pi * x) * cos(2 * pi * y).
Discretize the x domain using Nx = 60 uniform intervals, resulting in 61 grid points with spacing dx = 1 / 60.
Discretize the periodic y domain using Ny = 64 uniform grid points with spacing dy = 1 / 64 on [0, 1).
Use second-order central differences for spatial derivatives with periodic wrapping along y and Dirichlet enforcement along x.
Use the Implicit Euler method for time integration with time step dt = 0.001.
Advance the solution for exactly 300 time steps to reach final time T = 0.3.
Save the final numerical result to a file named solution_agent_heat_16.npz.
The npz file must include 1D array x, 1D array y, 2D array u with shape (len(y), len(x)) where u[j, i] corresponds to u(x[i], y[j]), and scalars T, dx, dy, dt.
Save a heatmap or contour plot of u(x, y, T) to a file named solution_agent_heat_16.png.
Print the minimum value of u, the maximum value of u, and the discrete L2 norm calculated as sqrt(sum(u^2) * dx * dy) at time T = 0.3.
Compute and print the maximum absolute error and discrete L2 error between the numerical solution and the reference solution on the grid at time T = 0.3.
