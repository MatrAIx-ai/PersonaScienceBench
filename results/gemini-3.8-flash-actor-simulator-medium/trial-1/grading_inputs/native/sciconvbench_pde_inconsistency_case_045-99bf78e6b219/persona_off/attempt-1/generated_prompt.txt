Apply periodic boundary conditions along the y boundaries such that u(x,0,t) = u(x,1,t) and u_y matches across y = 0 and y = 1.
Set the initial condition to u(x,y,0) = sin(pi * x) * cos(2 * pi * y).
Discretize the x domain using Nx = 60 intervals yielding 61 grid points with spacing dx = 1 / 60.
Discretize the periodic y domain using Ny = 64 grid points with spacing dy = 1 / 64.
Use second-order central differences for spatial derivatives.
Integrate in time from t = 0 to T = 0.3 using the Implicit Euler method with a time step of dt = 0.001 across 300 steps.
Compute the numerical solution u(x, y, T = 0.3) on the full grid.

Save a heatmap or contour plot of u(x, y, T) to an image file named solution_agent_heat_16.png.
Print the minimum value of u, the maximum value of u, and the discrete L2 norm computed as sqrt(sum(u**2) * dx * dy) at T = 0.3.
