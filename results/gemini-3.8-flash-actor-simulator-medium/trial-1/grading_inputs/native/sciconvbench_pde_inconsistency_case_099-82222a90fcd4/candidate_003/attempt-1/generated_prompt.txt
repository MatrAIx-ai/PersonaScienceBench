Solve the 1D wave equation u_tt = c^2 * u_xx numerically with wave speed c = 1.0.
The spatial domain is x in [0, 1] and the time domain is t in [0, 1.0].
The spatial domain is discretized into Nx = 800 uniform intervals with Nx + 1 grid points, yielding grid spacing dx = 1.0 / Nx.
The initial conditions are u(x, 0) = exp(-200 * (x - 0.5)**2) and u_t(x, 0) = 0.
The boundary conditions are homogeneous Dirichlet at x = 0 and x = 1, setting u(0, t) = 0 and u(1, t) = 0 for all time steps.
The spatial derivative u_xx is approximated using standard second-order central finite differences in the interior.
The time integration is performed using the second-order central difference leapfrog scheme.
The time step is determined by dt0 = 0.9 * dx / c, Nt = ceil(1.0 / dt0), and dt = 1.0 / Nt so that the final time T = 1.0 is reached exactly.
The solution at the first time step u^1 is computed via the second-order Taylor expansion u^1 = u^0 + dt * u_t(x, 0) + 0.5 * dt^2 * c^2 * u_xx^0.
At the final time T = 1.0, evaluate the solution u(x, T).
Save the solution to a file named solution_agent_wave_18.npz containing the 1D array x, the 1D array u, and the metadata scalars T, dx, and dt.
Save a line plot of u(x, T) versus x as solution_agent_wave_18.png.
Print the minimum value of u, the maximum value of u, and the discrete L2 norm defined as sqrt(sum(u**2) * dx) at time T = 1.0.
