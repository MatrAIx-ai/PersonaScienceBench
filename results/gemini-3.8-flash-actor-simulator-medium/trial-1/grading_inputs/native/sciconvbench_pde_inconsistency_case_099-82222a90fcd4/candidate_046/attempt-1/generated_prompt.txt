The task is to numerically solve the 1D wave equation u_tt = c^2 * u_xx.
Set the wave propagation speed parameter to c = 1.0.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 1.0].
Apply homogeneous Dirichlet boundary conditions u(0, t) = 0 and u(1, t) = 0 for all t.
Set the initial conditions to u(x, 0) = exp(-200 * (x - 0.5)^2) and u_t(x, 0) = 0.
Discretize the spatial domain using a uniform grid with Nx = 800 intervals and Nx + 1 grid points where dx = 1.0 / Nx and x_i = i * dx.
Discretize spatial second derivatives using standard second-order central differences at interior points.
Compute the baseline time step dt0 = 0.9 * dx / c.
Determine the total number of time steps as Nt = ceil(1.0 / dt0) and set the exact time step dt = 1.0 / Nt.
Initialize the first time step u^1 using a second-order Taylor expansion u^1 = u^0 + 0.5 * dt^2 * c^2 * u_xx^0 with boundary values enforced to 0.
Advance the solution in time up to T = 1.0 using the standard second-order central difference leapfrog scheme u^(n+1) = 2 * u^n - u^(n-1) + dt^2 * c^2 * u_xx^n at interior points.
Enforce the Dirichlet boundary conditions at both boundary nodes at every time step.
Compute the final solution u(x, T) at T = 1.0.
Save the results to a file named solution_agent_wave_18.npz containing 1D array x, 1D array u, and scalars T, dx, and dt.
Save a line plot of u(x, T) versus x to a file named solution_agent_wave_18.png.
Print the scalar diagnostics min(u), max(u), and the discrete L2 norm computed as sqrt(sum(u^2) * dx) at T = 1.0.
