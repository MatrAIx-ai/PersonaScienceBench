Solve the 1D wave equation u_tt = c^2 * u_xx with wave speed c = 1.0.
The spatial domain is x in [0, 1] and the temporal domain is t in [0, 1.0].
The boundary conditions are homogeneous Dirichlet u(0, t) = 0 and u(1, t) = 0 for all t.
The initial conditions are u(x, 0) = exp(-200 * (x - 0.5)^2) and u_t(x, 0) = 0.
Discretize the spatial domain into Nx = 800 uniform intervals with Nx + 1 points so that dx = 1.0 / Nx and x_i = i * dx for i = 0 to Nx.
Compute the initial time step base dt0 = 0.9 * dx / c.
Set the number of time steps Nt = ceil(1.0 / dt0) and the exact time step dt = 1.0 / Nt to hit T = 1.0 exactly.
Use standard second-order central differences for the spatial derivative u_xx at interior points.
Initialize step 0 with u^0 = u(x, 0).
Initialize step 1 using the Taylor expansion u^1 = u^0 + 0.5 * dt^2 * c^2 * u_xx^0 with boundary values set to 0.
Advance the solution in time using the second-order central difference leapfrog scheme u^(n+1) = 2 * u^n - u^(n-1) + dt^2 * c^2 * u_xx^n for interior points.
Enforce Dirichlet boundary conditions u = 0 at x = 0 and x = 1 at each time step.
Compute the final solution u(x, T) at T = 1.0.
Save the final arrays x and u along with metadata scalars T, dx, and dt into a file named solution_agent_wave_18.npz.
Save a line plot of u(x, T) versus x to a file named solution_agent_wave_18.png.
