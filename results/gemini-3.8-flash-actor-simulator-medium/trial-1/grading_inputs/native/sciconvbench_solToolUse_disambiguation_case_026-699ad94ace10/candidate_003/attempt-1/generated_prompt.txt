Use legacy FEniCS (dolfin) to implement a small-strain 2D linear elasticity solver under the plane-stress assumption with unit thickness.
Define the geometry as a right triangular domain with vertices at (0, 0), (1, 0), and (0, 0.5).
Discretize the triangular domain using a mesh composed of 64 triangular elements.
Set the material parameters to Young modulus E = 70e9 Pa, Poisson ratio nu = 0.33, and mass density rho = 2700 kg/m^3.
Compute the plane-stress Lamé parameters using mu = E / (2 * (1 + nu)) and lambda_ps = (E * nu) / (1 - nu^2).
Define a vector-valued continuous Lagrange finite element function space for displacement.
Apply a Dirichlet boundary condition fixing displacement to zero in both directions along the left vertical boundary at x = 0.
Apply a body force vector corresponding to gravity pointing downward in the y-direction with magnitude rho * g, where g = 9.81 m/s^2.
Apply a vertical surface traction vector T = (0, -5e3 * sin(pi * x)) Pa along the hypotenuse boundary defined by x + 2*y = 1.
Leave the bottom boundary at y = 0 traction-free.
Assemble the linear variational problem derived from the standard virtual work equation for linear elasticity.
Solve the resulting linear system using a direct linear solver.
Compute the Cauchy stress tensor from the solved displacement field.
Evaluate the 2D plane-stress von Mises stress field from the in-plane components of the Cauchy stress tensor.
Output and visualize the resulting displacement field and von Mises stress distribution.
