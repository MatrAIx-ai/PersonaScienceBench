Use legacy FEniCS (dolfin) to formulate and solve the 2D small-strain linear elasticity problem.
Define the 2D geometry as a right triangle with vertices at (0, 0), (1, 0), and (0, 0.5).
Generate a triangular mesh of the domain containing 64 elements.
Set Young modulus E to 70e9 Pa and Poisson ratio nu to 0.33.
Model the problem under the plane-stress assumption with unit thickness.
Define the plane-stress Lamé parameters as mu = E / (2 * (1 + nu)) and lambda = E * nu / (1 - nu * nu).
Define the small-strain tensor as the symmetric gradient of the displacement field.
Define the Cauchy stress tensor using the isotropic plane-stress constitutive relation.
Set the mass density rho to 2700 kg/m^3 and the gravitational acceleration g to 9.81 m/s^2.
Apply a downward gravitational body force vector defined as (0, -rho * g).
Apply a fixed Dirichlet boundary condition with zero displacement in both x and y directions on the left vertical edge where x equals 0.
Apply a position-dependent vertical traction vector T = (0, -5000 * sin(pi * x)) Pa along the hypotenuse defined by x + 2 * y = 1.
Keep the bottom edge along y equals 0 traction-free.
Discretize the displacement field using a vector Lagrange finite element space of polynomial degree 2.
Assemble the variational form representing the balance of linear momentum.
Solve the resulting linear system using a direct linear solver.
Evaluate the in-plane Cauchy stress components from the solved displacement field.
Compute the von Mises stress field defined as sqrt(sigma_xx^2 - sigma_xx * sigma_yy + sigma_yy^2 + 3 * sigma_xy^2).
Project the von Mises stress field onto a scalar discontinuous Lagrange function space for postprocessing and visualization.
