Use legacy FEniCS (dolfin) to solve the 2D plane-stress small-strain linear elasticity problem.
Define the domain as a rectangular plate spanning x from 0 to 1.0 meters and y from 0 to 0.20 meters.
Generate a structured uniform mesh on the domain with 20 subdivisions along the x-axis and 4 subdivisions along the y-axis.
Construct a vector-valued continuous Lagrange finite element function space of degree 1 for the displacement field u = (u_x, u_y).
Set material properties with Young's modulus E = 200 GPa and Poisson's ratio nu = 0.30.
Compute the shear modulus mu as E / (2 * (1 + nu)).
Compute the plane-stress Lamé parameter lambda as E * nu / (1 - nu^2).
Define the small-strain tensor epsilon(u) as the symmetric gradient of displacement.
Formulate the 2D plane-stress stress tensor sigma(u) as 2 * mu * epsilon(u) + lambda * tr(epsilon(u)) * I.
Apply a Dirichlet boundary condition on the left edge at x = 0 fixing displacement u_x = 0 and u_y = 0.
Apply a Dirichlet boundary condition on the right edge at x = 1.0 prescribing displacement u_x = 0.001 meters and u_y = 0.
Leave the top boundary at y = 0.20 and bottom boundary at y = 0 traction-free.
Assemble the variational form and solve the linear system using a direct linear solver.
Export the displacement field to an XDMF file.
Plot and save a color map of the horizontal displacement component u_x to an image file named q1_ux.png.
