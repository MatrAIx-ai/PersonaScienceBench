Use legacy FEniCS (dolfin) to solve the 2D small-strain linear elasticity problem.
Define the rectangular domain as Omega = (0, 1.0) x (0, 0.20) meters.
Generate a uniform structured mesh over the domain with 20 subdivisions in the x-direction and 4 subdivisions in the y-direction.
Define a continuous Galerkin vector function space for displacement using degree 1 Lagrange elements.
Set the material parameters to Young modulus E = 200e9 Pa and Poisson ratio nu = 0.30.
Compute the Lamé parameters using mu = E / (2.0 * (1.0 + nu)) and lambda = E * nu / ((1.0 + nu) * (1.0 - 2.0 * nu)) for the 2D constitutive formulation.
Apply a Dirichlet boundary condition on the left boundary at x = 0 with displacement u_x = 0 and u_y = 0.
Apply a Dirichlet boundary condition on the right boundary at x = 1.0 with displacement u_x = 0.001 meters and u_y = 0.
Keep the top at y = 0.20 meters and bottom at y = 0 meters traction-free.
Solve the variational problem using a direct linear solver.
Save a color map plot of the horizontal displacement component u_x to a file named q1_ux.png.
Save the resulting displacement vector field to an XDMF file.
