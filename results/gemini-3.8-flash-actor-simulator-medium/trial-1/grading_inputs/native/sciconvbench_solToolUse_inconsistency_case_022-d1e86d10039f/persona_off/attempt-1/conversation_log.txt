Q: Should the simulation use the plane-stress Lamé parameter $\lambda = \frac{E\nu}{1 - \nu^2}$ or the standard 3D Lamé parameter $\lambda = \frac{E\nu}{(1+\nu)(1-2\nu)}$?
A: Please use the reduced plane-stress constitutive law (treating the 2D strip as plane stress with unit thickness), which uses the plane-stress Lamé parameter:

$$\lambda = \frac{E\nu}{1 - \nu^2}$$

along with the standard shear modulus $\mu = \frac{E}{2(1+\nu)}$.

Q: What finite element family and polynomial degree should be used for the vector-valued displacement function space?
A: The requirements do not specify a particular finite element family or degree. Standard first-order continuous Lagrange elements (e.g., `VectorFunctionSpace(mesh, "Lagrange", 1)`) are typical for this problem and work well.
