Use legacy FEniCS (dolfin) to solve the 2D plane-stress linear elasticity problem.
Define the rectangular domain as (0, 1.0) x (0, 0.20) meters.
Discretize the domain with a uniform structured mesh of 20 by 4 subdivisions using RectangleMesh.
Define a vector function space using first-order continuous Lagrange elements.
Set the material properties to Young's modulus E = 200e9 Pa and Poisson's ratio nu = 0.30.
Use the 2D plane-stress Lamé parameter lambda = E * nu / (1.0 - nu**2) and shear modulus mu = E / (2.0 * (1.0 + nu)).
Assemble the variational formulation for small-strain isotropic linear elasticity under plane stress without body forces.
Apply a Dirichlet boundary condition of u_x = 0 and u_y = 0 on the left boundary at x = 0.
Apply a Dirichlet boundary condition of u_x = 0.001 m and u_y = 0 on the right boundary at x = 1.0.
Leave the top boundary at y = 0.20 and bottom boundary at y = 0 traction-free.
Solve the linear system using a direct linear solver.
