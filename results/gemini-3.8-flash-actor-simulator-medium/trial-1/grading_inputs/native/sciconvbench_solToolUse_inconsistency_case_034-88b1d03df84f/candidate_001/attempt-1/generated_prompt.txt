Use legacy FEniCS (dolfin) to solve the 2D small-strain linear elasticity problem under plane-stress conditions.
Define the geometry as an L-shaped domain formed by subtracting a 0.5 by 0.5 square from the upper right corner of a 1.0 by 1.0 unit square spanning from 0 to 1 in both x and y.
Discretize the domain using a mesh with 64 elements per edge.
Define a vector-valued displacement finite element function space on the mesh.
Set the material parameters to Young's modulus E = 70e9 Pa and Poisson's ratio nu = 0.33.
Use the reduced plane-stress constitutive formulation with unit thickness.
Apply a gravity body force vector of (0, -rho * g) where rho = 2700 kg/m^3 and g = 9.81 m/s^2.
Apply a fixed Dirichlet boundary condition with zero displacement on the left boundary at x = 0.
Apply a vertically varying surface traction vector of (0, -2.65e4 * y) Pa along the outer right boundary at x = 1.
Evaluate the traction profile on the boundary using the global y-coordinate.
Keep all re-entrant and remaining boundaries traction-free.
Assemble and solve the linear variational problem using a direct linear solver.
Compute the displacement field throughout the domain.
Compute the in-plane Cauchy stress tensor field and evaluate the von Mises stress distribution.
