Calculate the pressure drop in the pipe using the Darcy-Weisbach equation.
Given parameters: pipe length L = 100 m, inner diameter D = 0.05 m, volumetric flow rate Q = 2 L/s = 0.002 m³/s, fluid density ρ = 998 kg/m³, dynamic viscosity μ = 1.0e-3 Pa·s, pipe roughness ε = 0.15 mm = 1.5e-4 m, horizontal orientation so no elevation term.
Compute the cross-sectional area A = (π/4) × D² = 1.9635e-3 m².
Compute the average velocity v = Q/A ≈ 1.0186 m/s.
Compute the Reynolds number Re = ρ v D / μ ≈ 5.08 × 10⁴, confirming turbulent flow.
Compute the relative roughness ε/D = 0.003.
Solve for the Darcy friction factor f using the Haaland equation, 1/√f = -1.8 log₁₀[(ε/D / 3.7)^1.11 + 6.9/Re], giving f ≈ 0.0260 (equivalent Colebrook result within 1%).
Compute the pressure drop ΔP = f (L/D) (ρ v² / 2) ≈ 0.0260 × 2000 × (998 × 1.0186² / 2) Pa ≈ 2.69 × 10⁴ Pa.
Report the final pressure drop as ΔP ≈ 26.9 kPa over the 100 m horizontal pipe, assuming fully developed turbulent flow in a constant-diameter pipe with no minor losses.
