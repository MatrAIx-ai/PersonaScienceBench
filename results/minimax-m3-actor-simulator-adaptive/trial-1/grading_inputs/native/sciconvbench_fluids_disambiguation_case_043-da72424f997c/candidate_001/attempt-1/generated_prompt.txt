Compute the Taylor number for Taylor–Couette flow between concentric cylinders using the following specification.

Inner cylinder radius R_i = 0.05 m, outer cylinder radius R_o = 0.052 m, giving a gap d = R_o − R_i = 0.002 m.

Use the mean radius R_m = (R_i + R_o)/2 = 0.051 m; for this narrow-gap geometry one may equivalently approximate R_m ≈ R_i = 0.05 m, and the final value should report both choices.

Inner cylinder rotates at N = 100 rpm, giving angular velocity Ω = 2π N / 60 = 10.472 rad/s; the outer cylinder is stationary.

Fluid dynamic viscosity μ = 0.01 Pa·s, as given.

Fluid density ρ is NOT provided in the problem statement and must be assumed; assume ρ = 1000 kg/m³ and state this assumption explicitly in the result.

Compute kinematic viscosity ν = μ / ρ = 0.01 / 1000 = 1.0 × 10⁻⁵ m²/s.

Use the standard Taylor number definition Ta = 4 Ω² R_m d³ / ν².

Substitute values and report both Ta ≈ 1789 using R_m = 0.051 m and Ta ≈ 1755 using R_m ≈ R_i = 0.05 m.

Convert rotation to rad/s before substituting, keep all intermediate units explicit, and express the final Taylor number as a dimensionless number with no units.

Note in the final answer that ρ was assumed (not given), so the reported Ta is contingent on that assumption, and that the resulting Ta is approximately at the classical critical value (~1700), which would correspond to marginally stable or onset-of-instability conditions.
