Compute the Taylor number for flow between rotating concentric cylinders in a narrow-gap Taylor–Couette configuration.
Use the standard assumption that the inner cylinder rotates while the outer cylinder remains stationary.
Set the inner cylinder radius R_in to 5 cm, i.e., 0.05 m.
Set the gap width d to 2 mm, i.e., 0.002 m, which satisfies the narrow-gap condition d/R_in = 0.04.
Set the inner cylinder rotation rate to 100 rpm and convert to angular velocity ω = 100 × 2π/60 ≈ 10.472 rad/s.
Use a fluid dynamic viscosity μ of 0.01 Pa·s.
Use a fluid density ρ of 1000 kg/m³, adopted as the water-like default.
Compute the kinematic viscosity ν = μ/ρ = 1.0 × 10⁻⁵ m²/s.
Apply the standard narrow-gap Taylor number definition Ta = ω² × R_in × d⁴ / ν², equivalently Ta = ρ² ω² R_in d⁴ / μ².
Report the resulting dimensionless Taylor number.
Compare the computed value to the critical Taylor number for onset of Taylor vortices with a stationary outer cylinder, Ta_c ≈ 1708, and state whether the flow at this rotation rate lies in the subcritical (stable Couette) or supercritical (Taylor vortex) regime.
