Confirm that M2 is less than 2.0, reflecting that a supersonic flow in a converging passage decelerates rather than accelerates.

Report the exit Mach number M2 obtained from the supersonic branch.

Compute the exit static velocity V2 from M2 and the stagnation temperature derived from the inlet stagnation enthalpy, using the ideal gas constant for air.

Compute the inlet static velocity V1 from M1 and the same stagnation temperature.

Report the change in velocity defined as V2 minus V1, and note explicitly that this change is negative, meaning the velocity decreases from inlet to exit even though the wording of the problem asks for an increase.
