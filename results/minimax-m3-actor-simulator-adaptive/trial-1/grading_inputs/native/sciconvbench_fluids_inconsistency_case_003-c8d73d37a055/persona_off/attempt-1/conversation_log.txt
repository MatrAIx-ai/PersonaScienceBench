Q: What is the inlet static temperature T1 (in K) that should be used to compute the absolute exit and inlet velocities?
A: Good question — and honestly, the problem statement **does not specify an inlet static temperature T1**. Only the inlet Mach number (M1 = 2.0), γ = 1.4, and the area ratio (A2/A1 = 0.7) are given.

That said, here's what I can tell you:

**1. You don't actually need T1 to answer the core question.**

The question asks for the *increase* in exit velocity compared to the inlet — i.e., ΔV = V2 − V1 (or equivalently, the ratio V2/V1). Since the stagnation temperature T0 is constant:

$$\frac{T_2}{T_1} = \frac{1 + \frac{\gamma-1}{2}M_1^2}{1 + \frac{\gamma-1}{2}M_2^2}$$

and

$$\frac{V_2}{V_1} = \frac{M_2}{M_1}\sqrt{\frac{T_2}{T_1}}$$

So the velocity ratio (and hence the qualitative result — that the flow *decelerates*) is fully determined once M2 is found from the area–Mach relation.

A standard textbook assumption for air problems is **T1 = 300 K** (≈ ambient). With this, T0 = 300(1 + 0.2·4) = **540 K**, which then gives V1 = M1·a1 = 2.0·√(γRT1) ≈ 2.0·347.2 ≈ **694 m/s** at the inlet.
