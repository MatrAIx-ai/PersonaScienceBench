The problem considers isentropic, quasi-1D, frictionless flow of air (γ = 1.4, R = 287 J/(kg·K)) through a converging nozzle.
The inlet Mach number is M1 = 2.0 on the supersonic branch of the area–Mach relation.
The area ratio is A2/A1 = 0.7 (the passage converges).
The inlet static temperature is T1 = 300 K.
Determine the exit Mach number M2 from the area–Mach relation using the supersonic solution corresponding to A2/A1 = 0.7, which yields M2 < M1 ≈ 2.0 (approximately 1.62).
Compute the inlet velocity using V1 = M1 × √(γRT1).
Compute the exit static temperature T2 using the isentropic relation T2/T1 = [1 + (γ−1)/2 × M1²] / [1 + (γ−1)/2 × M2²].
Compute the exit velocity V2 = M2 × √(γRT2).
Report the change in velocity ΔV = V2 − V1.
Confirm the physical interpretation that a converging passage decelerates a supersonic flow, so ΔV is negative.
