Q: What Reynolds number do you want to use for the simulation?
A: Re = 100 ho jayega. Lid velocity 1 m/s, cavity size 0.1 m, aur nu 1e-3 m²/s diya hai — toh Reynolds number 100 aayega. Isko laminar maan ke chalao.

Q: What grid resolution and grid type do you want to use for the cavity (e.g., uniform 128x128, stretched grid with Nx by Ny resolution)?
A: Uniform Cartesian mesh chahiye, 20x20 cells ka — blockMesh se banao. Bas itna hi, koi stretched grid nahi. BlockMeshDict mein vertices (0 0 0), (0.1 0 0), (0.1 0.1 0), (0 0.1 0) rakh ke z-direction mein 0.01 m extrude kar dena taaki 2D case ban jaye (ek cell thick).

Q: Solver kaunsa use karna chahte hain — steady-state `simpleFoam` (SIMPLE algorithm, residual-based convergence), ya transient `icoFoam`/`pisoFoam` (time-stepping chala ke steady state tak le jaana, jaise standard cavity tutorial mein hota hai)?
A: `icoFoam` use karna hai — transient wala. SimpleFoam nahi chalana, kyunki standard lid-driven cavity tutorial mein icoFoam hi use hota hai time-stepping ke liye, aur Re=100 ke liye yahi sahi solver hai.
