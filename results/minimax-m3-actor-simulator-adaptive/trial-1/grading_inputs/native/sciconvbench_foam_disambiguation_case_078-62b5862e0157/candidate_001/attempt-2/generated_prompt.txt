Use the interFoam solver (VOF-based transient incompressible two-phase flow) for this case.
The case domain is a rectangular tank of dimensions 1.0 m (x) by 0.6 m (y) by 0.1 m (z).
Place the tank floor at y = 0 and let the left, right, and top walls lie at x = 0, x = 1.0 m, and y = 0.6 m respectively.
Create the mesh with blockMesh using 200 cells in x, 120 cells in y, and 1 cell in z.
Assign the front and back patches (z = 0 and z = 0.1) the type empty so that the case behaves as a 2D wedge.
Set the gravity vector in the constant/g file to (0 -9.81 0) m/s².
Initialize the velocity field U to (0 0 0) everywhere.
Initialize the pressure field p_rgh to 0 everywhere.
Initialize the phase fraction field alpha.water to 0 everywhere as the base state that will be overwritten by setFields.
Define ten boxes in the setFieldsDict that span the entire z extent (z from -1 to 1) so that the wedge is filled uniformly along z.
Each box i (for i = 0, 1, ..., 9) has x from (0.1 × i) to (0.1 × (i + 1)), y from 0 to (0.255 + 0.01 × i), and z from -1 to 1.
Inside setFieldsDict list all ten boxes under the boxToCell region and set alpha.water to 1 inside those boxes so that the result is a stair-stepped tilted water column with heights approximately 0.255 m at x = 0 rising to approximately 0.345 m at x = 1.
Apply the noSlip condition fixedValue (0 0 0) for U on the left, right, and bottom wall patches so that viscous boundary layers form and sloshing is realistically damped.
Apply the fixedFluxPressure condition for p_rgh on the left, right, and bottom wall patches so that pressure automatically satisfies the zero normal gradient condition consistent with no-slip.
Apply the zeroGradient condition for alpha.water on the left, right, and bottom wall patches so the phase fraction can evolve naturally at the walls.
Apply the pressureInletOutletVelocity condition for U on the top patch (atmosphere at y = 0.6) so that air can enter or leave based on local pressure.
Apply totalPressure with p0 equal to 0 for p_rgh on the top patch so the free surface sees atmospheric reference pressure.
Apply inletOutlet with inletValue 0 for alpha.water on the top patch so air enters by default and water phase is allowed to leave if the surface reaches the boundary.
Apply the empty condition for U, p_rgh, and alpha.water on the front and back patches to maintain the 2D wedge behavior.
In the system/controlDict set application to interFoam.
Set startFrom to startTime, startTime to 0, and stopAt to endTime with endTime equal to 10 s.
Set deltaT to 1e-3 s for the initial time step.
Set adjustTimeStep to yes so that deltaT adapts to satisfy the Courant constraint.
Set maxCo to 0.5 and maxAlphaCo to 0.5 to keep the VOF and velocity CFL numbers bounded.
Set writeControl to timeStep, writeInterval to 0.05 s, and ensure that writeFormat is ascii and purgeWrite is 0 so that every 0.05 s of simulated time is saved.
Set runTimeModifiable to yes so that controlDict edits may apply mid-run.
In system/fvSchemes set ddtSchemes default to Euler.
Set gradSchemes default to Gauss linear and for grad(alpha) set Gauss linear.
Set divSchemes default to none and explicitly choose div(phi,alpha) to Gauss vanLeer (or Gauss MULESCorr plus Gauss vanLeer limiter as the corrected scheme) to obtain a sharp, bounded interface.
Set div(phi,U) to Gauss linearUpwind grad(U) for bounded momentum convection.
Set div(phirb,alpha) to Gauss linear.
Set div(R) and any other div schemes to Gauss linear.
Set laplacianSchemes default to Gauss linear corrected.
Set interpolationSchemes default to linear.
Set snGradSchemes default to corrected.
In system/fvSolution choose the PIMPLE algorithm with nOuterCorrectors set to 1 or 2, nCorrectors set to 2, and nNonOrthogonalCorrectors set to 0 since the mesh is orthogonal.
Set residualControl with tolerances of 1e-5 for p_rgh and U to monitor convergence.
Residuals are only printed since nOuterCorrectors = 1; troubleshooting can increase this to 2.
Set solvers for p_rgh, U, and alpha.water to GAMG or PCG / PBiCG with appropriate preconditioners (DILU for U and alpha.water, FDIC for p_rgh).
Set pRefCell and pRefValue to 0 and 0 since incompressible.
Workflow: first run blockMesh, then run setFields to overwrite the alpha.water field with the stair-stepped tilted water column, and finally run interFoam to start the transient simulation.
The initially tilted free surface at rest under a tilted state will drive the sloshing as gravity pulls the heavier water column toward equilibrium, generating oscillatory motion that decays due to viscous no-slip wall damping.
