Final Specification for Spray Combustion Simulation:

Use OpenFOAM with the reactingParcelFoam solver to perform a Lagrangian simulation of reactive spray particles.

The computational domain is a 2D axisymmetric cylindrical combustion chamber with length L = 0.2 m and diameter D = 0.1 m, giving an aspect ratio L/D = 2:1.

Generate the mesh using blockMesh with 100 cells in the axial direction and 50 cells in the radial direction, applying grading refinement near the central axis and near the inlet face to resolve the spray plume.

Initialize the chamber interior with quiescent hot air at temperature T = 800 K, composition O₂ = 0.233 and N₂ = 0.767 by mass, and atmospheric pressure p = 101325 Pa.

Inject liquid n-Dodecane (nC₁₂H₂₆) using the coneInjection model positioned at the center of the inlet face (x = 0, r = 0), directed axially into the chamber, with a cone half-angle of 20°.

Set the injector mass flow rate to m_dot = 0.002 kg/s, with parcel initial temperature of 300 K and a Rosin-Rammler droplet size distribution with mean diameter d = 50 µm and spread parameter of 3.0 as a reasonable default if no additional data are available.

Apply the Ranz-Marshall correlation for convective heat transfer and mass transfer between droplets and the surrounding gas.

Use the standard drag model for momentum coupling between droplets and the continuous gas phase.

Define the JANAF thermophysical model for the gas phase to handle temperature-dependent properties of O₂, N₂, CO₂, H₂O, and dodecane vapor.

Use a single-step global reaction mechanism for dodecane combustion, written as C₁₂H₂₆ + 18.5 O₂ → 12 CO₂ + 13 H₂O, with Arrhenius kinetics following a Westbrook-Dryer style formulation with default parameters A, Ea, and third-body or turbulent-chemistry interaction terms appropriate for spray flames.

Apply the standard k-epsilon RAS turbulence model, with k and epsilon boundary values defined using a turbulence intensity of 5% and an integral length scale equal to 10% of the chamber diameter at the co-flow inlet.

Set the co-flow air inlet boundary at T = 800 K, atmospheric pressure, with composition O₂ = 0.233 and N₂ = 0.767, and specified turbulence parameters.

Set the outlet boundary at x = 0.2 m as a pressure-outlet condition with p = 101325 Pa and zero-gradient conditions for all other fields.

Set the cylindrical side walls and the non-injector portion of the inlet face to a fixed temperature of 400 K, with no-slip velocity condition.

Set the line r = 0 as the axis symmetry boundary of type axis.

Run the simulation in transient mode using adjustable time stepping, ensuring the Courant number remains below 1 in the gas phase, and continue until the flame structure reaches a quasi-steady state.
