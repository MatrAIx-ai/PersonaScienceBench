Q: Which gas-phase combustion model should be configured in the `combustionProperties` dictionary — for example `infinitelyFastChemistry`, `PaSR`, or `EDC`?
A: For a turbulent spray diffusion flame like this one, use **`PaSR` (Partially Stirred Reactor)** in `constant/combustionProperties`.

PaSR is the appropriate choice here because:

1. **Turbulent non-premixed flame** — In a spray flame, fuel vapor from evaporating droplets mixes with co-flow air; combustion is mixing-limited, not infinitely fast. `infinitelyFastChemistry` would be a poor fit.
2. **Finite-rate chemistry via a two-step global mechanism** — PaSR couples the chemical source terms with the turbulent mixing time scale (using k and ε from the RAS model), which is exactly what a global mechanism with two reactions needs.
3. **Computational cost** — EDC is also valid but much more expensive; for a 100×50 mesh with Lagrangian parcels, PaSR is the standard practical choice.

Typical `combustionProperties` setup:

```cpp
combustionModel PaSR;

PaSRCoeffs
{
    Cmix             1.0;   // mixing model constant (often left default)
    kappa            1.0;   // partially-stirred reactor parameter
    turbulentReaction on;
    semiImplicit     no;
}
```

Let the mixing time scale τ_mix = k/ε be computed from the k-ε RAS fields — that is what makes PaSR a *turbulent* combustion model rather than a laminar one.

Pair this with the two-step global mechanism in `reactionSchemes` (e.g., a fuel-oxidation step and a CO→CO₂ step for n-C₁₂H₂₆) using `janaf` thermodynamics, as already specified.
