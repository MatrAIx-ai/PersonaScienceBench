Use the pimpleFoam solver for a transient, incompressible, laminar simulation of flow past a 2D cylinder.
Set the cylinder diameter D = 0.1 m as the characteristic length of the problem.
Build the mesh with one cell layer in the spanwise direction to represent a true 2D case.
Set the frontAndBack patches in constant/polyMesh/boundary to type empty.
Set the inlet, outlet, and cylinderWall patches in constant/polyMesh/boundary to types that match the field boundary conditions defined below.
Use the Newtonian transport model in constant/transportProperties with kinematic viscosity nu set to 1e-3 m²/s.
Apply type empty to the frontAndBack patch in the 0/U field to keep the field boundary definition consistent with the mesh boundary.
Apply type fixedValue with value uniform (1 0 0) to the inlet patch in the 0/U field to impose a unit free-stream velocity in the x-direction.
Apply type zeroGradient to the outlet patch in the 0/U field to allow convective outflow.
Apply type fixedValue with value uniform (0 0 0) to the cylinderWall patch in the 0/U field to enforce a no-slip wall on the cylinder surface.
Apply type empty to the frontAndBack patch in the 0/p field.
Apply type zeroGradient to the inlet patch in the 0/p field.
Apply type fixedValue with value uniform 0 to the outlet patch in the 0/p field to anchor the pressure reference.
Apply type zeroGradient to the cylinderWall patch in the 0/p field.
Set the application to pimpleFoam in system/controlDict.
Set startFrom to startTime with startTime 0 in system/controlDict.
Set stopAt to endTime with endTime 20 in system/controlDict.
Set a fixed time step deltaT to 0.002 in system/controlDict.
Set writeControl to timeStep with writeInterval 500 in system/controlDict.
Set writeFormat to binary in system/controlDict for compact output.
Enable runTimeModifiable to true in system/controlDict.
Use the PIMPLE algorithm in system/fvSolution with appropriate outer and inner correctors to enforce pressure-velocity coupling at every time step.
Set the pressure solver in system/fvSolution to GAMG with GaussSeidel smoother for efficient solution on an orthogonal grid.
Set the velocity component solvers in system/fvSolution to smooth solvers using symGaussSeidel.
Use the default linear scheme for grad and snGrad terms in system/fvSchemes.
Use the linear scheme for Laplacian terms in system/fvSchemes.
Use a bounded linear or linearUpwind scheme for the divergence of the momentum equation in system/fvSchemes.
The Reynolds number defined as Re = U*D/nu is 100 with U = 1 m/s, D = 0.1 m, and nu = 1e-3 m²/s, placing the flow in the laminar vortex-shedding regime associated with the Von Karman vortex street.
Run the simulation for approximately 20 physical seconds to capture about 30 shedding cycles after the initial transient and to enable statistical averaging of drag and lift coefficients.
