Simulate an underexpanded Mach 2.0 compressible jet in 2D using OpenFOAM, treating air as a perfect gas and using `pimpleFoam` for the transient solution.
Use a 2D mesh with one cell thickness extruded in the z-direction and both front and back patches set to `empty`.
Set the computational domain as a rectangle in the x-y plane: x in [0, 0.5] m (axial, downstream direction), y in [-0.1, 0.1] m (symmetric about the centerline at y = 0).
Set the nozzle exit diameter D = 0.01 m (1 cm), centered on y = 0, so the jet exit strip at x = 0 occupies y in [-0.005, 0.005] m.
Model the nozzle as a flat supersonic inflow plane at x = 0 (sharp-edged exit; no converging-diverging contour resolved upstream).
Refine the mesh near the nozzle lip with cell sizes Δx, Δy of order D/100 (about 1.0e-4 m) grading to roughly D/10 (about 1.0e-3 m) downstream and toward the lateral far-field, biased toward the jet axis.
Initialize the entire interior of the domain with ambient still air: p = 101325 Pa, T = 300 K, U = (0, 0, 0).
Configure `constant/thermophysicalProperties` with `thermoType` containing type `hePsiThermo`, mixture `pureMixture`, transport `sutherland`, thermo `hConst`, equationOfState `perfectGas`, specie `specie`, and energy `sensibleEnthalpy`.
Specify air properties in the `mixture` sub-dictionary: molWeight 28.9, Cp 1005 J/(kg·K), Hf 0, and Sutherland coefficients As = 1.4792e-06 kg/(m·s·K^0.5), Ts = 110.4 K.
Treat the flow as a viscous laminar Navier-Stokes simulation with no RANS or LES turbulence model, since none is mentioned in the requirement.
Create `constant/turbulenceProperties` containing `simulationType laminar;` so pimpleFoam routes to laminar transport with molecular viscosity supplied by the Sutherland law in thermophysicalProperties.
At the inlet jet strip (x = 0, y in [-D/2, D/2]), apply fixedValue boundary conditions for U, p, and T: U = (686, 0, 0) m/s, p = 101325 Pa, T = 300 K, representing supersonic inflow.
At the side strips of the inlet (x = 0, y outside the jet region), apply fixedValue ambient boundary conditions: U = (0, 0, 0) m/s, p = 101325 Pa, T = 300 K, representing still air upstream of the jet edges.
At the top (y = +0.1 m), bottom (y = -0.1 m), and downstream outlet (x = 0.5 m) boundaries, apply far-field conditions: `waveTransmissive` for p and T (with reference ambient values pInf = 101325 Pa, TInf = 300 K) and `zeroGradient` for U.
Do not introduce any solid wall BC in this sharp-edged inflow setup, since the nozzle contour is not modeled and all non-inlet domain boundaries are open far-field, so noSlip walls never apply.
In `system/controlDict`, set `application pimpleFoam;`, `startFrom latestTime;`, and end the run after a few flow-through times (the convective time across the domain is L/U ≈ 0.5 m / 686 m/s ≈ 7.3e-4 s, so endTime of roughly 5e-3 s to 1e-2 s is appropriate to reach a quasi-steady shock-cell pattern).
Use an adjustable time step with a target maximum Courant number of about 0.5 to keep the strong shocks from a Mach 2 jet numerically stable, with `writeControl adjustableRunTime;` and `writeInterval 1e-4 s;` to capture the transient development of the jet.
Use `checkMesh` to verify mesh quality before running and monitor mass flow, dimensionless centerline velocity decay, and near-field pressure oscillations to validate that the expected shock-cell structure of an underexpanded Mach 2 jet is reproduced.
