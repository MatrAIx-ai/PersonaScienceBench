Use the twoPhaseEulerFoam solver for a steady-state, two-phase (oil–water) flow in a horizontal pipe.
At the inlet, impose a fixed mixture velocity of U = (0.1 0 0) m/s using type fixedValue.
At the inlet, impose a fixed water volume fraction of alpha.water = 0.3 using type fixedValue.
At the outlet, set alpha.water using type fixedValue with value uniform 0.3.
Use the noSlip condition on the pipe walls.
Run the simulation until it reaches a steady-state solution.
