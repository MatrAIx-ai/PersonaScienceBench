Use the twoPhaseEulerFoam solver for this case.

Run a steady-state, two-phase (oil–water) simulation in a horizontal pipe where the flow direction is along the x-axis and gravity acts in the negative y-direction.

Assign the first liquid phase as water with density 1000 kg/m³ and kinematic viscosity 1e-6 m²/s, and the second liquid phase as oil with density 500 kg/m³ and kinematic viscosity 1e-6 m²/s; tune these values to match the actual fluids of interest if different.

Disable surface tension (sigma set to zero in constant/transportProperties) so the two-phase coupling reduces to drag only, and use the default GraceHp drag model that ships with the standard twoPhaseEulerFoam tutorial.

Build the pipe as a 3 m long, 0.05 m diameter horizontal tube using a 2D axisymmetric or 3D wedge-shaped mesh with sufficient refinement across the cross-section to resolve the oil–water interface.

Set the inlet mixture velocity to a fixed value of 1 m/s along the pipe axis through the inlet patch in the 0/U file using type fixedValue and value uniform (1 0 0).

Set the inlet water volume fraction to 0.3 through the inlet patch in the 0/alpha.water file using type fixedValue and value uniform 0.3.

Apply noSlip boundary conditions on all pipe walls for U (value uniform (0 0 0)), zeroGradient for the phase fractions, and standard wall functions for k and epsilon.

Set the outlet condition for alpha.water exactly as specified by the user: type fixedValue and value uniform 0.3 on the outlet patch.

Set the outlet conditions for U to zeroGradient, for p_rgh to fixedValue uniform 0, and for k and epsilon to zeroGradient on the outlet patch.

Configure the inlet conditions for k and epsilon using fixedValue with values derived from a turbulence intensity of 5 percent and a mixing length equal to 0.038d of the pipe diameter d, which for d = 0.05 m gives approximately k = 3.75e-3 m²/s² and epsilon = 2.6e-4 m²/s³; the exact values can be computed by the standard k–ε wall-of-the-pipe inlet formula.

Select the kEpsilon RAS turbulence model in constant/turbulenceProperties with simulationType RAS, turbulence on, and printCoeffs on.

Use simpleFoam-style numerical schemes: linear upwind for divergence of U, k, and epsilon; vanLeer or linearUpwind for divergence of alpha.water; linear for all gradient terms; and linear for laplacian terms.

Set the linear solver tolerances for U, p_rgh, k, epsilon, and alpha.water so that final residuals fall below 1e-6 for pressure and 1e-8 for all other variables, and run the steady state simulation for at least 2000 iterations or until all residuals reach their targets and the outlet mass flow rate stabilizes to within 0.1 percent between successive 100-iteration intervals.

Verify the converged result by checking that alpha.water at the outlet equals 0.3 and that the mixture velocity at the outlet matches the imposed inlet mixture velocity of 1 m/s, confirming mass conservation and the imposed boundary conditions.
