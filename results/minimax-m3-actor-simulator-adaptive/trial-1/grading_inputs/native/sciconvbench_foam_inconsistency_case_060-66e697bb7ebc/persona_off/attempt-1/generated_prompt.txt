Set up the classic 2D dam-break benchmark in OpenFOAM using the `interFoam` solver, which solves the incompressible two-phase flow equations with a sharp free surface preserved by the MULES limiter on the `alpha.water` transport equation.

Create a case directory named `damBreak` with the standard OpenFOAM structure (0, constant, system).

In `system/controlDict`, set `application interFoam`, use `controlDict` defaults for `startFrom` (`startTime`), `startTime` (0), `stopAt` (`endTime`), `endTime` (1.0), `deltaT` (0.001), and `writeControl` (`adjustableRunTime`) with `writeInterval` (0.05).

In `constant/transportProperties`, define two phases named `water` and `air`: water has `transportModel Newtonian`, `nu 1e-06`, `rho 1000`; air has `transportModel Newtonian`, `nu 1.48e-05`, `rho 1`; set `sigma 0.07` for the surface tension coefficient.

Build the case as a 2D domain extruded by one cell in z using a simple `blockMeshDict` with a single hex block spanning x from 0 to 5 m and y from 0 to 3 m, with `(100 60 1)` cells in the `(x y z)` directions, simple grading in all directions, and the z-extent collapsed to a single zero-thickness layer using a `z` span that becomes empty, with side faces declared as type `empty` in the boundary list.

Define the boundary conditions as follows: at x = 0 use `type wall` named `leftWall`, at x = 5 use `type wall` named `rightWall`, at y = 0 use `type wall` named `bottom`, and at y = 3 use `type patch` named `atmosphere`.

Use 25.4 mm cell size (giving a 200×120 grid) for sharper interface capture than the coarser reference mesh.

In the `0/` directory, create the initial fields `alpha.water`, `U`, and `p_rgh`.

For `0/alpha.water`, use `type compressive` with `phi phi` and `rho phi` lookup, `fieldName alpha.water`, `alphaMin 0`, `alphaMax 1`, and `uMixture U`; at `leftWall`, `rightWall`, and `bottom` set `type zeroGradient`; at `atmosphere` set `type inletOutlet` with `inletValue uniform 0` and `value uniform 0`.

For `0/U`, use `type pressureInletOutletVelocity` at `atmosphere` with `value uniform (0 0 0)`, `type noSlip` with uniform zero at all walls, and set `value uniform (0 0 0)` as the initial condition (fluid starts at rest).

For `0/p_rgh`, use `type fixedFluxPressure` at all walls, `type totalPressure` at `atmosphere` with `p0 uniform 0` and `U U`, and set `value uniform 0` as the initial condition.

Generate non-uniform cartesian meshes for parallel execution of `blockMesh`.

Enable `gravity` in `constant/g` as `uniform (0 -9.81 0)`.

Use the default `system/fvSchemes` from the interFoam tutorial: `ddtSchemes` `Euler`, `gradSchemes` `Gauss linear`, `divSchemes` `div(rhoPhi,U) Gauss linearUpwind grad(U)`, `div(phi,alpha) Gauss vanLeer`, `div(phirb,alpha) Gauss linear`, `div(phi,k) Gauss upwind`, `laplacianSchemes` `Gauss linear corrected`, `interpolationSchemes` `linear`, `snGradSchemes` `corrected`.

Use the default `system/fvSolution` from the interFoam tutorial: solvers `(p_rgh p_rghFinal)` with `GAMG` and `smoother DICGaussSeidel`, solver tolerance `1e-7`, relTol `0.01`; solvers `"(U alpha.*)"` with `smoothSolver` and `symGaussSeidel`, tolerance `1e-8`, relTol `0`; SIMPLE algorithm with `nNonOrthogonalCorrectors 1`, `residualControl` with `p_rgh 1e-4 U 1e-4 alpha.water 1e-4`, `relTol 0.01`.

Initialize the water column with `setFields` using a `system/setFieldsDict` containing a `box` region defined from `(0 0 -1)` to `(2 2 1)` and the `defaultFieldValues` set to `uniform 0` for alpha.water, with the `fieldValues` set to `set alpha.water uniform 1` inside the `boxToCell` region.

After `setFields`, the initial `alpha.water` field equals 1 within the column spanning x ∈ [0, 2] m and y ∈ [0, 2] m (against the left wall) and equals 0 everywhere else, including the empty z-direction.

Run the case with `blockMesh`, then `setFields`, then `interFoam`.

Run for 1.0 s of simulated time, producing a sharp water-air interface that collapses under gravity, impacts the right wall, and produces the standard dam-break evolution used for benchmarking interface tracking accuracy.
