Simulate natural convection in a 2D square cavity as the de Vahl Davis benchmark case using the solver buoyantBoussinesqPimpleFoam.
Use a square cavity of side length L = 0.144 m, so that the dimensionless Rayleigh number comes out to Ra = 10^5 given the remaining parameters.
Set the working fluid properties in constant/transportProperties to nu = 1.0e-4 m²/s and alpha = 1.0e-4 m²/s, giving Pr = nu/alpha = 1.
Set beta = 3.39e-3 K⁻¹ (equivalent to 1/TRef) and TRef = 295 K in constant/transportProperties, so that the Boussinesq buoyancy term beta(T - TRef) is correctly coupled.
Use the Boussinesq approximation for the buoyancy force in the momentum equation.
Set gravity in constant/g to (0 -9.81 0).
Set the hot left wall to fixedValue T = 300 K.
Set the cold right wall to fixedValue T = 290 K.
Set the top and bottom walls to zeroGradient for T, i.e. adiabatic.
Apply noSlip (fixedValue U = (0 0 0)) on all four walls.
Initialize the velocity field to zero everywhere in the domain.
Initialize the temperature field uniformly to TRef = 295 K.
Use zeroGradient for pressure on all walls, consistent with the incompressible Boussinesq formulation.
Use consistent (non-orthogonal) discretization and the standard SIMPLE/PIMPLE pressure-velocity coupling provided by buoyantBoussinesqPimpleFoam.
Run the simulation from the quiescent, isothermal initial condition until the Nusselt number and velocity field reach a statistically steady state, and validate against the canonical de Vahl Davis results at Ra = 10^5 and Pr = 1.
