Identify four polymer fractions with molecular weights M_1 = 56526 g/mol, M_2 = 92809 g/mol, M_3 = 115856 g/mol, M_4 = 126029 g/mol and corresponding molecule counts N_1 = 96, N_2 = 131, N_3 = 153, N_4 = 146.
Compute the total number of molecules ΣN_i = 96 + 131 + 153 + 146 = 526.
Compute the mass-weighted sum Σ(N_i × M_i) = (96)(56526) + (131)(92809) + (153)(115856) + (146)(126029) = 5,426,496 + 12,157,979 + 17,725,968 + 18,400,234 = 53,710,677 (g/mol).
Apply the number-average molecular weight formula M_n = Σ(N_i × M_i) / ΣN_i = 53,710,677 / 526.
Report the result M_n ≈ 102,112 g/mol (more precisely ≈ 102,111.6 g/mol).
