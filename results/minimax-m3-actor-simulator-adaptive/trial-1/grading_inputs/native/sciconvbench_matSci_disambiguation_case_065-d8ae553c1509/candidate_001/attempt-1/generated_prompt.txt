The task is to determine the magnitude of the Burgers vector for a perfect dislocation in an FCC metal with a lattice parameter of a = 0.404 nm.
Use the standard Burgers vector for a perfect dislocation in an FCC crystal structure: b = (a/2) <110>, where <110> is the close-packed direction.
Compute the magnitude using |b| = (a/2) * sqrt(h^2 + k^2 + l^2), with (h, k, l) = (1, 1, 0) for the <110> family.
Set up the equation: |b| = (a/2) * sqrt(1^2 + 1^2 + 0^2) = (a/2) * sqrt(2) = a / sqrt(2).
Substitute a = 0.404 nm to obtain |b|.
Provide the final answer in nanometers, rounded to an appropriate number of significant figures.
