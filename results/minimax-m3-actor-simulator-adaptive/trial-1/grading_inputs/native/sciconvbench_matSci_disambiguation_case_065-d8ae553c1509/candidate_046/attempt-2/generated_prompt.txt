Specification for determining the Burgers vector magnitude of a perfect dislocation in a given FCC metal.

Use the standard FCC perfect dislocation model, where the Burgers vector is of the type a/2<110>.
Compute the magnitude of the Burgers vector using the formula |b| = a × √2 / 2.
Set the lattice parameter a to 0.404 nm.
Evaluate |b| = 0.404 × √2 / 2 nm, which equals approximately 0.286 nm.
Report the final answer as |b| ≈ 0.286 nm (or equivalently 2.86 Å).
State the Burgers vector direction family as <110>.
