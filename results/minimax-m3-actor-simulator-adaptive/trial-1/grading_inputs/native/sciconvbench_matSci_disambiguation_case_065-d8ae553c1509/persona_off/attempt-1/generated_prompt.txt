Determine the magnitude of the Burgers vector for a perfect dislocation in the FCC metal with lattice parameter a = 0.404 nm.
For an FCC crystal, the perfect dislocation Burgers vector corresponds to the shortest lattice translation vector of the type a/2⟨110⟩.
Calculate the magnitude using the formula |b| = a√2/2 = a/√2.
Substitute the given lattice parameter a = 0.404 nm into the formula.
Compute the numerical value: |b| = 0.404 / √2 ≈ 0.404 / 1.4142 ≈ 0.2857 nm.
Report the final Burgers vector magnitude as |b| ≈ 0.286 nm, which is equivalent to 2.86 Å.
