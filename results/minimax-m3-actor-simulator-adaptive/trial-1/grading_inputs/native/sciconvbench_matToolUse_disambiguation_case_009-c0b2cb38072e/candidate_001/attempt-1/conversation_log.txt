Q: What is the file structure inside the `Mg_Ga` defect-entry directory (e.g., does it contain a single `bulk.json`/`bulk.yaml`, a `defect_entries.json` collection, and `vbm`/`cbm` files, or is each charged defect entry stored as a separate file)?
A: Based on the requirement, the structure is folder-based — `Mg_Ga` is a directory that contains subfolders, and inside each subfolder you'll find `vasprun.xml.gz` and `LOCPOT.gz` files for the charged defect calculations.

Specifically:
- The `Mg_Ga` directory has one subfolder per charged defect entry (for charge states `[-2, -1, 0, 1]`).
- Each subfolder contains the standard VASP output, i.e. `vasprun.xml.gz` (and `LOCPOT.gz` for the Freysoldt correction).
- For the bulk reference, use `bulk_sc/LOCPOT.gz` (a `bulk_sc` subfolder containing the bulk supercell LOCPOT) along with the bulk `vasprun.xml.gz` to get the VBM and bulk entry.

There's no single `defect_entries.json` or `bulk.yaml` file mentioned — everything is read per-subfolder from the gzipped VASP outputs.

Q: What is the exact naming convention for the charge-state subfolders inside `Mg_Ga` (e.g., are they named `Mg_Ga_-2`, `Mg_Ga_-1`, `Mg_Ga_0`, `Mg_Ga_1`, or something like `q=-2`, `charge_-2`, etc.)?
A: The exact naming convention for those subfolders actually isn't pinned down in the spec, bro. The requirement only says:
- `Mg_Ga` is a directory with subfolders (one per charged defect)
- each subfolder has `vasprun.xml.gz` and `LOCPOT.gz`
- charge states to consider are `[-2, -1, 0, 1]`

So no specific folder names are required — you just need to glob/discover them yourself.

That said, a safe and common convention for this kind of test case is to name subfolders matching the pattern `Mg_Ga_<charge>`, e.g.:
- `Mg_Ga_-2/`
- `Mg_Ga_-1/`
- `Mg_Ga_0/`
- `Mg_Ga_1/`

Each containing `vasprun.xml.gz` and `LOCPOT.gz`, plus a `bulk_sc/` subfolder holding the bulk supercell's `LOCPOT.gz` (and the bulk `vasprun.xml.gz` at `Mg_Ga/bulk_sc/vasprun.xml.gz` or wherever you put it).

If you're writing the function, I'd recommend just iterating over the four charge values `[-2, -1, 0, 1]` and constructing paths like `os.path.join(file_path, "Mg_Ga", f"Mg_Ga_{q}", "vasprun.xml.gz")` rather than hard-checking a single convention. That way it works with whatever folder naming you actually use.

Also — heads up — when you load each `vasprun.xml.gz` for a defect, you need to tell `Vasprun` that it's a defect run (`defect_structure`, bulk `Structure`, etc.) and feed the matching `bulk_sc/LOCPOT.gz` plus the dielectric tensor (14) into `FreysoldtHandler` to get the `plot_data` and corrected energy. And grab the bulk VBM from the bulk `vasprun` (`vasprun.vbm` or via `potim`) to use as the Fermi reference when building `DefectEntry`.
