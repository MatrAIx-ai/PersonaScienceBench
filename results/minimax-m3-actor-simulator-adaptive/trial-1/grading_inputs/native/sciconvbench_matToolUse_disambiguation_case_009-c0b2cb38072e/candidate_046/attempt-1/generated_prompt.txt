Implement a Python module containing a function `compute_properties()` with no required input arguments.

Define a module-level constant `FILE_PATH` hardcoding the base directory that contains the local input files (the user adjusts the actual string value to match their local layout, but the rest of the code references only `FILE_PATH`).

Create the directory variable inside the function as `base_dir = FILE_PATH` and resolve all subpaths using `os.path.join`.

The directory layout to assume is exactly:
- `FILE_PATH/stable_entries_Mg_Ga_N.json` — JSON file containing a list of pymatgen `ComputedEntry` objects serialized via Monty.
- `FILE_PATH/bulk_sc/vasprun.xml.gz` — bulk supercell VASP output for the host (GaN).
- `FILE_PATH/Mg_Ga/q_<charge>/vasprun.xml.gz` — one subdirectory per defect charge for the Mg-on-Ga substitution defect, where `<charge>` is an integer that may be negative (so the folder name is e.g. `q_-2`, `q_-1`, `q_0`, `q_1`).

Add the following imports at the top of the file: `os`, `json`, `from monty.json import MontyDecoder`, `from pymatgen.io.vasp import Vasprun`, `from pymatgen.core import Element, Structure`, `from pymatgen.analysis.defects.core import Substitution, DefectEntry`, and `from pymatgen.analysis.defects.thermodynamics import FormationEnergyDiagram`.

Write a complete docstring for `compute_properties()` that explicitly states it takes no required arguments, describes that it reads all data under `FILE_PATH`, and documents that the return value is a `dict` with keys `chemical_potential_limits_count` (int).

Inside the function, perform these steps in order:

Read the stable entries by opening `os.path.join(FILE_PATH, "stable_entries_Mg_Ga_N.json")` and decoding with `MontyDecoder().decode(f.read())` to obtain `pd_entries` as a list of `ComputedEntry` objects.

Read the bulk data with `Vasprun(os.path.join(FILE_PATH, "bulk_sc", "vasprun.xml.gz"))` and from it obtain `bulk_entry = bulk_run.get_computed_entry()`, `host_structure = bulk_run.final_structure`, `vbm = bulk_run.get_band_structure().get_vbm()["energy"]`, and `band_gap = bulk_run.get_band_structure().band_gap`.

Construct the `Substitution` defect object once by using `host_structure` and selecting the first site whose species is `Element("Ga")` as `defect_site`, with `defect_specie = Element("Mg")` (use `frac_coords`, `coords`, and `species` attributes of `defect_site` when constructing the `Substitution`); use this single `defect` object for every charged DefectEntry.

Iterate over the entries of `os.listdir(os.path.join(FILE_PATH, "Mg_Ga"))` and keep only those whose names start with `"q_"` and are directories.

For each such folder name `folder`, parse `charge = int(folder.split("_", 1)[1])`, then load `v = Vasprun(os.path.join(FILE_PATH, "Mg_Ga", folder, "vasprun.xml.gz"))` and set `defect_entry = DefectEntry(defect=defect, charge=charge, computed_entry=v.get_computed_entry())`. Append each `defect_entry` to a list called `defect_entries`.

Build the diagram with `fed = FormationEnergyDiagram(bulk_entry=bulk_entry, defect_entries=defect_entries, pd_entries=pd_entries, vbm=vbm, band_gap=band_gap)`.

Compute `chemical_potential_limits_count = len(fed.chemical_potential_limits)`.

Return the dictionary `{"chemical_potential_limits_count": chemical_potential_limits_count}`.

Wrap the directory listing in `sorted(...)` so the resulting charge list is deterministic, and do not apply any charge-correction (Freysoldt/Kumagai) to the `DefectEntry` objects because `chemical_potential_limits` depends only on the bulk entry and `pd_entries`.
