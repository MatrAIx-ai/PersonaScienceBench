Perform a structural relaxation of BaTiO3 using VASP and report the optimized total energy.

First, create the INCAR file for structure optimization with the following exact parameter block:
ALGO = Fast
EDIFF = 0.0005
ENCUT = 520.0
IBRION = -1
ISIF = 3
ISMEAR = -5
ISPIN = 2
LASPH = .TRUE.
LMAXMIX = 4
LORBIT = 11
LREAL = Auto
LWAVE = .FALSE.
MAGMOM = 39*-0.0
NELM = 100
NSW = 0
PREC = Accurate
SIGMA = 0.05

Write this block into a file named INCAR in the current directory (data/relax/BaTiO3), alongside the existing POSCAR, KPOINTS, POTCAR, run_vasp.sh, and get_energy.py files.

Next, execute the relaxation by running the provided launcher script with: bash run_vasp.sh

After the VASP run completes, preserve a copy of the INCAR that was used by running: cp INCAR INCAR1

Then, extract the optimized total energy from the VASP output by running: python get_energy.py

The script reads vasprun.xml and prints the optimized total energy after relaxation.

Return the optimized total energy exactly as printed by get_energy.py, with no modification.
