Specification for computing the MoS2 band gap with VASP (PBE ground state + HSE):

1. Create an INCAR for the PBE ground-state calculation with the following parameters: SYSTEM = MoS2 PBE ground state, PREC = Normal, ENCUT = 450, ISMEAR = 0, SIGMA = 0.05, EDIFF = 1E-5, EDIFFG = -5E-3, IBRION = -1, NSW = 0, ISIF = 2, ISPIN = 1, ISTART = 0, ICHARG = 2, LWAVE = .TRUE., LCHARG = .TRUE., LREAL = Auto, NPAR = 1, KPAR = 4, NCORE = 1.
2. Do not set LHFCALC, HSE06, AEXX, magnetic moments, NBAND, or NELECT in this Step 1 INCAR.
3. Run the PBE ground-state calculation with: bash run_vasp.sh.
4. Save a copy of the Step 1 INCAR as INCAR1 with: cp INCAR INCAR1.
5. Create a new INCAR for the HSE calculation using the parameter block from data.json, but override ICHARG from 11 to 2 (since the task note states ICHARG cannot be larger than 10 when recomputing the charge density from an existing WAVECAR).
6. Do not set magnetic moments, NBAND, or NELECT in the Step 2 INCAR.
7. The Step 2 HSE INCAR must contain: PREC = Normal, ENCUT = 450, NELM = 500, IBRION = -1, ISPIN = 1, NSW = 0, ISIF = 2, EDIFF = 1E-5, EDIFFG = -5E-3, ISTART = 0, ICHARG = 2, ISMEAR = 0, SIGMA = 0.05, LWAVE = .TRUE., LCHARG = .TRUE., LREAL = Auto, LPLANE = .TRUE., NPAR = 1, KPAR = 4, NCORE = 1, LORBIT = 11, ALGO = All, LHFCALC = .TRUE., HSE06 = .TRUE., HFSCREEN = 0.2, TIME = 0.4, AEXX = 0.25, AGGAX = 0.75, LMAXFOCK = 4, PRECFOCK = Fast.
8. Run the HSE calculation with: bash run_vasp.sh.
9. Save a copy of the Step 2 INCAR as INCAR2 with: cp INCAR INCAR2.
10. Extract the band gap by running: python gap.py.
11. Return the band-gap value exactly as printed by gap.py.
