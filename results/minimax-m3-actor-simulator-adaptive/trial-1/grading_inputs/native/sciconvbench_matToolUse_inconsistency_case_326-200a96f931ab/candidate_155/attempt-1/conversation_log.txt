Q: For the Step 1 PBE ground-state calculation, the task says no explicit INCAR parameters are provided in `data.json`, but I still need to create one.

What specific parameters should be used for the PBE ground-state `INCAR`?
A: 关于 Step 1 的 PBE 基态 `INCAR`,完整的需求说明里只给了这么一句话:

> "This case does not provide an explicit INCAR parameter block for Step 1 in `data.json`. You still must create an `INCAR` suitable for a PBE ground-state calculation before running VASP."

也就是说,**官方没有规定具体参数**,只要求"写一份适合 PBE 基态计算的 INCAR"。下面这一份是我基于 PBE 标准做法 + 与 Step 2 HSE 计算的兼容性所拟的建议版本,不属于强制的硬性条款,请按需选用:

---

### 建议的 PBE ground-state `INCAR`(Step 1)

```
SYSTEM = MoS2 PBE ground state
PREC   = Normal
ENCUT  = 450
EDIFF  = 1E-5
IBRION = -1
NSW    = 0
ISIF   = 2
ISPIN  = 1
ISMEAR = 0
SIGMA  = 0.05
ISTART = 0
ICHARG = 2
LWAVE  = .TRUE.
LCHARG = .TRUE.
LREAL  = Auto
LPLANE = .TRUE.
NPAR   = 1
KPAR   = 4
NCORE  = 1
LORBIT = 11
EDIFFG = -5E-3
```

---

### 说明(便于你判断是否采纳)

1. **`ENCUT = 450`**:与 Step 2 HSE 完全保持一致,这样 PBE 阶段得到的波函数在 HSE 阶段不会因截断能不同而需要重做。
2. **`IBRION = -1`、`NSW = 0`、`ISIF = 2`**:单点能(single point)计算,不进行离子弛豫 —— 因为 POSCAR 已经是结构。`EDIFFG` 此时实际上不起作用,但保留无害。
3. **`ISPIN = 1`**:与 HSE 的设置保持一致,MoS2 基态以非自旋极化处理。
4. **`ISMEAR = 0`、`SIGMA = 0.05`**:MoS2 是半导体,使用 Gaussian smearing,`SIGMA=0.05 eV` 是常规安全值。
5. **`ISTART = 0`、`ICHARG = 2`**:`ICHARG=2` 表示从原子电荷密度叠加出发,这是冷启动(没有 WAVECAR/CHGCAR)时的标准做法。
6. **`LWAVE=.TRUE.`、`LCHARG=.TRUE.`**:保留 `WAVECAR` 与 `CHGCAR`。**注意**:Step 2 的 HSE `INCAR` 中 `ISTART=0` 且 `ICHARG=0`,实际上**不会**读取这两个文件 —— 所以严格来说 PBE 的输出对 HSE 步骤并非功能性输入,而是作为 PBE 基态档案留存。如果你的目标是只求最终带隙,这一项也可改为 `.FALSE.` 以节省磁盘。
7. **没有 `NBAND`、`NELECT`、磁矩相关参数**:与 Step 2 任务备注中的明确要求保持一致。
8. **`NPAR=1`、`KPAR=4`、`NCORE=1`、`LREAL=Auto`、`LPLANE=.TRUE.`**:并行与数值设置与 HSE 步骤对齐,避免兼容性歧义。

---

### 与硬性需求的差异之处(请特别确认)

- 唯一必须满足的硬约束是:**这是一份"适用于 PBE 基态计算"的 `INCAR`**,并保证 `bash run_vasp.sh` 能正常跑通。
