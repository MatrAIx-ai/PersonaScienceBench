Compute the electronic band gap of MoS2 using VASP via a two-step workflow: a PBE ground-state calculation followed by an HSE hybrid functional calculation, then extract the gap with the provided post-processing script.
Use the POSCAR, KPOINTS, and POTCAR files already present in the case directory as inputs to VASP.
Step 1, create an INCAR suitable for a PBE ground-state single-point calculation with the following parameters: SYSTEM = MoS2 PBE ground state, PREC = Normal, ENCUT = 450, EDIFF = 1E-5, EDIFFG = -5E-3, IBRION = -1, NSW = 0, ISIF = 2, ISPIN = 1, ISMEAR = 0, SIGMA = 0.05, ISTART = 0, ICHARG = 2, LWAVE = .TRUE., LCHARG = .TRUE., LREAL = Auto, LPLANE = .TRUE., NPAR = 1, KPAR = 4, NCORE = 1, LORBIT = 11.
Do not specify magnetic moments, NBAND, or NELECT in any INCAR.
Write no other mandatory parameters for Step 1 beyond those listed, and do not include hybrid-functional-related tags.
Step 1, run VASP with the command: bash run_vasp.sh.
Step 1, after the run completes, save a copy of the INCAR used by running: cp INCAR INCAR1.
Step 2, create a new INCAR for the HSE calculation using the parameter block supplied in data.json, then override ICHARG from 11 to 0 so that the charge density is recomputed from the existing WAVECAR as required by the task note.
The Step 2 INCAR must therefore contain: PREC = Normal, ENCUT = 450, NELM = 500, IBRION = -1, ISPIN = 1, NSW = 0, ISIF = 2, EDIFF = 1E-5, EDIFFG = -5E-3, ISTART = 0, ICHARG = 0, ISMEAR = 0, SIGMA = 0.05, LWAVE = .T., LCHARG = .T., LREAL = Auto, LPLANE = .TRUE., NPAR = 1, KPAR = 4, NCORE = 1, LORBIT = 11, ALGO = All, LHFCALC = .TRUE., HSE06 = .TRUE., HFSCREEN = 0.2, TIME = 0.4, AEXX = 0.25, AGGAX = 0.75, LMAXFOCK = 4, PRECFOCK = Fast.
Step 2, the ICHARG = 0 choice resolves the contradiction between the data.json block (which lists ICHARG = 11) and the task note (which forbids ICHARG larger than 10 when a hybrid functional is started from an existing WAVECAR).
Step 2, run VASP again with the command: bash run_vasp.sh.
Step 2, after the HSE run completes, save a copy of the INCAR used by running: cp INCAR INCAR2.
Step 3, extract the band gap by running: python gap.py, which reads vasprun.xml, builds the band structure, and prints the band gap.
Return the band-gap value exactly as printed by gap.py as the final answer.
