Inside the directory `data/bandgap/MoS2`, compute the electronic band gap of MoS2 with VASP following the multi-step workflow in `data.json`, using the supplied `POSCAR`, `KPOINTS`, `POTCAR`, `run_vasp.sh`, and `gap.py`.

Step 1 (PBE ground state): create an `INCAR` file containing PREC=Normal, ENCUT=450, NELM=500, IBRION=-1, ISPIN=1, NSW=0, ISIF=2, EDIFF=1E-5, EDIFFG=-5E-3, ISTART=0, ICHARG=2, ISMEAR=0, SIGMA=0.05, LWAVE=.T., LCHARG=.T., LREAL=Auto, LPLANE=.TRUE., NPAR=1, KPAR=4, NCORE=1, LORBIT=11, ALGO=Normal, with no MAGMOM, NBAND, or NELECT tags.

Run the PBE ground-state calculation by executing `bash run_vasp.sh`.

Save the Step 1 INCAR with `cp INCAR INCAR1` immediately after writing it (before it is overwritten in Step 2).

Step 2 (HSE calculation): overwrite `INCAR` with the HSE06 parameter block from `data.json`, but set ICHARG=0 instead of ICHARG=11, because the task note requires that the charge density must be recomputed from the existing WAVECAR when launching the hybrid step, which excludes any ICHARG value larger than 10.

Run the HSE calculation by executing `bash run_vasp.sh`.

Save the Step 2 INCAR with `cp INCAR INCAR2` immediately after writing it.

Step 3 (band gap extraction): run `python gap.py`, which parses `vasprun.xml` produced by the HSE run and prints the band gap.

Return the band-gap value exactly as printed by `gap.py`, with no additional formatting or unit transformation.
