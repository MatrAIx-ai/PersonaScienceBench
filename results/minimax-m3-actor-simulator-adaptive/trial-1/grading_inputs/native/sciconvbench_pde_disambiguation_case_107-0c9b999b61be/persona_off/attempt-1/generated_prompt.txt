Solve the 3-state ODE system defined below using a Classical 4th-order Runge–Kutta (RK4) integrator with a fixed time step.

The dependent variables are E(t), I(t), and H(t).

The ODE system is:
dE/dt = alpha*E - beta*E*I - gamma*E + 0.01*sin(t).
dI/dt = delta*E - epsilon*I.
dH/dt = theta*I - phi*H.

Use radians for the sine function in the dE/dt equation.

The parameters are alpha = 1.2, beta = 1.0, gamma = 0.5, delta = 0.8, epsilon = 0.7, theta = 0.9, and phi = 0.4.

The initial conditions at t = 0.0 are E(0.0) = 0.5, I(0.0) = 0.2, and H(0.0) = 0.1.

The time domain is the closed interval [0.0, 50.0].

Use a fixed time step dt = 0.01 with Nt = 5000 steps so that the final time t = 50.0 is reached exactly.

Evaluate the full state vector Y(t) = [E(t), I(t), H(t)] at all time points t_n = 0.0 + n*dt for n = 0, 1, ..., Nt, giving Nt + 1 = 5001 total time points.

Save the results to "solution_molk_006.npz" containing the array t of shape (Nt+1,), the array Y of shape (Nt+1, 3) with columns ordered as [E, I, H], and the scalar parameters alpha, beta, gamma, delta, epsilon, theta, and phi.

Save a line plot of each of E(t), I(t), and H(t) versus t to "solution_molk_006.png".

Print the final state values E(50.0), I(50.0), and H(50.0) as well as the minimum and maximum of each of E, I, and H over the full time interval.
