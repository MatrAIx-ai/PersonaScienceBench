Compute the viscous stress using a centered difference of the cell-centered v values to obtain v_x, then compute sigma = (zeta + 4/3 * eta) * v_x at cell centers.

Add the viscous flux F_visc = [0, -sigma, -v_interface * sigma] to F_hat at each interface to obtain the total interface flux F_total = F_hat + F_visc.
Advance the semi-discrete finite-volume system in time with 2-stage SSP-RK2 (Heun's method).
