Q: What value should be used for Nx (the number of uniform finite-volume cells on [-1,1])?
A: Nx 的值应当使用 **400**。

根据完整规范：
- Nx = 400 个均匀有限体积单元,分布在区间 [-1, 1] 上
- 因此 dx = 2 / Nx = 2 / 400 = 0.005
- 单元中心位于 x_j = -1 + (j + 0.5) * dx,其中 j = 0, 1, ..., 399

此外,CFL 数的一个常见默认值为 **0.5**(虽然规范中未明确指定,但用于 dt_conv 计算)。如果您希望使用其他 CFL 数值,请告知。
