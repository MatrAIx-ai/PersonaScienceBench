Solve the 1D Compressible Navier–Stokes equations (without heat conduction) in conservative form on x in [-1, 1] and t in [0, 0.5] using a cell-centered finite-volume method.
Use the conserved fluxes m = rho*v and total energy E = p/(Gamma-1) + 0.5*rho*v^2.
Use viscous stress sigma = (zeta + 4/3*eta)*v_x with zeta = eta.
Enforce the PDE system:
rho_t + (m)_x = 0,
m_t + (m^2/rho + p - sigma)_x = 0,
E_t + ((E+p)*v - v*sigma)_x = 0.
Set Gamma = 1.6666666666666667, eta = 0.1, zeta = 0.1.
Apply periodic boundary conditions at x = -1 and x = 1 by wrapping indices.
Use smooth initial conditions evaluated pointwise on the grid:
rho(x,0) = 1.0 + 0.2*sin(pi*x),
v(x,0) = 0.1*cos(pi*x),
p(x,0) = 1.0 + 0.2*cos(pi*x).
Use a uniform finite-volume grid with Nx = 400 cells on [-1, 1], giving dx = 2/400 = 0.005, and cell centers x_j = -1 + (j + 0.5)*dx for j = 0, ..., 399.
Evolve the conservative variables U = [rho, m, E] as cell averages.
Recover pressure from the equation of state p = (Gamma-1)*(E - 0.5*m^2/rho) and clip rho and p to a floor of 1e-12 to enforce positivity.
Compute the convective flux F_conv(U) = [m, m^2/rho + p, (E+p)*v] where v = m/rho.
Use the Rusanov (local Lax-Friedrichs) numerical flux with interface wave speed a = max(|v_L| + c_L, |v_R| + c_R) where c = sqrt(Gamma*p/rho), giving F_hat = 0.5*(F_conv(U_L) + F_conv(U_R)) - 0.5*a*(U_R - U_L).
Compute v_x with a centered difference on the cell-centered v values, then form sigma = (zeta + 4/3*eta)*v_x at cell centers and average neighboring cell-centered sigma values to the interfaces.
Add viscous contributions F_visc = [0, -sigma, -v*sigma] at interfaces using interface-averaged v and sigma so the total interface flux is F_total = F_hat + F_visc.
Integrate in time with 2-stage SSP-RK2 (Heun's method) on the semi-discrete finite-volume system.
Set the time step each step from:
dt_conv = CFL * dx / max_j(|v_j| + c_j),
dt_visc = 0.5 * dx^2 / max(zeta + 4/3*eta, 1e-30),
dt = min(dt_conv, dt_visc),
with CFL = 0.5, and shrink the last step so that the final simulation time matches T = 0.5 exactly.
Compute the final solution rho(x,T), v(x,T), p(x,T) on the cell centers at T = 0.5.
Save the file "solution_pdebench_cns1d_eta0p1_periodic_smooth.npz" containing the 1D arrays x (length Nx), rho, v, p and the scalars Gamma, eta, zeta, T, dx, CFL.
Save a 3-panel line plot of rho, v, p versus x at T = 0.5 as "solution_pdebench_cns1d_eta0p1_periodic_smooth.png".
Print the minimum and maximum of rho and p as a positivity check and the mean of rho over the domain as a mass-conservation check.
