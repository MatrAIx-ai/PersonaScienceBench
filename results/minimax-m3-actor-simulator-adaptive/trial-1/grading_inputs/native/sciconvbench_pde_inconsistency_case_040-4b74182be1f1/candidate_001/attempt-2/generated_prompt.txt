Solve the 2D heat equation u_t = 0.05 * (u_xx + u_yy) on the periodic domain (x,y) in [0,1) x [0,1) for t in [0, 0.5].
Use alpha = 0.05 as the diffusion coefficient.
Discretize space on a uniform periodic grid with Nx = Ny = 64 points (no duplicated endpoints), so x_i = i*dx and y_j = j*dy with dx = dy = 1/64 for i, j = 0, 1, ..., 63.
Apply 2nd-order central differences with periodic wrap-around to form the discrete 2D Laplacian L.
Apply periodic boundary conditions in both x and y so that u and its first derivatives match across opposite edges.
Set the initial condition u(x, y, 0) = cos(2*pi*x) + sin(2*pi*y) on the grid.
Advance in time using Crank–Nicolson with dt = 0.0025 for 240 steps to reach T = 0.5.
At each time step, assemble the sparse linear system (I - 0.5*dt*alpha*L) u^{n+1} = (I + 0.5*dt*alpha*L) u^n and solve using a sparse direct solver.
Use radians for all trigonometric functions and interpret '^' as exponentiation (using '**' in Python).
At the final time T = 0.5, compute u(x, y, T) on the same 2D grid.
Save the results to "solution_agent_heat_11.npz" containing arrays x (1D, length 64), y (1D, length 64), u (2D array with shape (len(y), len(x)) = (64, 64) such that u[j,i] = u(x[i], y[j]) at T), and metadata scalars T, dx, dy, dt.
Save a heatmap or contour plot of u(x, y, T) as "solution_agent_heat_11.png" (use the u array shape (len(y), len(x)) with appropriate axis labels).
Print the min(u), max(u), and discrete L2 norm sqrt(sum(u^2)*dx*dy) at T.
Evaluate the reference exact solution u_exact(x, y, T) = exp(-0.05*(2*pi)^2*T)*cos(2*pi*x) + exp(-0.05*(2*pi)^2*T)*sin(2*pi*y) on the same grid and print the max absolute error and L2 error sqrt(sum((u - u_exact)^2)*dx*dy) versus the reference.
