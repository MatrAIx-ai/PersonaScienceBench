Solve the 2D heat equation u_t = 0.05 * (u_xx + u_yy) on x in [0,1] and y in [0,1) for t in [0,0.3].
Use a uniform tensor spatial grid with Nx = 60 intervals on [0,1] (producing 61 x-points including both endpoints: dx = 1/60, x_i = i*dx for i=0..60) and Ny = 64 periodic points on [0,1) (dy = 1/64, y_j = j*dy for j=0..63).
Apply Dirichlet boundary conditions u(0,y,t) = 0 and u(1,y,t) = 0 enforced exactly at the endpoint rows.
Apply periodic boundary conditions in y by wrapping indices modulo Ny.
Discretize the spatial Laplacian with second-order central differences: u_xx uses (u[i+1,j] - 2*u[i,j] + u[i-1,j])/dx^2 (with u=0 at i=-1 and i=Nx from Dirichlet), and u_yy uses (u[i,j+1] - 2*u[i,j] + u[i,j-1])/dy^2 with j±1 wrapped mod Ny.
Set the initial condition u(x,y,0) = sin(pi*x)*cos(2*pi*y) using radians for both pi arguments.
Integrate in time with implicit (backward) Euler using a fixed time step dt = 0.001 for 300 steps to reach T = 0.3, so that u^{n+1} = u^n + dt * 0.05 * (Dxx + Dyy) u^{n+1}. Equivalent to (I - dt*0.05*L) u^{n+1} = u^n, where L is the discrete Laplacian; solve this linear system at every time step.
Use direct linear algebra (for example via numpy.linalg.solve or scipy.linalg.solve after forming the full (Ny*(Nx+1)) x (Ny*(Nx+1)) sparse or dense system, or solve each x-line independently exploiting the tensor structure) to advance the solution.
