Solve the 1D wave equation u_tt = c^2 * u_xx on x in [0,1], t in [0, 1.0] with c = 2.
Apply Dirichlet boundary conditions u(0,t) = 0 and u(1,t) = 0 at all times.
Use initial conditions u(x,0) = exp(-200*(x-0.5)^2) and u_t(x,0) = 0.
Discretize space on the closed interval [0,1] with Nx = 800 uniform intervals, giving Nx+1 grid points including both endpoints, with dx = 1/Nx and x_i = i*dx for i = 0,...,Nx.
Approximate u_xx in the interior using 2nd-order central differences: (u_{i-1} - 2*u_i + u_{i+1}) / dx^2.
Use a 2nd-order leapfrog (Störmer–Verlet) scheme for time integration of u_tt.
Enforce stability by setting the target time step dt0 = 0.9 * dx / c.
Compute Nt = ceil(T / dt0) and then set dt = T / Nt so that the final time T = 1.0 is hit exactly.
Initialize with u^0_i = u0(x_i) at all grid points, then compute u^1 using the Taylor start: u^1_i = u^0_i + dt * v0(x_i) + 0.5 * dt^2 * c^2 * (u^0_{i-1} - 2*u^0_i + u^0_{i+1}) / dx^2, with v0(x) = 0.
At every time step, overwrite the boundary values u_{0} and u_{Nx} with 0 to enforce the Dirichlet BC.
Advance the solution from n to n+2 using the leapfrog update: u^{n+1}_i = 2*u^n_i - u^{n-1}_i + (c*dt/dx)^2 * (u^n_{i-1} - 2*u^n_i + u^n_{i+1}).
At the final time T = 1.0, extract the solution array u(x, T) on the spatial grid x.
