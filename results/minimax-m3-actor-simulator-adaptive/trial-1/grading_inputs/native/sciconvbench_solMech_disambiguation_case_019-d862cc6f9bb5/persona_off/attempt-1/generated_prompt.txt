Solve a solid circular shaft carrying two concentrated torques using small-deformation, linear-elastic Saint-Venant torsion theory.
Work throughout in N, mm, and MPa.
Use as inputs: shaft diameter d = 30 mm, total length L = 1200 mm, fixed at x = 0 and free at x = L.
Apply torque T1 = +200,000 N·mm at x = 1200 mm and torque T2 = -200,000 N·mm at x = 400 mm, with signs defined by the standard right-hand rule about the shaft axis.
Use AISI 1020 steel with shear modulus G = 76,923.1 MPa.
Partition the shaft into two segments: segment 1 from 0 to 400 mm and segment 2 from 400 to 1200 mm.
Compute the polar moment of inertia of the solid cross section as J = (π d^4) / 32 ≈ 79,521.6 mm^4.
Deliverable (a): determine the internal torque T(x) in each segment by cutting the shaft and enforcing static equilibrium of the free body to the right of the cut.
State the result for segment 1 as T1(x) = T2 + T1 = -200,000 + 200,000 = 0 N·mm.
State the result for segment 2 as T2(x) = T1 = +200,000 N·mm.
Deliverable (b): compute the maximum shear stress in each segment using τ_max = 16 T / (π d^3).
State the result for segment 1 as τ_max,1 = 0 MPa.
State the result for segment 2 as τ_max,2 = 16(200,000) / [π(27,000)] ≈ 37.72 MPa.
Deliverable (c): compute the angle of twist in each segment using φ_i = T_i L_i / (J G), then sum to obtain the total rotation at x = L.
Use segment lengths L1 = 400 mm and L2 = 800 mm.
State the result for segment 1 as φ1 = 0.
State the result for segment 2 as φ2 = (200,000)(800) / [(79,521.6)(76,923.1)] ≈ 0.02616 rad, which is approximately 1.50°.
State the total angle of twist at the free end as φ_total = φ1 + φ2 ≈ 0.02616 rad ≈ 1.50°.
Verify the small-deformation assumption by confirming φ_total ≈ 0.026 rad, well within linear-elastic torsion theory limits, so the use of superposition and the linear twist formula is justified.
Present all governing relations (equilibrium cut, τ_max, and φ = TL/(JG)) alongside the numerical results, with at least three significant figures.
