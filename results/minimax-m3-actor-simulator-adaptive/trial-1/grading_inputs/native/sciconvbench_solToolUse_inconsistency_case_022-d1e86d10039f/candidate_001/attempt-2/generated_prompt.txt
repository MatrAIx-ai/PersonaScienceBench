Solve a 2D plane-stress linear elasticity problem on a rectangular plate using legacy FEniCS (dolfin).
Define the domain as the rectangular plate with x in (0, 1.0) m and y in (0, 0.20) m.
Generate a uniform structured mesh with 20 cells along the x-direction and 4 cells along the y-direction using dolfin.RectangleMesh or an equivalent legacy mesh constructor, with cell type triangle.
Use a vector-valued continuous Lagrange function space of degree 1 for the displacement field u = (u_x, u_y).
Use a direct linear solver (LU) for the assembled linear system.
Use SI units throughout: metres, Pascals, Newtons.
Set the material parameters to Young's modulus E = 200 × 10^9 Pa and Poisson's ratio nu = 0.30.
Compute the Lamé parameter using the formula lambda = E nu / ((1 + nu)(1 - 2 nu)).
Compute the shear modulus with mu = E / (2 (1 + nu)).
Assemble the 2D constitutive law using the standard isotropic relation sigma = 2 mu eps + lambda tr(eps) I, where eps = sym(grad(u)) is the symmetric strain tensor and I is the 2D identity tensor.
Form the variational problem with bilinear form a(u, v) = integral over Omega of inner(sigma(u), eps(v)) dx and linear form L(v) = 0 with no body forces or boundary tractions.
Apply Dirichlet boundary conditions on the left edge at x = 0: u_x = 0 m and u_y = 0 m.
Apply Dirichlet boundary conditions on the right edge at x = 1 m: u_x = 0.001 m and u_y = 0 m.
Leave the top edge at y = 0.20 m and the bottom edge at y = 0 m as traction-free (zero Neumann) boundaries.
Solve the variational problem with dolfin.solve(a == L, u, bc).
Extract the x-component u_x of the displacement solution as a scalar Function.
Render a colour map of the u_x field (for example, using matplotlib with a sequential colormap) and save it to the file q1_ux.png.
Write the full vector displacement field to an XDMF file (for example, displacement.xdmf) using dolfin.XDMFFile.
