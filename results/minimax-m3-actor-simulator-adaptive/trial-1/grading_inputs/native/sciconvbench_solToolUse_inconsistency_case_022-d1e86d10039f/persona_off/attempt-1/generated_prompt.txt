The specification for case_022 is as follows:
Solve a 2D plane-stress linear elasticity problem using FEniCS legacy (dolfin) with a vector-valued displacement space and a direct linear solver.
The domain is a rectangular plate Omega located in the interval (0, 1.0) meters in the x-direction and (0, 0.20) meters in the y-direction.
Generate a uniform structured mesh with 20 subdivisions along x and 4 subdivisions along y, totaling 80 cells.
Use the material properties E = 200 GPa for Young's modulus and nu = 0.30 for Poisson's ratio.
Compute the first Lame parameter as lambda = E*nu / ((1 + nu) * (1 - 2*nu)) when assembling the isotropic 2D constitutive law.
Compute the shear modulus as mu = E / (2 * (1 + nu)).
Define the strain tensor as the symmetric gradient of the displacement field, epsilon(u) = sym(grad(u)).
Define the stress tensor as sigma = 2*mu*epsilon(u) + lambda*tr(epsilon(u))*Identity(2).
Define the variational form using Galerkin's method with test functions v corresponding to the vector-valued displacement trial functions u = (u_x, u_y).
Integrate the inner product sigma : epsilon(v) over the domain Omega using dx.
Apply Dirichlet boundary conditions on the left edge at x = 0: enforce u_x = 0 and u_y = 0 (fully fixed).
Apply Dirichlet boundary conditions on the right edge at x = 1.0: enforce u_x = 0.001 m and u_y = 0 (prescribed horizontal displacement).
Leave the top edge at y = 0.20 and the bottom edge at y = 0 as traction-free with no explicit boundary conditions applied.
Solve the resulting linear system using a direct linear solver.
Save a colour map (plot) of the horizontal displacement component u_x to the file named q1_ux.png.
Save the resulting vector displacement field to a file in XDMF format, for example displacement.xdmf, using the appropriate XDMF output facilities compatible with dolfin.
