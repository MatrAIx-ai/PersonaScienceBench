Solve a 2D small-strain linear elasticity problem on an L-shaped domain using legacy FEniCS (dolfin).

Use a unit square outer domain with a 0.5×0.5 square cut-out removed from the bottom-right corner (i.e., remove the region x∈[0.5,1], y∈[0,0.5]), so the L-shape consists of x∈[0,0.5] for y∈[0,1] union x∈[0.5,1] for y∈[0.5,1], with the re-entrant corner at (0.5, 0.5).

Mesh the L-shaped domain with 64 elements per edge of the outer and inner squares, using standard triangular elements.

Use material parameters: Young's modulus E = 70e9 Pa, Poisson's ratio ν = 0.33, density ρ = 2700 kg/m³.

Use the reduced plane-stress constitutive law with unit thickness.

Use a vector-valued P1 (or P2) finite element space for the displacement field u = (u_x, u_y) over the L-shaped mesh.

Apply clamped boundary conditions (u_x = u_y = 0) on the entire left edge x = 0, y∈[0,1].

Apply a Neumann traction on the outer right edge x = 1, y∈[0.5,1] with traction vector t = (0, -2.65e4 * x) Pa = (0, -26500) Pa, which is uniform over that edge since x=1 there.

Leave the re-entrant inner boundaries (x=0.5 for y∈[0,0.5] and y=0.5 for x∈[0.5,1]) traction-free.

Impose a body force f = (0, -ρ*g) = (0, -2700*9.81) N/m³ acting in the negative y-direction throughout the domain.

Form the weak form using ε(u) = sym(∇u), σ = C : ε, inner product σ : ε(v) integrated over the L-shaped domain, plus the inner product f · v over the domain, plus the boundary traction integral ∫ t · v on the loaded right edge.

Assemble and solve the resulting linear system using a direct linear solver.

Compute the displacement field u_h and the in-plane Cauchy stress σ_h = C : ε(u_h).

Compute the von Mises stress from the in-plane Cauchy stress components using the plane-stress von Mises formula.

Save the displacement field, the full in-plane Cauchy stress tensor (σ_xx, σ_yy, σ_xy), and the von Mises stress to VTK files for visualization.

Print the displacement magnitude range, the maximum von Mises stress, and a verification that the re-entrant corner stress field is non-trivial.
