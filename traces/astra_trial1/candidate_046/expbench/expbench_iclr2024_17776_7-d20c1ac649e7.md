Para cada modelo verificar su límite efectivo total `L_m`. Reservar **128 tokens propios del modelo para salida**, de modo que el prompt debe satisfacer `tokens_m(prompt) + 128 ≤ L_m` para ambos. Contar también tokens especiales y separadores. No asumir que un token representa igual cantidad de texto en ambos modelos.

Plantilla neutral de continuación, sin instrucciones conversacionales ni marcadores de infilling exclusivos:
1. fragmentos de otros archivos, rotulados mediante comentarios Python con ruta;
2. comentario que identifica el archivo actual;
3. prefijo local, hasta el punto de corte exacto, sin añadir un salto de línea después de ese punto.

Para impedir que fragmentos externos se interpreten como código local contiguo, se mostrarán como comentarios Python línea por línea. Es una **decisión de representación provisional** que puede afectar diferencialmente a los modelos; se registrará literalmente. No incluir nombres de repositorio, metadatos ni instrucciones que no sean necesarios.

**Regla determinista de recorte:**
- Sea `B_m = L_m − 128`. Construir primero el sufijo más largo del prefijo local, recortando solo por inicios de línea, cuyo prompt local con etiquetas ocupe como máximo el 50 % de `B_m` bajo ambos tokenizadores. Si la línea inmediatamente anterior al corte no cabe, conservar su sufijo más largo por caracteres Unicode que cumpla ese límite; registrar este caso.

Añadir fragmentos completos, secuencialmente, cuando quepan bajo ambos límites completos; saltar los que no quepan y registrar sus IDs. No cortar internamente un fragmento externo.

## 4. Generación, extracción y contabilización

Una sola continuación por ejemplo y condición; decodificación greedy, sin muestreo ni búsqueda de prompts en evaluación. Fijar tokens BOS/EOS/PAD, opciones del tokenizador, versiones del motor y semillas donde proceda. Procesar cada prompt sin estado compartido con otros ejemplos.

Decodificar **solo los tokens nuevos**, sin limpieza automática de espacios. Extraer el texto anterior al primer salto de línea; aceptar LF o CRLF como terminadores, sin conservarlos. Si aparece EOS antes, extraer todo lo anterior a EOS. No quitar indentación, no hacer `strip`, no retirar cercas Markdown ni reparar sintaxis. Si no hay terminador ni EOS al alcanzar 128 tokens, extraer todo lo generado y marcar salida truncada.

- **Salidas truncadas:** permanecen y se puntúan tal como se extrajeron; reportar tasa por modelo. No otorgarles excepciones ni descartarlas.
