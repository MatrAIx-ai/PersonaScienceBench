## 3. 建议执行方案（未由输入唯一确定的部分均为方法假设）
### 模型、初始化和更新
采用标准正方格最近邻铁磁 XY：`H=-sum_<ij> cos(theta_i-theta_j)`，J=kB=1，双方向周期边界，beta=1/T。XY 家族和周期性来自任务，具体哈密顿量及单位归一化是必要方法假设。

45 个 (L,T) 点分别从对应 slot 的独立拷贝启动，不采用沿温度退火；固定、记录主随机种子并派生各点独立随机流。每 pass：一次完整局部 Metropolis sweep，随后两次完整微正则局部场反射 sweep，再两次 Wolff 单团簇翻转。Metropolis 增量取均匀 `[-1.13,1.13]`。这里“reflection”为 overrelaxation、“cluster repeat”为一次单团簇、width 为半宽均属方法假设；在代码中明示。

严格先按 113 个热化 pass、116 个测量 pass、每 pass 测普通量、每 5 pass 测径向关联实施。记录能量、m²、键电流、涡旋、绕数、接受率和团簇大小的轨迹及有效团簇覆盖率。检查热化尾部漂移、测量前后半段差异、积分自相关时间和块长稳定性；必要时作选定临界附近点的独立热/冷启动核查。特别防范扭转初态滞留。若配置长度不能支持平衡和误差估计，不把短程结果称为收敛；追加运行需明确标注，不静默改变配置。

### 六项观测量
令 N=L²，正向两方向键和为 E_mu=sum cos(delta_mu)、I_mu=sum sin(delta_mu)。
1. 刚度 `Upsilon = sum_mu[<E_mu>/N - (<I_mu²>-<I_mu>²)/(NT)]/2`，保留连通电流涨落并报告电流均值检查，不截断负估计。
2. 涡旋：每 plaquette 的有向主值角差和除 2pi 后取最近整数 q；密度 `sum |q|/N`，含涡旋与反涡旋。与 `q!=0` 的差别若出现高电荷需报告。
3. 关联 `G(r)=<cos(theta_i-theta_j)>`，用 FFT 周期自相关求所有位移，按最小像距离落入 `[r-0.5,r+0.5)` 的格点位移做等权壳平均，除以 N 的空间平均；G(0)=1 用作校验，输出 r=1..50。径向分箱约定属方法假设。
4. eta(T)：对最大尺寸每个 T 都采关联，用 `7<=r<=24` 的正 G 值作 `log G = a-eta log r` 等权回归，不减磁化平台。配置窗口解释为距离且含两端，不是 Python 切片；主窗口固定，邻近窗口只作敏感性检查。保留所有温度 eta，focus 仅控制输出四条曲线。
5. 定义 `S(k)=<|sum_i s_i exp(ik.r_i)|²>/N`，s 为二维自旋；S1 为两轴最小非零波矢结构因子平均。`xi_2nd/L = sqrt(S0/S1-1)/(2L sin(pi/L))`，先平均结构因子再计算比值，不逐帧平均 xi。非正根号参数应标记并查采样，不盲目截断。
6. `chi = <|sum_i s_i|²>/(NT)=S0/T`，采用零场矢量磁化的非连通有限体积定义，不减 `<|m|>²`。此归一化明确写入代码。

### 外推、偏移扫描和转变选择
所有截距路线按原尺寸顺序用 `x=1/log(L)`，逐温度对 beta*Upsilon 与 xi/L 分别做线性最小二乘，输出截距、斜率各 9 项。刚度截距与 2/pi 交点为其估计；xi/L 截距交点暂采用周期正方格 XY 常用临界目标约 0.7506912（外部理论方法假设，输入未指定，非由本数据证明）。eta 与 1/4 交点形成指数路线。各尺寸原始 Upsilon/T 与 2/pi 的交点作 raw NK 估计，以 L 权重求平均（“size-weighted”具体权重输入未给出）。

交点以相邻温度线性插值，优先物理方向的下降交点（eta 为上升）；若多交点，选择邻近主 WM 估计者并记录歧义。无交点不向温区外盲目外推，使用区间内最小绝对失配作为受边界限制的替代并明确披露。残差字段用相应无量纲目标的有符号失配。

两类扫描均完整覆盖 L_min=`[32,50,68]`，各留 5、4、3 个尺寸，各输出长度 9 的完整温度相对 L2 残差：
- WM：拟合题定 `(2T/pi)*(1+1/[2(log L+C)])`，残差为 `norm(pred-data)/norm(data)`。
- 响应：题定 `A L^(7/4)(log L+C)^(1/8)`；固定 C 时以线性最小二乘消去正振幅 A，再一维搜索 C。

每个尺寸子集约束 `C in [-log(L_min)+0.05,100]`，粗网格覆盖加局部有界细化，检查边界命中，必要时报告扩大上界敏感性；不以接近预期温度作为调 C 目标。在原温度点存 full trace，温度最优值允许在扫描域内对观测量分段线性插值并重拟 C 后细化。默认主选择 L_min=50，避免最小尺寸且保留四个尺寸；L_min=32、68 用于稳定性检查，不因为某三点子集残差更小就自动偏爱它。该选择是预先固定的方法假设。`preferred_transition_temperature` 等于主 WM 估计，summary 使用同一个数；响应估计独立，不替代主估计。两 sweep 的 stability spread 定义为三个最佳温度的标准差。

summary 的 jump ratio 暂采用 beta*Upsilon 外推截距在主 T 处的插值，以对应热力学跳跃；输入只规定 Upsilon/T 而未明确其尺寸来源，因此这是需要声明的选择。residual 严格等于该数减 2/pi。`dimensionless_ratio_at_transition` 严格插值其截距而不是最大尺寸原始值；defect span 严格最大尺寸最高 T 密度减最低 T 密度。

### Jackknife、共识和误差
116 个普通测量按连续时间分成 4 个等长块（每块29 pass）；径向测量按对应 pass 归块。删除块后重新计算所有非线性量、径向指数、外推、偏移优化和转变，不能只对最终温度或已拟合误差做 jackknife。主尺寸阈值及拟合窗口固定，不在删块样本间切换。误差用 `(B-1)/B * sum(theta_-b-mean)^2` 开方。四块仅为配置长度下的初始方法选择，需验证块长相对自相关时间；4/更细分块的敏感性不能弥补实际样本不足，失败时明确说明。

component 数组严格按 `[WM, size-weighted raw NK, beta*Upsilon intercept, xi/L intercept, eta=1/4]`；response 单列诊断而不添加成第六 component。共识暂取五路线算术均值，避免相关估计被错误当作独立逆方差加权；共识标准差表示路线差异，共识 uncertainty 由每个 jackknife 副本重算均值得到。summary transition_estimate_spread 同取路线标准差，主温度仍是 WM，不与共识混用。
