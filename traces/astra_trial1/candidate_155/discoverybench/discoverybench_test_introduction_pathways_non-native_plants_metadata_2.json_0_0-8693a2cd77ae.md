### 先严格区分三个问题
1. **主要指标：样地出现率**。各生境内 count(n.gard>0)/样地数，包括所有零值样地。它最直接回答“在该生境的受调查位置，遇到至少一种园艺引入非本地植物有多普遍”。后续报告分子、分母、比例及区间；解释限于受调查样地。

### 比较及稳健性
