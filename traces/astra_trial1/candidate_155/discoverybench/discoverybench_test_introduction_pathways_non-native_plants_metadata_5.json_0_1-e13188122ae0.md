基本环境调整中园艺、无意途径的正斜率通过同一调整层次九暴露×三途径的27项Holm校正，p分别0.0075和约0.000001；农林途径未通过。**这不意味着途径之间斜率已经证实不同。**

直接比较基本环境调整模型的斜率，计数比之比为：
- Gardening / Unintentional：0.971（0.921–1.024）；
- Gardening / AgriForest：1.052（0.945–1.172）；
- Unintentional / AgriForest：1.084（0.966–1.217）。

三组差异的Holm校正p均大于0.51，联合两自由度Wald p=0.324。进一步调整后的联合p也约0.324。因此不能凭“两条显著、一条不显著”宣称三种途径对城市土地利用的响应有明确差异。

### 2. 实际拟合的公式与选择
对样地 i、途径 k：
`Y_ik | b_i ~ Poisson(lambda_ik)`；
`log(lambda_ik) = alpha_k + beta_k * urban_i + gamma' Z_i + b_i`；
`b_i ~ Normal(0, sigma²)`。

三类途径分别有截距和城市覆盖斜率；样地随机截距处理同一样地三种计数的依赖。其余协变量系数跨途径共享，避免AgriForest仅21个阳性位置时过度参数化。这一共享约束是需保留的模型限制。

- **基本环境调整**：同年同尺度耕地、海拔、年降水、年辐射、log(1+距水道距离)。数值协变量标准化。
- 海拔与温度r=-0.958，不同时加入；另做温度替代海拔敏感性分析。海拔与降水仍相关（r=0.861），VIF约6.61/5.84，已如实保留共线性风险。
- **进一步调整**：加入生境九个哑变量及log(1+道路距离)。这些变量可能是混杂，也可能处于城市化相关路径上；故不把充分调整模型称为已辨识的直接因果效应。
- **空间敏感性**：增加标准化原始坐标的 `x+y+x²+xy+y²`。没有把距离标为公里。

使用Poisson-lognormal分层模型、40点Gauss–Hermite积分极大似然；区间使用样地积分似然得分的聚类sandwich协方差。随机截距已允许过度离散；充分调整后的边际离散度接近1，未另加负二项或零膨胀成分。没有模型不收敛而被隐瞒删除的情形；另以样地聚类Poisson GEE检验对分布假设的敏感性。

### 3. 完整年份—尺度敏感性
**其余八项均已分析，没有择优筛选。**九个组合×基本环境/生境道路/空间三种调整的完整计数比、区间、校正p及直接途径差异，见 `results/report.md`、`effects.csv`、`contrasts.csv`。

主要模式是：
- 基本环境调整下，Gardening与Unintentional在九个组合的点估计均为正；不是每个组合均有充分统计支持。
- 加入生境和道路后，大多数园艺/无意引入关联明显减弱，主暴露区间均跨1。
- 农林途径在全部六个标称500/1000m组合的充分调整模型中呈负关联。空间调整后，1993.1000m和2009.1000m计数比分别为0.628（0.488–0.808）与0.714（0.589–0.866），仅样地聚类推断的27项Holm p为0.0078/0.0159。
- **改用原始坐标相对分位网格的24个空间块推断，再对27条斜率作Holm校正后，没有一条通过0.05；最小校正p=0.144。**因此这些农林负关联只能保留为尺度依赖提示，不能作为稳健确认结论。
- 城市覆盖各年份/尺度间r约0.56–0.96。未同时加入九个高度相关城市变量，也未进一步拟合历史变化或引入时间模型。

### 4. 关键诊断
- **收敛**：28个主要及敏感性模型全部报告优化成功；Hessian最小特征值均为正，最小约0.0246。主暴露三个调整模型最大梯度绝对值约0.00010–0.00015。40→80点积分最大参数变化分别0.00190、0.000003、0.000001。
- **离散度**：主暴露基本/充分/空间模型的边际Pearson统计量除以近似剩余自由度为1.334/1.100/1.212；随机截距SD为1.108/0.763/0.723。该指标是诊断，不是正式离散度检验。
- **零值**：实际三类零值515/487/611；充分调整预测519.2/476.8/610.1。1200次预测模拟中观察零值均在95%范围内，不支持仅因为零多就增加零膨胀模型。
- **重要失配**：基本环境调整模型预测尾部过重。实际园艺/无意最大计数4/7，而模拟最大值95%范围约6–32/9–63；充分调整后改善为4–13/6–22。报告没有将零值拟合良好夸大为整个分布拟合完美。
- **空间残差**：8近邻、999次置换。基本调整后无意途径残差Moran I=0.072、p=0.003；充分调整为0.029、p=0.094；加空间趋势后0.013、p=0.451。后者园艺/农林为-0.016/-0.006，p=0.328/0.759。未检出不等于不存在空间依赖。
- **空间块**：16、24、34非空块的主暴露敏感性均保留基本调整中园艺和无意途径的正关联，而充分/空间调整后仍跨1。
- **GEE检查**：基本环境调整的Poisson GEE计数比为1.066（1.009–1.126）、1.097（1.050–1.147）、1.011（0.897–1.139）；充分及空间调整后均跨1。二元出现GEE也表现出同样调整依赖性，但其效应量是优势比。
- **非线性**：城市二次项联合Wald p在基本/充分/空间模型中为0.029/0.056/0.137。基本模型中正关联偏重于低城市覆盖区间，高覆盖区间变弱。因此线性模型的每0.1比值只能作模型摘要，不能称为所有覆盖水平都恒定增加。
- **影响点/替代协变量**：基本模型最有影响位置分别真实删除重拟合后，园艺计数比1.103–1.109、无意1.140–1.151，方向未变；温度替代海拔也保持调整层次依赖性。AgriForest的不确定性更大。
- **共同支持**：主暴露非零值分布不均，Urban生境57/65、Scrublands仅6/106；生境间比较和标准化预测均需谨慎。

### 5. 最终解释边界
支持的是“具有园艺或无意引入途径的植物，在城市覆盖较高位置的计数往往较高”这一**有条件、调整敏感的关联假说**，不是城市化造成更多引入事件的结论。加入生境/道路后衰减，既可能表示环境结构解释关联，也可能表示调整了城市化路径，资料无法区分。
