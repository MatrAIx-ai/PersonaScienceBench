# 基本分子性质提取与分析：最终实验设计

**状态：仅完成设计，未执行实验、安装依赖或生成分析结果。**

## 1. 研究目标与方法理由
目标是建立可审计的流程，从化学结构提取基本二维分子描述符，量化数据质量，并描述性质分布及性质间关联。

采用二维描述符的理由是：不要求三维构象或量化计算，适合小分子的初步数据概览，且便于复核。计算 logP 等属于模型输出，不等同于实验测量；本设计不预测药效、安全性或因果关系。

**已知条件**：任务仅要求设计；尚无实际数据集。所提供环境为系统 Python、项目依赖未预装、网络关闭、无 GPU。

**设计假设**：未来输入为带 ID/SMILES 的小分子表格，以 RDKit 计算二维描述符。这些不是已确认的数据或软件资源。以下默认选择足以指导后续实施，不依赖额外来源答复。

## 2. 输入要求及分析单位
### 输入
默认读取 UTF-8 CSV，必需字段为 `record_id`、`smiles`，均按字符串读取；保留原始行号和全部原始字段。可接收 TSV，但须在配置中明确分隔符。

- `record_id` 缺失或重复时不直接删除分子，增加内部唯一 `row_uid`，记录 ID 异常。
- 空白 SMILES 为缺失；只去除字段外围空白，不改写内部字符串。
- 不自动把名称、CAS 号或其他标识符转换为结构，不联网补全。
- 未来实施须取得数据文件、合法使用权限、离线软件及锁定版本。

### 主分析纳入范围
主分析采用以下明确、偏保守的范围：
1. RDKit 能解析并通过完整 sanitization；
2. 恰好一个连通组分；
3. 含至少一个碳原子，元素限于 H、C、N、O、P、S、F、Cl、Br、I；
4. 无自由基、无查询原子或通配原子；
5. 所有原子的形式电荷均为零。

这排除了离子、两性离子、金属配合物及多组分条目，也不代表这些结构本身错误。允许同位素和未指定立体化学，但记录标志。元素和电荷限制是为保证本次性质解释的统一性，不是普遍化学有效性标准。对每项排除原因分别标记，并给出一个确定顺序的首要原因以制作不重叠流程统计。

### 多组分与其他范围外结构
- 只要解析结果有多个连通组分，就标记 `multi_component`；仅凭点分隔不能断言它一定是盐、溶剂化物还是混合物。
- 保留整个输入和组分数，不自动取最大组分，不脱盐、不去溶剂、不做中和，也不纳入主分析。
- 可为有效的范围外结构保留整条结构的分子式、质量、重原子数和形式电荷作为审计信息；这些是**输入表示的整体属性**，不是母体分子的性质。
- 默认不为范围外结构生成 logP、TPSA、HBD/HBA、环数和可旋转键的主分析结果；相应值为 NA 并附原因。尤其不将多组分记录的计算 logP 解释为单一分子的物性。
- 未来若有明确母体映射依据，可另建衍生分析；本设计不默认实施该分支。

### 唯一结构判定
在成功解析的结构上，使用 RDKit 默认芳香性处理、去除普通可移除显式氢的标准处理，并生成 canonical isomeric SMILES 作为 `structure_key`。保留同位素、形式电荷及已指定立体信息，不中和、不做互变异构体归一化。普通显式氢处理的参数须写入配置；同位素氢不得静默丢弃。

- 相同 key 定义为本流程中的同一结构，不按名称或 ID 去重。
- 互变异构体、不同质子化状态、不同指定立体异构体分别保留。
- 未指定立体化学不作为匹配任意已指定立体异构体的通配条件。
- key 依赖 RDKit 版本，不宣称是跨软件的绝对化学同一性判据。

**统计用途**：结构层面每个主分析 key 权重为 1，作为主要结果，避免重复录入主导分布；记录层面保留每行权重为 1，作为输入数据实际构成的补充结果。两者差异用于显示重复权重的影响，不默认把重复行视为独立实验重复。

## 3. 描述符定义、单位与拟用实现
锁定版本后使用下列 RDKit 接口；实施时先检查其签名和枚举可用性，不允许静默替换为另一算法。

| 描述符 | 定义及单位 | 拟用实现 |
|---|---|---|
| 分子式 | 包括隐式氢；显示同位素区别；无单位 | `rdMolDescriptors.CalcMolFormula`，明确 `separateIsotopes=True`、`abbreviateHIsotopes=False` |
| 平均分子量 | 原子量加和，通常按自然丰度平均；指定同位素按工具规则处理；数值对应 g/mol 的摩尔质量 | `Descriptors.MolWt` |
| 重原子数 | 非氢原子数，整数 | `mol.GetNumHeavyAtoms()` |
| 形式电荷 | 各原子形式电荷之和，以基本电荷为单位 | `Chem.GetFormalCharge` |
| HBD、HBA | 指定规则下的氢键供体数、受体数，整数，不是氢原子总数 | `rdMolDescriptors.CalcNumHBD`、`CalcNumHBA` |
| 可旋转键数 | 使用 RDKit 的 Strict 定义，整数 | `CalcNumRotatableBonds(..., NumRotatableBondsOptions.Strict)` |
| 环数 | RDKit 感知的环计数，整数，不是所有可能简单环的数目 | `rdMolDescriptors.CalcNumRings`；记录其版本对应的环感知定义 |
| TPSA | 拓扑极性表面积，Å² | `rdMolDescriptors.CalcTPSA(..., includeSandP=False)`；采用默认不计 S/P 极性贡献的版本 |
| 计算 logP | Wildman–Crippen 原子贡献模型估计的辛醇/水分配系数对数，无量纲 | `Crippen.MolLogP`，记录默认氢处理方式 |

主分析的形式电荷按纳入规则恒为零；保留该字段用于审计，但不纳入相关矩阵。TPSA 的 S/P 选择需在图表和方法说明中披露。分子量不是单同位素精确质量；本方案默认不输出后者。计算 logP 不是指定 pH 的 logD。

| 乙酸 | `CC(=O)O` | C2H4O2 | 60.052 | 4 |

要求：均通过主分析纳入；元素计数、重原子数、净电荷完全一致；质量与手算值绝对差不超过 0.02 g/mol。分子式比较按元素计数，而非仅比较排版字符串。

### 等价表示与身份边界对照
- `CCO` 与 `OCC`：key 相同，整数描述符完全相同，浮点值差不超过 `1e-6`。
- `c1ccccc1` 与 `C1=CC=CC=C1`：芳香性处理后应获得同一 key，描述符满足上述一致性要求。
- `CCO` 与 `[H]OC([H])([H])C([H])([H])[H]`：普通显式氢处理后同一 key、同一结果。
- `F[C@H](Cl)Br` 与 `F[C@@H](Cl)Br`：key 必须不同；两者二维描述符可能完全相同，不据此判为重复。
- `[13CH4]` 与 `C`：key 必须不同，前者需保留同位素标志；不将自然丰度质量参考强用于同位素结构。
- 同一 SMILES 输入两行：记录层面计数增加，结构层面只计一个；原 ID 不被覆盖。

### 异常及范围外对照
| 输入 | 预期处理 |
|---|---|
| 空字符串、仅空白、缺失字段 | 标为缺失结构，不能当成有效零原子分子 |
| `C1CC` | 未闭合环解析失败；隔离并记录原因 |
| `[CH5]` | 价态/sanitization 失败；不得强制接受 |
| `CC(=O)[O-].[Na+]` | 可解析的多组分盐样输入；排除主分析，logP 为 NA |
| `CCO.O` | 多组分；不自行认定水是否应移除；logP 为 NA |
| `C[NH3+]` | 单组分带电；排除主分析 |
| `[NH3+]CC(=O)[O-]` | 净电荷零但有带电原子；仍排除主分析 |
| `[CH3]` | 自由基；排除主分析 |
| `*CC` | 通配原子；排除主分析 |

### 模型描述符和流程验收
- HBD/HBA、环数、旋转键数必须为非负整数；TPSA 非负；质量为正；所有成功的浮点结果须有限。logP 允许为负，不设武断“合理区间”。
- 核对简单规则：甲烷 HBD/HBA、环数、可旋转键数均为 0；乙醇 HBD/HBA 均为 1；苯环数为 1。若不符，检查接口、氢处理和结构，而不是修改参考以迎合输出。
- logP/TPSA 验证采用等价表示一致性、序列化后重解析一致性，以及锁定版本的上游同定义测试例（若离线可得）。没有独立同定义值时，明确只完成一致性验证，不声称验证预测准确性。**不要求计算 logP 与实验 logP 完全一致。**
- 对全部唯一主分析结构做 canonical SMILES 重解析；要求 key 稳定，整数结果完全一致、浮点差不超过 `1e-6`。失败结构隔离并调查，不能悄悄保留其中一次结果。
- 输入行数必须等于各互斥终止状态行数之和；表之间映射不得丢行或倍增；相同 key 的映射结果必须一致。
- 对照失败、环境签名不符或记录守恒失败：阻断正式统计，修复后从预检重跑。真实记录解析失败本身不等于流程失败：保留它们，报告损失率后分析有效子集。
- 主分析无有效结构时只交付质量报告；不生成虚假的分布或相关矩阵。个别描述符失败时按性质报告实际样本数，不填补、不将整个记录的其他有效性质一并删除。

## 6. 描述性统计与相关分析
### 质量与覆盖率
报告总记录数、可解析数、主分析记录数、主分析唯一结构数，以及每项失败/排除原因。明确分母是全部输入、已解析集合还是主分析集合。若有实际分组字段，补充各组保留率，检查结构过滤是否产生明显不均衡；不假设当前存在分组。

### 分布
每个性质分别报告有效 n、缺失 n/比例、中位数、Q1/Q3、最小值、最大值；补充均值和样本标准差（n<2 时标准差为 NA）。分位数采用线性插值并记录实现。计数性质用频数图；连续性质优先用经验累积分布图及箱线图，避免任意分箱支配解读。

箱线图的 1.5×IQR 规则仅标记待回查值，不自动删除。极端值先回查原始结构、适用范围及单位。正式汇总默认不缩尾、不插补。

### 相关关系
主分析在唯一结构表中，对分子量、重原子数、HBD、HBA、旋转键数、环数、TPSA、计算 logP 计算 Spearman 秩相关。并列值取平均秩；每对使用完整观测，输出配对样本数。任一变量无变异或配对 n<3 时结果为 NA 并注明原因。小样本结果不作稳定性保证。

输出相关矩阵及预先选定的散点图：分子量—重原子数、分子量—计算 logP、TPSA—计算 logP、TPSA—HBA。点重叠严重时采用透明度或二维分箱，不改变计算样本。记录层面重复同样统计作为权重敏感性分析。

不默认开展显著性检验或多重筛选，因此不产生以 p 值为中心的结论。分子大小和描述符共同计算定义会导致关联，相关性不代表独立机制或因果。若未来需要实质分组比较，应另行预先明确问题及独立观测单位，而不是看到结果后挑选组别。
