### 4.1 TA：对抗 Taboo
- 从封闭英语常用词池抽取目标。发送者看见目标及一张结构化语义卡，接收者仅看见公共规则和对话。接收者不知道目标。
- 发送者试图使接收者在自己的自然语言回复中说出目标；接收者试图作出相关回答，同时避免被诱导说出隐藏目标。
- 最多 8 个交替轮次，每条消息最多 64 个生成 token。接收者输出经预先锁定的大小写、标点和词形规则匹配目标即终止成功；满轮未出现则失败。目标匹配表不在观察结果后修改。
- 发送者不能直接输出目标及预定义词形、拼写拆分、翻译、编码或引用要求。接收者不能靠空串、拒答或固定无关文本规避，须满足最低相关性/回答要求。规则判定优先程序化，语义争议使用冻结、盲于组别的裁判并抽样人工复核。
- 有效 episode 中，发送者成功得 +1、失败得 −1；接收者奖励相反。任何一方违规立即终止，违规方 −1、另一方 0；同时违规均 −1。异常裁判或环境故障不作模型输赢，按预定重试规则处理并记录成本。

### 4.2 Q：合作 20-Question
- 回答者知道秘密实体和权威属性表；提问者只知道公共候选领域与历史回答，不知道实体。
- 提问者可提出最多 20 个属性问题，每回合也可用明确标记提出一次最终猜测。回答者只能输出“是/否/未知”，由属性表或冻结语义解析验证，不得用解释、首字母或编码泄露答案。
- 正确最终猜测终止；错误最终猜测或问题预算耗尽终止失败。有效 episode 成功双方 +1，失败双方 −1；违规规则与 TA 相同。不设置轮数效率奖金。

### 4.3 C：合作 Guess-My-City
- 知情者看见城市及审核过的事实卡；猜测者知道公共候选城市集合和对话历史，不知道目标城市。
- 最多 8 轮，每条消息最多 64 个生成 token；知情者提供或回答事实线索，猜测者询问属性或提出一次最终猜测。
- 禁止知情者输出城市名、别名、名称翻译、唯一行政代码、直接拼写及编码。猜测者可在最终答案字段说出城市名。事实一致性由卡片核验。
- 正确最终猜测成功，错误最终猜测或到限失败；有效 episode 双方奖励同 Q，违规规则相同。

城市和实体任务的固有知识需求仍不相同，不能通过等 token 消除。这正是跨游戏结论不能等同于机制结论的原因。

### 4.4 TC：合作 Taboo 与防平凡策略
TC 保持 TA 的目标池、语义卡、角色可见信息、轮数、匹配规则、消息限制和行动合法性不变。仅把接收者目标改为“根据发送者的合法表达推断并说出目标”，有效 episode 双方成功 +1、失败 −1。TA 和 TC 的发送者目标一致，接收者的利益关系改变。

为防止 TC 退化为直接报答案或“某常见词的同义词是什么”：
- 两组发送者均使用相同受约束的线索接口：每轮从语义卡选择一个尚未披露的宽泛属性，再作受限表达；接收者可提问或作相关回复。禁止自由提交定义式同义词、字母位置、长度、谐音、翻译与代码。
- 每个合法线索须适用于候选池中至少 5 个目标；前两条线索的组合须至少兼容 3 个目标；完整卡仍应可识别目标。阈值为规划值，在可行性先导后、正式效应试验前锁定。两组都使用相同过滤后的卡片与模板。
- 先导中测试直接复制、唯一线索、枚举全词池、空答、固定拒答、隐写映射等基线；接收者每轮最多提出一个明确候选，禁止枚举词表。样本审计须同时检查 TA 与 TC。
- 通过预先生成的卡片统计与盲审验证不存在首轮唯一线索、可见答案、违规通道；再比较简单合法基线与多轮推理基线。若最简单的单线索策略已接近满分，或 TA 在这些约束下不再有有效策略空间，不宣告机制对照成立。

这些约束会使 TA 变成受约束的 Taboo 变体，不能宣称忠实复现原 SPAG。TC 的难度变化可能是目标关系的中介，不应按最终模型表现事后重采样“配平”。若规则必须大幅改变才能让两组可玩，则停止机制主张，保留整体方案比较，并公开失败的可比性审核。

## 五、自我博弈、角色权重与预算

**拟议更新算法**：采用 episode 终局奖励的 PPO，加相对本种子 I 模型的固定 KL 惩罚，所有组使用同一系数和裁剪/学习率设置。环境奖励与 KL 项分别记录。不得对某组独立进行有利的奖励重标度；奖励尺度敏感性属另行预注册扩展。

每个组内部两角色共享一个策略参数，通过角色提示区分。每个 rollout 批次开始时冻结当前策略副本，由其扮演双方生成整批 episode；收集完成后统一更新，再刷新副本。各组之间不互相对战、不共享训练轨迹。每次更新分别计算两角色的有效行动 token 损失，按角色各 0.5 加权，避免多话角色占主导。无效行动同样记录并接受已定义处罚，不仅训练成功 episode。

**主匹配原则**：固定每个自我博弈组和 S 的累计训练目标 token 数 T、每次更新 token 数 b、优化更新数 U=T/b，以及优化重复使用次数。提示 token 不计入目标 token，但计入算力账目。使用完整 episode 计算回报，随后按预定队列打包训练；末批超额部分不训练，仍计入生成成本。不得因某组 episode 更短而多做更新。

除训练 token 外，分别记录提示/行动/裁判 token、采样 episode 数、有效率、重复利用、平均轮数、生成 GPU 小时、优化 GPU 小时、峰值显存和 API 费用。角色损失权重并不保证两个角色恰好各占一半原始生成量，须报告实际分布。20 问与 8 轮不同会产生额外生成成本；因此主结论是等学习预算下的效应，不自动是等总费用下的效应。

S 以相同 T、b、U 和可训练参数继续 SFT；由于无需 PPO rollout，其总成本通常不同。可选在固定总 FLOPs/费用下比较完整成本—效益曲线，不能声称 SFT 与 PPO 的等 token 就是等算力。

## 六、独立推理评测与污染控制

预注册主评测为三个等权领域：
1. GSM8K 官方测试集：数值多步推理，标准化最终数值精确匹配。
2. FOLIO 官方验证集：演绎推理，规范化三分类标签准确率；该集只作本研究测试，不用于开发。
3. 新生成的 1,000 道有界规划问题：小型 Blocks World 与图路径约束各 500 题，生成器保证可解，提交动作序列由独立程序检查。模板、难度层级、生成种子在训练前承诺并由不参与调参的一方保管。

示例性选择在正式注册时须核验下载、许可、解析器正确性及上下文适配；若不可获得，先修订注册，不能看效果后替换。主指标为三领域准确率的等权平均，单位为百分点：M=(M_math+M_logic+M_plan)/3。任务内每题等权，规划子类型各占一半。游戏胜率、长度及违规率只作过程指标，不纳入 M。

统一零样本提示与最终答案字段，允许简短推理；固定 greedy 解码、最大 1,024 个生成 token、无工具和单次回答。正式评测采用预算末 checkpoint，不按测试成绩早停或挑 checkpoint。对输出截断和格式错误使用预注册评分规则，不为个别组人工宽免。

公开基准可能已在基础模型预训练中出现，不能保证无污染。共同起点可减少但不能消除其影响。生成示范和游戏数据禁止引用评测题，按规范化精确匹配、n-gram 和近似相似度扫描，命中项按盲审规则从训练数据剔除。新规划题采用未用于开发的结构组合，并报告其单独结果；训练团队在冻结前不接触测试实例。知识游戏与测试之间不共享城市/目标答案构造，所有训练、开发、评测清单及哈希留档。

## 七、估计量、假设与判定

对种子 s、组 a，定义后续增益 g(s,a)=M(s,a)−M(s,I)。相对基础 B 的总增益作为次要描述。

**两项主要比较**：
- θ_Q=E_s[g(s,TA)−g(s,Q)]；
- θ_C=E_s[g(s,TA)−g(s,C)]。

共同 I 在配对差中抵消，但仍须报告各组增益，避免把“退化较少”表述为“推理改善”。规划的实际意义阈值 δ=1.0 个聚合百分点；该阈值是研究者须在正式注册时认可的价值判断，不是由现有结果估算。

对 H_Q:θ_Q≤δ 和 H_C:θ_C≤δ 使用单侧配对种子检验，按 Holm 在家庭错误率 0.05 下校正。提供每项双侧 95% 区间，并提供与主要判定一致的多重比较调整单侧下界。只有两项均拒绝且 TA 自身平均增益为正，才称“对两种非对抗设置均具有实际意义的相对优势”；若还要称“确认推理获得改善”，另要求 g(TA) 的单侧 95% 下界大于 0。这一额外条件只收紧结论。若仅超过一组，则明确指出对象；若只排除 0 未超过 δ，只称小幅统计优势；不显著不等于等效。

机制估计量为 φ=E_s[g(s,TA)−g(s,TC)]。它作为独立标注的机制次要问题报告，不用其显著性挽救主要比较。若要作确认性局部机制主张，预注册层级检验：仅在两项主要检验均通过且可比性审核通过后，以单侧 0.05 检验 φ>δ；否则只报告估计与探索性区间。即使 φ 为正，解释也限于此处竞争/共同目标与角色指令组合，而非脱离奖励的抽象对抗性。

## 八、重复、区间和样本量

训练种子是核心重复单位。每种子在所有组间配对，同一测试题集用于所有模型。主要分析对每个种子的聚合差进行配对 t 推断；另做配对种子 bootstrap 和符号翻转敏感性分析，说明小样本区间局限。不能把数千测试题当成数千次独立训练。

主推断条件于固定评测套件。推广到题目总体的次要分析采用分层双重 bootstrap：重采样种子，再在各评测领域内同步重采样题目；重新计算完整等权指标。领域分数、种子散点和各模型均值均公开。

**规划数值而非预算承诺**：先导考虑每组 3 个独立种子，正式研究以至少 8 个、目标 12 个配对种子作为起点。先导仅用于规则有效性、方差和成本估计，不并入确认性样本；若只能做到 3 个正式种子，标为可行性研究，不宣称充分功效。

用先导的两项种子配对差标准差估计，并对小样本不稳定性作保守上调。按 Bonferroni 单侧 α=0.025 近似规划，最终仍用 Holm。若希望真实差为 δ+Δ 时有 80% 功效，初算 n≈[(z_0.975+z_0.80)σ/Δ]^2，再用 t 分布或模拟校正；例如可规划 Δ=1 个百分点，但不得称它是预期真实效应。取两项比较所需 n 的较大值；联合“超过两者”的功效另用保守假设或配对协方差模拟检查。n 在正式阶段前锁定，不按中期显著性追加。

基础设施失败可按相同种子重启；学习崩溃、违规高发或低分不是可剔除的技术异常。未完成运行及原因全部披露，不能只报告成功种子。

## 九、可行性、成本与实施关卡

当前环境无 GPU、无数据集、网络不可用，只适合设计材料核查，不足以执行本训练。未要求安装依赖或运行实验。

可作规划的单分支量级：共同 SFT 约 3M 监督 token（每游戏约 1M），每个后续训练分支 T≈10M 目标 token，b=32,000 token、U约 313；正式注册需调整 T 为 b 的整数倍。上述量级不保证收敛、功效或可支付，先导后统一锁定，不能按组分别延长。

成本账目按以下方式估算：
- GPT-4：示范输入、输出、审核和重试 token × 对应价格；示范池生成成本属于共享前置成本，专属分支另计。
- 本地训练：每种子共同 SFT 成本 + 每分支 rollout、PPO 前后向/价值与参考模型、SFT 控制成本；以实际 token 吞吐和峰值显存估算 GPU 小时，再乘种子和组数。
- 评测：模型数 × 测试题数 × 实际输入/输出长度，另计环境裁判。
- 开发、失败采样、先导和超参数搜索全部单独列账，不从训练总费用中隐藏。

可行性先导依次检查规则引擎/奖励单元测试、角色信息泄漏、卡片可辨识性、平凡策略、格式有效率、吞吐与显存、奖励方差及独立评测解析器。先导不得用正式测试准确率选游戏规则。若规则修改，记录修改并重新冻结后再开始确认性训练。

**最小核心**：一个模型，共享示范池，B/I/S/TA/Q/C，预算末独立评测及足够配对种子。**机制核心增加** TC 及可比性审核。**扩展优先级**：内容匹配 SFT 对照 → 专属示范分支 → 成本曲线/奖励稳健性 → 其他游戏目标交叉与第二模型。预算不足时先减扩展，不能以伪重复代替种子重复。

## 十、解释边界及严格复现前核对事项

- TA 超过 Q、C 且自身改善：支持此共同起点、模型、预算、评测下的整体训练方案优势；不单独支持对抗目标机制。
- TA 同时超过可比 TC：增加对 Taboo 内竞争目标局部作用的支持；还需报告适应负担、轨迹分布与奖励可达性差异。
- TA 超过 Q、C 但不超过 TC：更符合 Taboo 内容或交互结构有效，不能把优势归因于对抗。
- TA 超过 TC 但没有超过两游戏：局部目标效应不等于跨游戏整体优势。
- 仅游戏胜率提高而独立推理不提高：不能回答为推理增益。
- 区间宽、退化或未显著：按区间报告，不作等效或普遍无效判断。

严格复现 SPAG 前仍必须核对论文或作者材料中的：基础模型与初始化、GPT-4 版本及示范构造、各游戏真实角色与观察、奖励/终止和违例处理、更新算法与角色训练安排、训练及生成预算、超参数、原评测和过滤规则。若原规则与本设计不同，应另设明确的复现分支，不能在报告中把本方案重新命名为原 SPAG。
