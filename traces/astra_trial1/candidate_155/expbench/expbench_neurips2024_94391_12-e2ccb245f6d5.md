输入 X∈R^(B×L×C)，标准化后记 Z；每个样本起点 t_b 为统一网格整数索引。模板 Q∈R^(P×C)，初始化全零，主干参数 W∈R^(H×L)、d∈R^H，跨所有变量共享。

历史相位 i_hist[b,l]=(t_b−L+l) mod P，l=0,…,L−1；未来相位 i_fut[b,h]=(t_b+h) mod P，h=0,…,H−1。索引得到 Q_hist∈R^(B×L×C)、Q_fut∈R^(B×H×C)。

R=Z−Q_hist；U=transpose(R,1,2)∈R^(B×C×L)。共享线性层 V=UW^T+d∈R^(B×C×H)，输出 Z_hat=transpose(V,1,2)+Q_fut。最终 X_hat=μ+s·Z_hat。所有模板减加均发生在固定标准化尺度内。

用 PyTorch Linear 的默认初始化作为 W、d 初始化，记录框架版本；配对模型使用相同种子的同一初始 W、d 和窗口顺序。Q 和主干联合训练，不对 Q 使用显式平滑或额外正则。Q 与线性层存在分解不可辨识性，因此不将学到的 Q 直接解释为唯一真实周期，只评价预测及对照差异。

简短伪代码：
```
forward(x_filled, t, Q, linear):
    z = (x_filled - mu) / scale
    ih = (t[:, None] - L + arange(L)) % P
    jf = (t[:, None] + arange(H)) % P
    r = z - Q[ih]
    pred_z = linear(r.transpose(1, 2)).transpose(1, 2) + Q[jf]
    return pred_z

fit(train_windows, val_windows):
    seed_all(seed); initialize_parameters()
    for epoch in range(max_epochs):
        for x, y, observed_mask, t in shuffled_train_batches:
            pred_z = forward(x, t, Q, linear)
            target_z = (safe_observed_targets(y) - mu) / scale
            # 避免 NaN*0；以布尔索引或安全填充值计算有效元素
            loss = mean_over_variables_of_masked_MSE(pred_z, target_z)
            optimizer.zero_grad(); loss.backward()
            clip_grad_norm_(trainable_parameters, 1.0); optimizer.step()
        score = validation_macro_standardized_MSE()
        save_if_improved(score); stop_if_patience_exhausted()
    restore_best_checkpoint()
    evaluate_test_without_parameter_updates()
```

## 4. 对照、消融与敏感性
每种方法使用相同窗口、历史可用性、掩码及尺度统计。
1. **主要对照：无周期共享线性模型**，直接对 Z 使用同一 Linear(L,H)，没有 Q；主干初始化和训练配置配对。
2. **固定模板残差模型**：Q_fix[p,c] 为训练段标准化原始观测在相位 p 的均值，冻结；减去、线性预测、加回步骤相同。某相位无观测时置零并报告。它检验端到端学习模板相对经验周期均值的增量。
3. **季节朴素预测**：重复预测起点之前最近一个完整 P 点片段；未来 h 使用输入位置 t−P+(h mod P)，即使 H>P 也不读取未来标签。
4. **持续预测**：各变量重复最后一个可用输入值。
5. **固定模板单独预测**：输出 Q_fix 的未来相位，无残差主干。

可选消融：保持 L、H 不变比较 P=12、24、168，分别训练并仅在验证集选择；P=24 保持为预指定主分析，其他周期作为敏感性，不能事后替代主结果。

错误相位诊断：冻结训练好的 P=24 完整模型，保持输入、历史模板和残差输出不变，仅将未来加回模板替换为 Q[(t+h+δ) mod P]，δ=6、12。记录相对正常前向的误差变化。这是人为破坏预测端相位一致性的敏感性测试，不是部署基线，也不是训练中整体平移相位的比较。整体平移训练和测试相位可能只重编号模板，因此不使用它证明对齐有效；扰动无影响也可能来自 Q 很小或主干补偿，不能单独否定机制。

## 6. 可复现合成机制诊断
使用 NumPy default_rng，生成 N=7200、C=3、P=24，t=0,…,N−1。数据种子为 2026、2027、2028，每个种子先生成独立标准正态数组 ε[t,c]；各条件共用该数组。固定 A=(1,0.7,1.3)、φ=(0,π/3,2π/3)，背景 g_t=0.5t/(N−1)，噪声 0.2ε。
- 稳定周期：y_tc=g_t+A_c[sin(2πt/24+φ_c)+0.3cos(4πt/24+φ_c)]+0.2ε_tc。
- 无周期：y_tc=g_t+0.2ε_tc。
- 漂移周期：令 θ_t=2πt/24+2π(max(t−a,0)/(N−a))²，用 θ_t 替代稳定条件中的 2πt/24，即第二谐波为 cos(2θ_t+φ_c)。漂移在训练结束后连续引入，到序列尾部约多累计一个周期。

使用同样 70/10/20 划分、L=168、H=24、模型 P=24、标准化和基线。诊断最低预算使用每个数据种子配固定训练种子 11，不将三个数据实现误称为优化种子重复；可选再做训练种子交叉。此处无缺失，缺失规则另由单元测试验证。稳定条件检验已知结构是否可利用，无周期检验不必要模板的代价，漂移检验固定重复模板的局限；不预言排序。

## 7. 评价和预先分析计划
主终点：真实数据 H=24 的**宏平均训练尺度标准化 MSE**。对每个变量，将所有测试起点和 horizon 中有标签的平方误差除以 s_c² 后平均，再对 C 个变量等权平均。重复出现的同一日历目标属于不同预测起点/提前量，按预定滚动协议分别计数，不解释为独立样本。

主要比较：完整模型减去无周期共享线性模型的主指标，负值代表完整模型误差较低。次比较为完整模型对固定模板残差和季节朴素预测；其他跨度、单提前量曲线及相位扰动均为次要/诊断分析，不从中事后挑选主结果。

同时报告：逐变量原始尺度 MAE、MSE；其变量等权宏平均明确标注为受单位影响的辅助量；宏平均标准化 MAE；每个预测跨度和提前量的误差。避免 MAPE 的零值问题。没有有效测试标签的变量须披露，不能默默改变主指标变量集合。

两类波动分开处理：
- **优化随机性**：报告 3 个训练种子各自分数、均值和样本标准差，以及配对种子的模型差值；种子范围不等同于测试采样置信区间。
- **时间相关误差**：在相同测试起点上先对三个种子的误差差值平均，再做成对移动时间块 bootstrap，保留块内所有变量、提前量、标签掩码和模型配对；每次从连续块抽样至原起点数并截断，重算完整宏指标。主块长 K=max(168,H)，重复 2000 次，bootstrap RNG=9029，报告百分位 95% 区间。可选 K/2、2K 敏感性，K 不超过可用起点数；若测试仅有很少有效块，明确区间不可靠，不作强推断。该区间描述既定数据/种子下的时间块重采样不确定性，不涵盖数据集外迁移或全部训练随机性。

支持标准：若主比较平均差为负、配对种子方向稳定且时间块区间不跨零，支持该数据和配置下周期模块贡献；若相对固定模板残差也更低，才进一步支持“模板可学习”带来的增量。仅优于季节朴素但不优于无周期主干，不能归因于周期机制；区间跨零视为证据不足，不宣称等价；持续劣于无周期或固定模板则不支持该配置的贡献。真实数据和合成诊断共同解释机制边界，不以合成成功替代真实数据结论，不作普遍优越性主张。
