# 词排序程序：最终实验设计

## 1. 目标与理由
设计并验证一个程序：将词列表排序，返回以空格分隔的单行文本。原题明示的是“词列表、按字母顺序、单行及空格分隔”；以下具体接口和排序语义属于本设计获批采用的约定，不表示已经确认原题的未知意图。

采用 Python 内置排序和字符串拼接，减少自定义排序的实现风险。验证重点为排序正确、内容与重复次数保持、输出格式正确、输入不被修改，以及非法输入处理一致。本交付仅为设计，没有执行程序或测试。

## 2. 输入、输出和错误处理约定
- 输入：Python `list[str]`。非列表抛出 `TypeError`；列表中任一元素不是字符串也抛出 `TypeError`，不隐式转换。
- 每个词必须非空，且不得包含任何满足 Python `str.isspace()` 的字符。空词或含空白词抛出 `ValueError`，不自动裁剪、拆词或忽略。
- 校验优先级：先检查容器类型，再检查所有元素类型，最后检查所有词的内容。因此同时含非字符串与空词的输入先报 `TypeError`。错误消息内容不作为通过条件。
- 排序：区分大小写的 Unicode 码点字典序；相同前缀下短词优先。保留原始字符、重复词和大小写，不进行规范化、地区排序或自然数排序。
- 允许数字、标点及其他非空白字符。ASCII 大写字母先于小写字母；例如数字字符串 `"10"` 排在 `"2"` 之前。
- 输出：返回 `str`，相邻词用一个 U+0020 普通空格连接，无首尾空格，不附加换行。空列表返回 `""`；单词列表返回该词本身。
- 不修改调用者的列表；非法输入不返回部分结果。

此排序在纯小写英文字母等适用范围内等同通常字母顺序，不能概括所有语言的词典排序。例如重音字母、大小写与组合字符的顺序可能不符合当地语言习惯。按当前约定，视觉相同但编码不同的字符串不合并。

## 3. 拟议实现（未执行）
```python
def sort_words(words: list[str]) -> str:
    if not isinstance(words, list):
        raise TypeError("expected a list")
    if any(not isinstance(word, str) for word in words):
        raise TypeError("all elements must be strings")
    if any(not word or any(ch.isspace() for ch in word)
           for word in words):
        raise ValueError("words must be nonempty and contain no whitespace")
    return " ".join(sorted(words))
```
`sorted` 创建新列表，避免原地修改；`join` 直接落实单空格连接。这里采用 `isinstance`，允许列表和字符串的子类；不接受元组、迭代器或整段字符串代替列表。
