## 2. 拟采用的研究思路
### 实现界定与公平比较
- 首先确认 BAdam 是否指 block-wise Adam，以及所据论文、算法或实现版本；不能仅凭名称认定。若确为该算法，需要锁定分块粒度、块顺序、切换周期、非活动块是否计算梯度、动量状态是否保留及偏差校正的步数定义。这些选择都可能改变扰动谱。

### 学习扰动与模块
- 建议主要定义为累计权重变化：对模块 m，在检查点 t 分析 ΔW_m(t)=W_m(t)−W_m(0)。它不同于梯度、单步优化器更新以及最终权重 W_m(t)；后者重尾不能证明学习扰动重尾。单步或块循环增量只作为机制补充。
- 建议优先研究全参数微调。若使用 LoRA 等适配器，应分析合并后的权重变化，并单独讨论低秩参数化对结论的结构性约束，不能据此推广到全参数微调。
- 候选模块为各层 attention 的 Q/K/V/O 投影及 MLP 的 up/down 投影；如架构含 gate 则包括 gate。固定 QKV 的拆分规则，不将不同层或不同形状矩阵混成一条谱。向量型 bias 和 normalization 参数不作为主矩阵谱对象；embedding 是否加入需确认。

### 奇异值重尾性与有效秩
- 对每个 ΔW 单独求奇异值 σ₁≥…≥σ_q≥0，q=min(矩阵两维)，分析其上尾，而非仅看双对数图是否近似直线。
- 建议将“重尾”操作化为：预先指定的尾区间中，幂律或截断幂律等尾部模型的拟合与替代模型比较所支持的有限样本证据，同时报告尾起点、尾样本数、指数及不确定性。将幂律、截断幂律与严格渐近重尾概念区分；有限谱不能证明无限尾部性质。需与指数等轻尾模型、对数正态候选比较，不能把“未拒绝幂律”当作已证明重尾。
- 建议直接定义在 σ 上；如改用 σ² 或 Gram 矩阵特征值，必须另行标明，因为尾指数会改变。矩阵内奇异值相关，尾拟合检验须说明校准限制，不能把全部奇异值视作独立实验重复。
- 建议主要有效秩采用熵定义：p_i=σ_i/Σ_jσ_j，r_eff=exp(−Σ_i p_i log p_i)；同时报告 r_eff/q。稳定秩 Σ_iσ_i²/σ₁²可作敏感性指标，但不与熵有效秩混称。全零扰动单独标记，避免对未定义的归一化计算或人为加 epsilon 后产生伪秩；小奇异值的精度与阈值规则需要预先固定。

### 如何判定“可比”
- 以相同模块、检查点和配对种子比较有效秩；建议主要效应量采用 log(r_eff,BAdam/r_eff,Adam)，归一化秩差作为补充。
- 先规定具有科学意义的等效界限，再设计精度与重复数。例如比值区间 [1/κ,κ] 可以表达允许偏差，但 κ 目前没有输入依据，不能事后按结果设定。
- 使用等效检验或相应置信区间完全落入等效界限的判据，而不是普通差异检验的 p>0.05。区间过宽意味着证据不足，不是等效；落在界限之外则不支持预定义的可比性。
- “跨模块”须明确是每个预先指定模块均满足，还是某个层级总体结论。建议按模块家族、深度及检查点展示结果，并预先处理多重比较；同一次训练的不同层不是独立训练重复。总体均值接近不能掩盖个别模块的系统性差异。
- 重尾性与有效秩可比性是两个独立判断：一种成立不推出另一种。除 BAdam 的尾部证据外，也应同样分析 Adam，作为对照。

- BAdam 各种子使用不同随机块排列，随后在该次训练内重复此排列；排列由独立 RNG 产生。记录每步活动块、各块累计激活步数、距最近更新的步数、梯度范数和学习率。在主检查点每块激活200步，但更新时间滞后仍从0到约120步不等，不能把完整循环末称为消除了相位效应。

### 调参规则
主分析采用共享超参数以聚焦更新规则。使用与正式种子分离的2个开发种子，双方分别试峰值学习率 {1×10⁻⁵, 3×10⁻⁵, 1×10⁻⁴}，均按完整预算训练；用双方平均验证 token NLL 最小的共同学习率作为主配置，平局选较小者。不得依据秩或尾部结果选学习率。该调参共12次训练，预算需显式计入。

若网格中没有双方均稳定的设定，记录失败并修订配置，不选择性删除失败种子。保存双方各自最佳学习率；“各自等调参预算最佳设置”的比较作为可选敏感性分析，不能替代主共享设置或事后挑选结论。

### 顺序与相位控制
核心顺序敏感性：正式8个种子中预先指定4个，再运行 BAdam 的反向块排列，训练流、学习率和预算不变；Adam 使用原配对结果。它检验层深与更新时间顺序的耦合，4个额外运行仅作敏感性证据，不并入8个主独立重复。

相位诊断：在主运行最后一个循环各块完成激活时，保存该块的分析矩阵及其准确 token 时刻，用于比较“刚更新后”的秩与终点秩。这些局部快照不构成相同 token 的主比较，也不替代终点结果。可选扩展为轮转起点或每循环重排的官方支持配置；若顺序改变引起主要结论改变，结论必须标记为顺序敏感。

## 四、模块范围与有效秩判定
### 主矩阵集合
每层 Q、K、V、O 投影和 MLP up、down 投影，共预期72个矩阵。按配置解包融合 QKV，并校验实际 head 排布，不能默认简单切片就正确。固定权重转置约定；不将 bias、LayerNorm 向量、embedding/head 纳入主要推断。若实际架构不同，先更新注册清单。

### 指标与容差
完整奇异值 σ_i≥0，q=min(d_in,d_out)。主要指标为
p_i=σ_i/Σ_jσ_j，r_eff=exp(−Σ_i p_i log p_i)，并报告 r_eff/q。
补充稳定秩为 Σ_iσ_i²/σ₁²，两者不可混称。

对每个种子和矩阵计算 d=log(r_eff,BAdam/r_eff,Adam)。建议等效区间为 [−log(1.10), log(1.10)]，即秩比值 [0.9091,1.10]。这是“几何比值不超过约10%偏离”的规范性选择，旨在把相对几何复杂度差异限制在较小范围；不是来自任务来源或已验证的下游性能阈值。另展示5%和20%界限的敏感性，但不以其中较宽者替换主判据。

### 分层推断与跨模块措辞
1. 家族主分析：每种子内对同家族12层的 d 取均值，再用8个种子的均值和标准差构造配对 t 等效检验 TOST；目标是种子与层平均的几何秩比，不是每层均等效。6个家族的等效 p 值用 Holm 控制 family-wise error 0.05。同时给出未校正90%区间与用于多重推断的保守98.333%区间，明确二者用途；后者全部落界内是充分的保守判据。
2. 逐层结果：展示全部72个矩阵的效应量及配对区间。若要逐矩阵宣称等效，采用其各自 TOST 并对72项 Holm 校正；不能把家族通过写成所有层通过。
3. 强结论：“所有主矩阵均可比”仅在全部72项满足预设校正判据时使用。这个规则较保守；一项不通过并不等于该项不等效，也可能只是精度不足。

t 方法依赖跨种子差值近似可建模；检查离群与分布，报告全部点。8个种子不支持精细的正态性验证，bootstrap 仅作稳健性描述而不保证修复小样本覆盖率。若区间跨越等效边界，报告证据不足；若区间完全位于容差之外，支持存在实质差异；普通差异检验不显著绝不作为等效证据。

正式运行前可用独立开发种子只估计方差、进行精度预算：对候选 n 计算临界值×s_d/√n，与 log(1.10) 比较，并考虑多重比较。两种子方差极不稳定，不能据此声称有足够功效。默认8对是适度预算而非功效保证；若资源不能支持更窄区间，保留不确定结论，不事后扩容直到显著。

## 五、重尾分析：有限谱证据，不作渐近证明
### 预处理与尾起点
对每个种子、每个主矩阵分别分析 σ，不混池。以 Frobenius 范数归一化可用于尾模型和图示，保持奇异值秩不变；不把 σ² 的指数与 σ 的指数混用。

候选尾起点取排序后观测值，要求至少100个正奇异值、且不超过正奇异值总数的50%进入尾部。对每个候选起点拟合 Pareto，取 KS 距离最小者；随后所有候选分布使用同一尾起点和同一批尾样本。保存阈值搜索范围及选择结果。少于100个合格尾样本则标为不足，不为得到结论降低门槛。另对尾样本数100、150、200、300中满足上限者作固定阈值敏感性分析，并报告尾覆盖比例和跨度。

### 候选模型及诊断
在 x≥x_min 上正确归一化的 Pareto、指数、截断 Pareto、对数正态，采用最大似然；截断模型中的指数截止与 Pareto 的边界嵌套关系需专门处理，不直接套常规卡方检验。

- 拟合优度：半参数/参数模拟中重新执行尾起点搜索，得到 KS 校准诊断；记录拟合参数及不确定区间。
- 模型比较：比较同一尾部样本上的对数似然、AICc，并以模拟校准的似然差作补充，不把 AICc 当显著性检验。建议 ΔAICc≥6 作为描述性的明显相对支持阈值。
- 必须明确：独立抽样模拟忽略奇异值依赖，其 p 值只作模型诊断，不具有已保证的谱数据覆盖率。最终证据还需矩阵级对照、阈值稳健性和独立训练种子一致性，不能依靠一个拟合 p 值。

### 预定义报告类别
- “幂律相容的有限谱尾部”：Pareto 拟合未明显失配、相对指数有明显支持，并且阈值改变不推翻结论；未拒绝拟合仅是必要诊断，不是证明。
- “对数正态相容”：对数正态拟合和模型比较更支持该解释；对数正态属于广义重尾，不能笼统归为轻尾，但不说明幂律。
- “截断幂律相容”：需保留截止特征；不称为严格渐近重尾，因为指数截止的渐近尾部是轻尾。
- “轻尾相容/反对所测重尾候选”：指数相对重尾候选具有稳定优势且矩阵级对照无法区分其尾部特征。这只反对所检验模型下的重尾解释，不证明不存在任何其他重尾形式。
- 尾样本不足、各候选均失配、模型难区分、跨度狭窄或阈值高度敏感，一律“证据不足”。

主重尾报告为每个矩阵8个种子的分类和参数，不进行奇异值级伪重复推断。可将至少6/8种子得到一致类别且不出现相反的强模型证据称为“跨种子可重复的描述性支持”；这是预定描述门槛，不是经校准的总体显著性检验。家族报告支持矩阵比例；只有每个预定矩阵都达到该门槛，才称在全部所测模块上观察到一致支持。Adam 完全执行同一分析，用于判断这种现象是否为双方共有。

### 分析校验与轻尾对照
- 对每种矩阵形状生成 iid Gaussian 矩阵，逐一匹配 ΔW 的 Frobenius 范数，至少100个实现，执行完整阈值选择和模型比较流程；估计该流程在尺寸、尺度匹配轻尾矩阵上误报尾部结构的频率。这是有限维随机矩阵零参照，不涵盖所有相关轻尾矩阵。
- 使用随机正交左右基构造已知完整谱：平坦谱、指数衰减谱、由 Pareto/对数正态/截断 Pareto 分布生成的谱、固定秩及近零谱，匹配形状和范数。核验有效秩恢复、排序、截断、尾起点选择和分类局限。区分“谱随序号幂律衰减”与“奇异值样本分布”的指数关系，不能直接照搬指数。
- 若控制显示误报率高或模型不能区分，正式数据只能报告描述性尾部形状，不能作强重尾结论。不得用正式数据反向修改算法再宣称确认；修改需要另行冻结验证。
这些控制均不能替代独立训练重复。

## 六、数值精度、存储与可行性
### 权重差与近零处理
保存 FP32 主权重而非仅 BF16 导出权重。读取后转 FP64 再减同一初始权重；这减少相减/分解的额外误差，但不能恢复训练或保存时已丢失的低位。记录 ||ΔW||F、||ΔW||F/||W₀||F 及变化元素比例。

全零扰动单独标记，熵秩未定义，不加 epsilon 伪造秩。近零包括扰动接近主权重存储的可分辨尺度，或其谱对精度/阈值选择显著敏感；先以无更新往返保存和数值校验确定误差底线。主要熵秩使用全部非负奇异值，0 log0=0；并报告将低于 max(d_in,d_out)×machine_epsilon×σ₁ 的值视为零的敏感性。尾部分析不纳入数值不可分辨值。不能按不同优化器分别选择阈值。

### 完整谱
逐矩阵以 FP64 SVD 计算全部 q 个奇异值，可不保存 U/V；核验 Σσ² 与 ||ΔW||F² 一致，并抽检另一求解路径。只计算 top-k 不能可靠得到 Σσ、熵或 r_eff，不作为主方案。Gram 分解可能加重小奇异值条件数问题，不作为未经验证的替代。

### 资源估计方法
本任务当前不需要资源，以下仅供将来预算：160M 参数的 FP32 权重约0.64 GB（十进制）；权重、梯度和两份 Adam 状态的基础量约2.56 GB，另加激活、临时张量、框架开销及混合精度副本。建议先按单张24 GB GPU、微批量1–2并梯度累积规划，但不保证无需测量即可容纳；可用双方一致的 activation checkpointing。

16个主运行×3个检查点×0.64 GB约30.7 GB，初始权重可共用。优化器恢复状态、调参、反序运行及额外局部快照另计；调参运行可以只保留日志与最终选定配置，不必保留全部谱检查点。仅保存 ΔW 不降低密集存储数量，压缩或低精度存储须验证不改谱。

预期72个矩阵/检查点，主运行三个检查点合计3456次完整 SVD。单矩阵复杂度约 O(mn min(m,n))、工作内存按实际求解器测量；768维方阵和3072×768矩阵可串行处理，避免一次加载全部差值和工作区。未来先对每种形状测单次 SVD 时间与内存，再乘数量并预留 I/O 开销；训练时间也用预热后的 tokens/s 分别估计，不能由理论参数量推定 BAdam 更快。16个主运行约3.41亿 token 暴露，12个开发运行及4个反序运行分别再加约2.56亿、0.85亿；它们是累计计算量而非独立数据规模。

### 核心与低预算版本
核心必需：核实算法身份、配对 token 主比较、FP32 初始/终点权重、所有主矩阵完整谱、独立种子、预定等效界限、顺序记录、轻尾与已知谱校验。中间检查点、各自最佳学习率、AdamW、额外模型/数据及额外相位训练均可削减。

低预算可保留终点谱，采用一个预先固定学习率3×10⁻⁵（明确放弃调参稳健性）、4对种子和2个反序敏感性运行。仍保留所有模块及完整谱；其主要定位是可行性和效应区间描述，不能承诺支持10%等效。任何减少训练步数或模型规模的版本都是较窄的新研究范围，须在看结果前声明。

## 七、最终决策与交付
有效秩：校正后的等效判据通过，支持所声明层级的可比性；精确区间越过容差且位于其外，支持实质差异；跨边界或过宽则证据不足。失败训练、近零未定义及缺失矩阵均显式报告，不能通过删去困难模块获得“所有模块”结论。
