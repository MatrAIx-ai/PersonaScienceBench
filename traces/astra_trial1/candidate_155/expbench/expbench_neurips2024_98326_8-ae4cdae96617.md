## 1. 目标与选择理由

回答的问题是：如何使用 TorchOpt 对元学习双层目标实现隐式微分，并验证所得元梯度及其在外层学习中的作用？

- 唯一、可核对的解析解；

外层参数 φ 是**可学习共享先验/近端中心**，不是单纯的求解器初始化。φ 必须进入内层目标；如果它仅改变初始化，而唯一内层最优解与 φ 无关，那么收敛后对 φ 的隐式梯度为零，不能实现这里的元学习。

## 2. 双层目标与隐式梯度

对任务 τ，支持集为 (X_S,y_S)，查询集为 (X_Q,y_Q)。模型无截距，预测为 xᵀθ。

内层目标：

L_in,τ(θ,φ) = ||X_Sθ−y_S||²/(2n_S) + λ||θ−φ||²/2，
θ*τ(φ) = argminθ L_in,τ(θ,φ)。

外层目标：

J(φ) = E_τ[L_Q,τ(θ*τ(φ))]，
L_Q,τ(θ) = ||X_Qθ−y_Q||²/(2n_Q)。

定义
Aτ = X_SᵀX_S/n_S + λI，
bτ(φ) = X_Sᵀy_S/n_S + λφ，
Fτ(θ,φ) = ∇θL_in,τ = Aτθ−bτ(φ)。

因为 λ>0，Aτ 对称正定，内层唯一解满足 Aτθ*τ=bτ。所有“解析解”实现都使用线性方程求解，不显式求逆。

由 Fτ(θ*τ(φ),φ)=0 得
D_φθ*τ = −(∂θFτ)⁻¹∂φFτ = λAτ⁻¹。

令 qτ=∇θL_Q,τ(θ*τ)=X_Qᵀ(X_Qθ*τ−y_Q)/n_Q，解伴随系统
Aτᵀvτ=qτ。

则每任务元梯度为
∇φL_Q,τ = ∂φL_Q,τ − (∂φFτ)ᵀvτ = λvτ。
批量元梯度是任务元梯度的平均。

这里查询损失没有显式 φ 项，所以偏导 ∂φL_Q=0。一般问题若有显式依赖，需要额外加上该项。

**适用条件：** 最优性映射局部连续可微，驻点满足 F=0，∂θF 可逆。本方案的光滑二次目标和正 λ 保证这些条件。近似内层解不满足精确驻点条件，因此在其上构造的隐式梯度应称为近似值。CG 适用于这里的正定伴随系统，不由此推断它适合任意非凸 Hessian。

## 4. TorchOpt 实现流程与接口边界

### 4.1 参数对应和伪代码

主路线是函数式 `torchopt.diff.implicit.custom_root`。下述是**概念伪代码**；装饰器签名和配置写法须在实施前核验。

```text
# 以下五个位置按概念对齐：
# 位置 0：最优性函数接收候选解 theta；求解函数接收初值 theta0
# 位置 1：可求导的外层参数 phi
# 位置 2、3：常量支持集 XS, yS
# 位置 4：固定常量 lambda

F(theta, phi, XS, yS, lambda):
    return XS.T @ (XS @ theta - yS) / nS + lambda * (theta - phi)

solve_forward(theta0, phi, XS, yS, lambda):
    在 no_grad 环境中，用 phi 的当前数值固定内层目标
    从 theta0 的数值副本开始执行梯度下降
    达到驻点残差阈值或迭代上限后返回 theta_hat
    不保留前向迭代轨迹的自动微分图

implicit_solve = CUSTOM_ROOT_WRAP(
    solve_forward,
    optimality_function=F,
    differentiate_argument=phi 的位置 1,
    linear_solver=基于算子的 CG
)

phi = requires_grad 的叶张量，初始为零
对每个外层训练步：
    清空 phi.grad
    对批内每个任务：
        theta_hat = implicit_solve(zeros, phi, XS, yS, lambda)
        loss_tau = ||XQ @ theta_hat - yQ||² / (2*nQ)
    loss = mean(loss_tau)
    loss.backward()       # 触发隐式反向，而非前向轨迹反传
    在 no_grad 环境中 phi -= 0.1 * phi.grad
```

若选定版本的 `argnums` 使用上述对齐函数的零起始参数位置，则目标位置是 1；究竟应传 `1`、`(1,)`，以及它依据求解函数还是最优性函数的签名解释，均属于实施前核验项。不能未经核验把这里的概念包装器当成真实 TorchOpt 调用。

### 4.2 如何切断轨迹而保留隐式依赖

- `solve_forward` 的迭代只需要 φ 的数值，可以在 `no_grad` 下运行；其输出作为隐式根包装器的数值解。
- 调用包装器时必须传入原始、可求导的 φ；不要先把 φ 脱离计算图再传给包装器。
- 不要在包装器返回后再次 `detach()` θ̂ 再计算查询损失，否则会切断隐式反向边。
- 正确的依赖不是“沿每一步 θ 更新回传”，而是包装器使用 F(θ,φ) 在最终解附近重新建立局部导数关系。
- 残差、迭代次数等诊断量应以脱图日志保存，不误作需反传的求解输出。真实 API 若涉及辅助返回值，需核对其支持方式。

### 4.3 反向中的局部自动微分

在最终 θ̂ 处重新启用局部自动微分：将 θ̂ 的数值视为独立局部变量，并保留 F 对 φ 的偏导关系。对输入方向 u，局部 VJP 给出

u ↦ (∂θF)ᵀu = Aᵀu。

当 F 由 `grad(L_in, theta)` 构造时，需要保留用于进一步求导的局部图，例如 PyTorch 的 `create_graph=True` 机制；不能连局部 F 的图也在 `no_grad` 中计算。这里也可用显式 F 公式构造可微运算，避免不必要的嵌套梯度。

以查询损失传来的 q 为右端，CG 通过上述算子得到 v；随后计算
−VJP_φ(F,v)=λv。

这一 VJP 应是固定 θ̂ 的偏导，v 在该收缩中作为给定向量；不要意外计算出 θ̂ 或 v 对 φ 的额外全导数。实际包装器承担这一隐式反向规则，实验用解析公式独立检查其符号、尺度及任务平均方式。这里不要求高阶元梯度。

主实现使用算子乘积，不显式构造 Hessian。d=10 的稠密 A 仅用于参考解、残差核对及选择稳定的前向步长。

### 4.4 实施前必须核验的 API 项

候选线性求解器为 `torchopt.linear_solve.solve_cg`，但本地没有资料确认其调用约定。实施前记录 Python、PyTorch、TorchOpt 版本，并核对：
1. `custom_root` 的装饰/包装方式，最优性函数与求解函数的位置参数对应，`argnums` 规则；
2. 根变量、求解输出及 pytree 结构要求，辅助返回值的处理；
3. 线性求解回调接收何种算子、是否已转置、右端结构和返回结构；
4. `solve_cg` 是工厂还是直接求解调用，绝对/相对容差与迭代上限语义；
5. 包装器如何对无轨迹前向输出建立隐式反向。

核验后才能将伪代码替换成可运行实现。若内置 CG 的停止规则不完全一致，应通过适配器实现目标残差口径，并始终以独立重算的实际残差为准。

## 5. 内层与伴随求解默认值

### 内层前向

采用定步长梯度下降 θ←θ−αF，α=1/λ_max(A)。对本小问题，λ_max(A) 通过对称特征值计算获得；这是为了稳定且易解释的参考设置，不宣称该选步策略可扩展到大网络。

定义
r_in = ||F(θ,φ)||₂ / max(1,||b(φ)||₂)。

默认停止条件为 r_in≤10⁻¹²，最多 2,000 步；从 θ₀=0 开始，每步后检查，初始点也检查。到上限仍不达标，记录失败，不当作收敛结果。

### 伴随反向

CG 初值 v₀=0，定义
r_adj = ||Aᵀv−q||₂ / max(1,||q||₂)。

默认 r_adj≤10⁻¹²，最多 200 步。q 精确为零时直接返回 v=0。若出现数值停滞或到上限未达标，保留实际残差和失败标记。

## 6. 正确性对照与误差分离

### 6.1 三类必需对照

**A. 解析/直接线性求解参考**
- 解 Aθ*=b，再解 Aᵀv*=q(θ*)，得到 g*=λv*，批量取平均。
- 对直接线性求解得到 θ* 的路径使用普通自动微分，得到另一参考梯度，检查公式及实现。
- 对主实现返回的 θ̂，额外计算 g_loc=λ solve(Aᵀ,q(θ̂))。它不是精确最优解映射在真实根处的最终参考，而是用于分离反向求解误差的局部参考。

**B. 中心有限差分**
- 在诊断批上，用直接线性求解定义精确双层标量目标 J_ref，逐坐标计算中心差分。
- 扫描相对步长 s∈{10⁻²,10⁻³,10⁻⁴,10⁻⁵,10⁻⁶,10⁻⁷}，坐标步长 h_j=s·max(1,|φ_j|)。
- 不以容差终止的迭代前向作为主要有限差分目标，避免停止步数跳变和求解误差污染。
- 可补充一个固定随机单位方向的方向导数检查，但不替代逐坐标检查。

**C. 完整展开**
- 使用相同 θ₀ 和相同步长，保留每一步的计算图，对固定步数 K 的内层算法直接反传。
- 检查 K∈{1,5,20,100}，以及 K_conv。K_conv 为该固定参数点的无图前向首次达到 r_in≤10⁻¹² 的步数；重新展开时将其冻结，不对停止判断求导，最多 2,000 步。
- 有限 K 的梯度是“执行 K 步求解算法”的导数，不是精确 argmin 映射的导数。只有内层及其敏感性充分收敛，才应趋近 g*。不把小 K 的差异判为 TorchOpt 错误。

### 6.2 独立控制两类求解精度

在全部诊断种子、两个常规 φ 点及近零点上，做以下固定扫描：
- 内层扫描：tol_in∈{10⁻²,10⁻⁴,10⁻⁶,10⁻⁸,10⁻¹⁰,10⁻¹²}，tol_adj 固定 10⁻¹²。
- 伴随扫描：tol_adj 取同一集合，tol_in 固定 10⁻¹²。

记录 ||g_loc−g*||（前向近似影响）、||g_impl−g_loc||（反向求解/实现影响）及 ||g_impl−g*||（总误差）。这些误差不必逐项严格单调下降；报告真实残差，不能只画用户请求的容差。

### 6.3 预设指标与通过判据

对每个任务和批平均均报告：
- 梯度绝对误差 ||g−g_ref||₂；
- 当 ||g_ref||₂>10⁻⁸ 时，报告相对误差及余弦相似度；若候选梯度也近零，余弦标记为不适用；
- 当参考梯度范数≤10⁻⁸ 时，不用相对误差或余弦判定，报告绝对误差和双方范数；
- 内层解误差、r_in、r_adj、迭代次数及失败状态。

拟议正确性标准：
1. 直接求解自动微分与解析梯度：误差≤10⁻¹⁰+10⁻⁹||g*||₂。
2. 默认高精度隐式梯度：误差≤10⁻⁸+10⁻⁶||g*||₂，且前向和伴随均达到规定残差。
3. 有限差分：至少两个相邻步长档满足误差≤10⁻⁷+10⁻⁵||g*||₂；完整报告所有档，不只报告最佳步长。
4. K_conv 展开对照：误差≤10⁻⁸+10⁻⁶||g*||₂；若不满足，则报告未能得到充分收敛的展开参考，而不是更改阈值隐藏差异。

这些阈值是预先提出的工程判据，不是数学保证。分别报告通过数量、最大误差及失败案例；尤其不能用任务梯度在批平均中抵消来掩盖逐任务错误。若主实现未通过默认正确性检查，不将随后外层变化解释为已验证的隐式元学习效果。

## 7. 外层学习与独立测试

### 7.1 训练流程

使用默认高精度内层和伴随设置，100 步 SGD 更新 φ。记录第 0、20、40、60、80、100 步的训练批损失、||φ||、元梯度范数及求解残差；训练批损失包含批次波动，不作为独立泛化评估。

可在相同批序列上并行执行一条使用解析元梯度的外层参考轨迹，作为实现一致性诊断；它不是额外的科学假设或性能基线。记录两条 φ 轨迹的距离，不强迫它们在浮点数层面完全相同。

若求解器达到上限、出现非有限数或更新发散，按预设失败规则报告，不临时降低学习率或筛掉种子。重新设计超参数属于另一次明确标注的方案修订。

### 7.2 固定先验与配对比较

每种子完成训练后，在其 128 个独立测试任务上比较：
- 学习先验 φ̂，即第 100 步的 φ；
- 固定先验 φ=0，即训练前先验。

两者使用相同测试任务、相同支持/查询数据、相同 λ，并都用直接线性求解适配 θ*。这样测量的是先验差异，而不是两种方法的测试时求解误差。可额外检查默认迭代适配与直接求解的一致性。

每任务定义配对差值
Δτ=L_Q,τ(θ*(φ̂))−L_Q,τ(θ*(0))。
负值表示学习先验在该任务上更好，正值表示更差。主要终点为每种子的任务平均 Δ，不用相对百分比掩盖小分母。

### 7.3 跨种子汇总

报告全部 5 个种子的：两种先验平均查询损失、平均 Δ，以及配对任务差值的分布摘要。跨种子报告平均 Δ、种子间标准差和全部单种子值。

可给出基于 5 个种子均值的 t 区间：平均值 ± t_(4,0.975)·标准差/√5，明确其样本量小且近似假设有限。不能将 640 个任务差值当成 640 次独立训练重复，因为同一种子内共享学习先验。不预设显著性或改善方向；若学习更差或差异不明确，也如实报告。

## 8. 成本、CPU 可行性与可报告结论

d=10、每任务 40 个样本、每种子 264 个任务，无需下载数据。内层矩阵、伴随向量和局部图很小；从计算结构看适合 CPU。即便有最多 2,000 步的展开对照，也只在小诊断集合上执行。这是可行性分析，不是运行时间承诺。

主隐式路径不保留 K 步前向更新图，其自动微分存储不随前向迭代数 K 线性增加；但它仍需要最终解、局部 F 的导数图和伴随求解工作空间。完整展开通常需要与 K 相关的轨迹图。本设计不据此声称隐式方法在小问题上实际更快或总内存一定更低。

如测量时间和内存：
- 固定线程数、软件版本、数据、前后向容差和日志设置；
- 分别计时前向、反向、总步，并记录迭代次数；预热 5 次、测量 20 次，报告中位数及离散程度；
- CPU 峰值 RSS 用独立进程和一致的进程级测量工具，给出基线与测量口径，不用 Python 对象内存代替全部张量内存；
- 不将闭式参考或有限步展开的不等价计算量误表述为同精度速度对比。

完成实施后，本设计可以支持关于“在这个强凸、光滑、可核对的元回归实例中，TorchOpt 隐式反向是否正确、误差如何受两类求解精度影响、学习共享先验在独立任务上的表现如何”的结论。**不能外推为一般非凸神经网络中的正确性、收敛性、稳定性或效率保证。**
