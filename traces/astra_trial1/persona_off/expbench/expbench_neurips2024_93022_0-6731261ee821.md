## Aim and scope
Assess whether forward-model samples reproduce ground-truth all-atom MD distributions for tetrapeptides across backbone torsions, sidechain torsions, and leading TICA components. This is a design, not an executed analysis. Agreement would support similarity for the tested ensembles and observables, not full atomistic equivalence or kinetic fidelity.

## Required inputs and unresolved setup
Required inputs are reference and generated coordinates or equivalent validated torsion outputs; peptide identities and topology, including terminal chemistry and atom mapping; trajectory/replica identifiers and timestamps; MD conditions and equilibration information; generation and initialization protocols; any sampling weights; and model training/validation provenance. TICA requires time-ordered reference trajectories with known frame spacing.

Peptide identities, physical conditions, sampling protocols, trajectory availability, TICA settings, available resources, and expected outcomes remain unknown. No extra source topics are assumed available. Missing inputs should trigger the contingencies below rather than guessed setup facts.

## Primary and diagnostic comparisons
Define a primary family separately for each peptide and matched condition, and, for finite-time sampling, each prespecified time window. Include:
- Every chemically defined backbone torsion, including phi/psi and applicable omega, and every sidechain chi: circular Wasserstein-1 distance, using shortest angular distances normalized by pi.
- Joint distributions: MMD with a fixed characteristic kernel on sine/cosine features for each residue's phi/psi pair, each multi-chi sidechain, and the full torsion vector. These local joint tests prevent a single global score from hiding a conformational failure.
- Each retained leading TICA coordinate: Wasserstein-1 distance after frozen reference scaling; plus MMD on the joint retained TICA coordinates.
- Absolute occupancy differences for any scientifically important basins identifiable before evaluation. These become primary if specified; basins noticed after examining model results are exploratory.

Kernel form, bandwidths, coordinate scaling, and any basin boundaries are fixed using reference fitting/calibration data before evaluation. Use nonnegative empirical MMD for an interpretable distance, recognizing its finite-sample bias and calibrating it through MD-versus-MD comparisons.

Diagnostic displays include circular densities, Ramachandran maps, sidechain joint maps, TICA densities, occupancy tables, distance-versus-sample-size plots, replica heterogeneity, and coverage of low-occupancy states. Density estimation is descriptive, not the primary decision basis. Transition counts and autocorrelation plots may diagnose sampling problems but will not establish kinetic accuracy.

## Stepwise protocol
### 1. Define the estimand and validate compatibility
Compare each peptide under matched physical conditions; do not pool different sequences or thermodynamic states. Validate topology, units, atom ordering, geometry needed for torsions, missing frames, and trajectory boundaries. Invalid generated structures are reported as model failures with their frequency; do not silently discard them and claim unconditional similarity. If exclusions are necessary, explicitly label the resulting conditional estimand.

For an equilibrium target, specify equilibration removal using preparation metadata and reference-only stationarity diagnostics, and then apply an appropriate prespecified policy to generated trajectories. Pool retained frames according to the intended time/replica weighting, not whichever trajectories happen to be longest. Stationarity checks cannot prove complete equilibration; residual uncertainty must be reported.

For finite-time trajectories, match the initial-state distribution, conditioning variables, physical time and observation windows. Compare distributions at prespecified times or within windows using identical temporal weights. Preserve paired starting-condition structure where available. Frames within one rollout are not independent replicates. If initial-state distributions differ, stratify on common support or use prespecified, justified weighting; report unsupported strata. If model steps lack a physical-time interpretation, do not claim matched-time similarity. Only a separately defensible stationary ensemble comparison is then possible.

### 2. Partition reference data and freeze analysis choices
Prefer disjoint independent replicas for reference fitting, calibration and final evaluation, also separated from model training/tuning. The fitting partition determines feature transformations and TICA; calibration selects settings, assesses precision, and supplies MD-versus-MD baselines. Final reference evaluation and generated samples are not used to select settings.

Splits must preserve parent simulation and initialization groups. Where only long trajectories exist, use contiguous blocks with gaps informed by reference dependence estimates; do not randomly shuffle frames into train/test sets. Document overlap with model training. Unverifiable overlap precludes a clean claim of out-of-sample generalization even if distributional comparison remains descriptive.

### 3. Construct periodic features
Extract identical backbone and sidechain torsions from both sources. Mark chemically undefined torsions as not applicable, rather than zero. Use circular arithmetic across the minus-pi/pi seam. Specify symmetry conventions for equivalent sidechain atoms before extraction, distinguishing relabeling symmetry from physically distinct rotamers. Use sine/cosine embeddings for multivariate torsional comparisons and, provisionally, as the TICA input representation. The TICA representation is a design choice, not a source-reported setting.

### 4. Select and fit TICA without leakage
Use reference fitting trajectories for all covariance estimation and reference calibration trajectories for lag/component selection. Do not create lagged pairs across trajectories, split boundaries, or missing-time gaps. For an equilibrium target, reversible TICA is a candidate only if its assumptions are defensible; otherwise document an appropriate nonreversible implementation or limit interpretation to a reference-defined projection.

Prospectively use this reference-only selection rule:
1. Build a geometric lag grid in units of the actual saved-frame interval, restricted to lags with adequate within-trajectory pairs and independent reference blocks. Determine the upper bound from the available duration and dependence, not generated performance.
2. For each candidate lag, estimate candidate leading subspaces across reference replica/block resamples. Match nearly degenerate modes as subspaces rather than insisting on identical signed eigenvectors.
3. Retain leading nonconstant components only while covariance estimates are well-conditioned, lagged structure is reproducible on calibration data, and the subspace is stable across resamples and neighboring lags. Exclude unstable modes even if their fitted eigenvalues are large. Fix regularization using reference data only.
4. Select the smallest lag in a stable run of neighboring grid points, and the largest leading subspace up to a prespecified cap that passes stability and precision checks. Provisional choices are three neighboring lag points and a cap of five components; these are tunable design settings, not known system facts. Numerical stability tolerances, such as allowable principal angles and held-out score variability, must be documented before generated samples or final evaluation are examined. Implied-timescale plateaus may support selection but are not sufficient by themselves.
5. Freeze the selected fitting-data TICA map, centering, scaling, lag and component count. Apply it unchanged to final MD and model samples. If no candidate passes, report the top-TICA endpoint as not reliably estimable instead of choosing a favorable projection.

For nonstationary finite-time reference data, a pooled TICA projection can be sensitive to initialization and time weighting. Fit under the same specified reference weighting and label the projection accordingly; do not interpret it as equilibrium slow dynamics. If that projection is unstable, use the TICA contingency rather than importing an unverified stationary reference.

### 5. Establish calibration baselines and equivalence margins
Use independent reference calibration replicas or suitably separated blocks to construct MD-versus-MD comparisons under the same preprocessing, time windows and weighting. Repeat comparisons at sample sizes and dependence levels resembling the planned model-versus-MD comparison; report raw and effective sizes, since effective size is observable-specific. These baselines quantify expected sampling discrepancy, bias, power limitations and attainable precision. They are not scientific equivalence margins, and a noisy reference must not automatically permit larger model error.

Before final evaluation, assign every primary endpoint a practical tolerance in its own units. Justify tolerances through acceptable errors in basin populations or downstream uses when available. Circular distances and standardized TICA distances still require scientific interpretation; reference standardization does not supply that interpretation. Deliberate perturbations can help map distances to interpretable occupancy errors, but cannot themselves decide which errors are acceptable. Where no defensible margin is available, provide calibrated estimates without a formal similarity claim. Reference precision inadequate for a meaningful margin calls for an inconclusive result or more data, not an enlarged margin.

### 6. Evaluate and quantify uncertainty
Compute frozen endpoints on final held-out MD and generated trajectories. Resample independent replicas or parent trajectories at the highest independent level, with paired resampling for matched initial conditions. Where appropriate, resample time blocks within trajectories; choose block lengths to cover the slowest relevant dependence in both sources and test longer-block sensitivity. Estimate uncertainty in both MD and model samples. Nominal frame count is not sample size, and simple frame-wise bootstrap or frame-wise label permutation is invalid for correlated trajectories.

For sparse states, report counts, independent visits and uncertainty; zero observed occupancy is not proof of zero probability. Use independent-unit or block subsampling and MD-versus-MD calibration to assess finite-sample distance bias and confidence-interval behavior, particularly near zero distance. If there are too few independent units for credible interval calibration, do not present nominal coverage as assured.

Report primary uncertainty conditional on the frozen TICA map. Separately refit TICA across reference-fitting resamples and recompute comparisons as a sensitivity analysis; align stable subspaces and report whether conclusions depend materially on estimation of the projection.

## Controls
- Independent MD versus MD: apply the identical analysis pipeline to disjoint reference samples. Differences much larger than anticipated motivate investigation of reference heterogeneity, insufficient sampling, or mismatched weighting. This is a repeatability/precision control, not a guarantee that MD is fully converged.
- Deliberately perturbed distributions: use held-out calibration MD frames reweighted to omit a populated basin, alter a sidechain rotamer weight, or enrich a tail. Add a diagnostic synthetic construction that retains marginal torsion distributions but breaks their joint dependencies. Such controls need not be physical trajectories; they test distributional endpoints only. Prespecify perturbation magnitudes and confirm that important changes exceed the analysis noise floor before final evaluation. An identical-sample comparison checks implementation but is not an independent negative control.
- Feature checks: equivalent angle representations across the periodic seam should give identical distances; harmless trajectory reordering must not create TICA lagged pairs; atom-symmetry conventions must be invariant to equivalent relabeling.

## Family-level decision rule
Freeze endpoint families and margins before final evaluation. Construct simultaneous uncertainty bounds for all primary endpoint distances across claimed peptides, conditions and time windows. A provisional familywise error level is 0.05. A conservative implementation uses multiplicity-adjusted individual block/cluster confidence bounds; a validated max-statistic resampling approach may improve efficiency. Secondary exploratory comparisons are labeled as such and cannot repair a failed primary endpoint.

For nonnegative discrepancy d_j and scientifically justified tolerance delta_j:
- Similarity for the claimed family: every simultaneous upper bound is below its delta_j, sampling and estimation checks are adequate, and no required endpoint is unavailable.
- Meaningful discrepancy: at least one simultaneous lower bound is above its delta_j. Identify the failing variables and affected systems; do not hide them in a mean score.
- Inconclusive: neither condition is met, or essential margins, support, independent sampling, or required TICA estimation are inadequate. A subset may support similarity, but cannot be promoted to a full-panel claim.

Failure to reject an equality null is not similarity. Statistically detectable differences below practical tolerances need not be meaningful discrepancies. If one endpoint clearly fails while others remain uncertain, report the established failure and the remaining uncertainty separately.

## Contingencies and feasibility
With few replicas, use long-trajectory blocking only when duration substantially exceeds dependence scales, report sensitivity to gaps/block lengths, and explicitly weaken independence claims. With only one poorly mixing trajectory or too few independent transitions, restrict reporting to descriptive differences and inconclusive inference. If TICA is unstable, try reference-only regularization or a smaller stable leading subspace and disclose the reduced scope; do not replace required TICA evidence with a favorable torsion-only result.

Coordinate reading and torsion extraction scale roughly with frame count times torsion count and can be streamed. TICA covariance formation scales roughly as frames times squared feature dimension, with a feature-space eigensolve. Exact multivariate MMD is quadratic in sample count; block estimators or fixed random-feature approximations can reduce cost, with approximation checks on calibration subsets. Bootstrap refits may dominate cost and can be separated from the primary frozen-map analysis. Save derived torsions/TICA projections and process by trajectory. No available budget, runtime, dataset size, or hardware sufficiency is asserted.

## Reporting deliverable
Provide a provenance and split diagram; peptide/condition inventory; retained sampling windows and weighting; raw counts, independent-unit counts and dependence diagnostics; torsion definitions; TICA selection/stability records; fixed metrics and margins with rationale; control results; per-endpoint distances with simultaneous bounds; distribution plots; invalid-sample and rare-state accounting; and explicit similarity/discrepancy/inconclusive labels. Summarize limitations without predicting outcomes.
